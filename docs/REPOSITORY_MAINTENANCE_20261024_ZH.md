## B 每一份未来实验与数据 PR 的最小清单

1. **角色**：准确标明 `proposal` / `development` / `frozen-evaluation` / `exploratory-diagnostic` / `failed-gate` / `data-only` / `blocked-rights`；不得把“未过门”改写为“已证明没用”。
2. **协议与信息边界**：预测对象/市场/产品、时间轴和交易日、目标变量、期限、基准、评分区间、等资产汇总规则、失败处理、任何事前修改的 SHA/时间戳。
3. **完整记录**：带输入/代码哈希的 manifest；逐资产和等资产 ΔQLIKE；改善资产计数；训练/推断错误与非正方差原点计数，原样保留。
4. **时点与使用权**：公告首次可得时间及版本；源码/第三方行情/政策全文的再分发权分别记录；外部数据权限不足时仅公开非侵权的摘要、来源链接、合法复现指令与失败码。
5. **校验**：机器可复现验证结果、相对链接检查；论文相关统计推断须报告区间及条件，不得写无区间的“显著”；负 QLIKE 损失水平不能报百分比变化。
6. **流程**：若需要新模型实验，另提 ≤60 行的事前冻结方案与预算等待作者确认；不要在已见 2025/2026 反复换基准、期限、资产或区间。数据整理本身不触发拟合。
