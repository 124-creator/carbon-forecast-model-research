# 标准统计基线：加权岭回归与平滑 Markov reward

日期：2026-10-17。实现：[source/stat_baselines.py](source/stat_baselines.py)。这两项用于检验结构模型是否超越标准统计方法；**不构成创新模型，也没有使用真实价格拟合或选择参数。**

## 公共输入与输出

调用方提供训练批次：x 为 N×20×C 输入，scale 为 N 个严格正的起点尺度，y 为 N×20 的未来累计价格变化除以该起点尺度，state 为 N 个当前状态，event 为 N 个首步事件。事件顺序固定为 0=零、1=负、2=正。

两个预测器均返回 B×20 的归一化累计变化 m。转换为价格预测由 runner 完成：

\[
\widehat P_{t+h}=P_t+s_t\,m_{t,h}.
\]

预测器不乘第二次尺度、不除以平方根期限，也不使用未来时点更新尺度。训练/验证划分、标签成熟、公共支持、年度冻结和验证价格 MSE 选择均由 runner 控制；本模块不发现文件、不读取数据、不进行调参。

## 1. 加权多输出岭回归

接口：

    model = fit_ridge(train, alpha)
    m = predict_ridge(model, batch)

先按原时间/通道顺序展开 x。每个输入坐标采用训练样本的**无权总体均值和标准差**，标准差下限 1e-6。加入一个截距列，列顺序为截距在前。令标准化设计矩阵为 X，输出矩阵为 Y：

\[
w_i=\frac{s_i^2}{N^{-1}\sum_j s_j^2},\qquad
\left(\frac{X^\top W X}{N}+\alpha D\right)\beta
=\frac{X^\top W Y}{N},
\quad
D=\operatorname{diag}(0,1,\ldots,1).
\]

截距不受惩罚。由于价格预测误差等于 s_i(m_i-y_i)，该权重对应共同尺度常数下的价格平方误差。特征标准化本身仍无权，不能把这两项混淆。

候选强度由父任务固定为 0.01、0.1、1、10、100。本模块接受单个正 alpha；选择由 runner 使用相同验证价格 MSE 完成。

实现先计算 (scale/max(scale))² 再按其均值归一化，避免直接计算巨大或极小 scale² 造成整体溢出/下溢。这在数学上等价于上述权重；远小于浮点表示范围的相对权重可能数值下溢为零。合成检查覆盖 1e-200 与 1e200 的整体单位变化和极端权重不平衡。模型保存训练均值、标准差及系数的只读副本，预测批次不重新估计统计量。

## 2. 平滑 Markov 计数与方向幅值基线

接口：

    q, b = fit_markov_mle(train)
    m = predict_markov_mle((q, b), batch)

函数名保留约定的 mle 字样，但估计包含明确伪计数平滑，**不是未经平滑的最大似然估计**。

### 状态必须来自完整可见前缀

调用方传入：

\[
s=3(\ell+1)+\min(a,2),
\]

其中最后一个非零变化方向 ℓ 属于 {-1,0,+1}；0 表示从未出现非零变化。a 是连续零变化长度。因此负方向对应 0/1/2，中性未知对应 3/4/5，正方向对应 6/7/8。

零事件保留原来的非零方向并把零龄加一、上限二；负事件移到状态 0；正事件移到状态 6。**即使最近 20 个输入都是零，也不能把更早已知的非零方向重置为未知。** 模块使用 caller 的 state，不从最近输入窗口重建历史。

### 概率与幅值

设 c_jk 是当前状态 j 下下一事件 k 的计数，c_k 是全局计数，n_j 是状态样本量，N 是总样本量：

\[
q_k^{\mathrm{global}}=\frac{c_k+1}{N+3},\qquad
q_{jk}=\frac{c_{jk}+q_k^{\mathrm{global}}}{n_j+1}.
\]

先对全局三事件做 Laplace add-one，再给各状态一个遵从全局分布的伪观测。稀疏或全局缺少的方向仍有正概率。

幅值只用首步归一化变化 |y_i,1|。负、正方向分别计算全局方向幅值均值 g_d；若某方向没有样本，使用全体非零首步变化的平均绝对值。若训练首步变化全部为零，两方向均用 1 作为回退。各状态幅值为：

\[
b_{jd}=
\frac{\sum_{i:s_i=j,e_i=d}|y_{i,1}|+g_d}
{c_{jd}+1}.
\]

实现将 b 截到严格大于 1e-4 的最邻近可表示浮点数。这里每个状态方向只加入一个全局方向幅值伪样本。计数和幅值不使用 scale² 权重，也不使用 y 的后 19 维。

### 固定起点上下文下的精确累计期望

用上述确定转移 T(j,k) 构造：

\[
P_{j\ell}=\sum_k q_{jk}\mathbf 1\{T(j,k)=\ell\},\qquad
r_j=-q_{j,1}b_{j,-}+q_{j,2}b_{j,+}.
\]

以 v_0=0 开始作 Bellman 递推：

\[
v_h=r+Pv_{h-1},\qquad m_{i,h}=v_h[s_i].
\]

q、b 与归一化单位在一个起点的 20 步内固定；未来状态按 P 演变。计算不采样、不进行未来上下文重估，也不导入 SMP 神经模型。当前实现是独立 NumPy 递推。

## 3. 实际合成核验

脚本：[source/check_stat_baselines.py](source/check_stat_baselines.py)。收据：[provenance/STAT_BASELINES_SYNTHETIC.json](provenance/STAT_BASELINES_SYNTHETIC.json)。

本次环境为 Python 3.12.14、NumPy 2.5.4；42 项检查、5,177 次标量比较全部 PASS，最大绝对误差 1.4210854715202004e-14。内容包括：

- 岭回归的独立正常方程梯度、无权训练均值/标准差、截距闭式解和不惩罚截距。
- 五个固定 alpha、极端尺度、常数特征、预测分批不改变训练标准化。
- 手工事件计数和方向幅值伪样本、缺少方向、全恒定训练、严格幅值下限。
- 九状态正确转移；独立枚举至五步的全部随机事件路径；独立计算所有九初态的完整 20 步确定性路径。
- 非法状态、事件符号不一致、非概率行和非法尺度等输入拒绝。

本次市场数据读取、确认读取和真实市场拟合均为 0，未导入 Torch。合成脚本默认只打印收据；可用 --output 写一个**尚不存在**的新文件，拒绝覆盖既有收据。例如在准备好必要 NumPy 环境后，从本研究根目录运行：
