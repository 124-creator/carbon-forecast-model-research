# SMP：模型定义、最近邻与可检验的贡献边界

本文件定义一个待实证检验的结构候选。**SMP（Signed Markov Propagation）是本实验的简称，不是已认证的原创算法名称。** 标准 Markov reward 递推、GRU、hurdle 似然、指数幅值分布和加权平方损失均不是本研究发明。是否存在可发表的方法贡献，须结合完整对照、结构消融和独立确认，见最终实验报告。

## 1. 科学问题与观察语义

问题是：在碳价历史较短、未来方向可能反转的条件下，要求全部预测期限共享一个可解释的未来符号／零龄过程，是否比直接输出彼此自由的多期均值更容易泛化？

报价记录为日期与价格 `(d_t, p_t)`。目标是其后第 1、5、20 个**观测步**的报价，不是固定 1、5、20 个自然日。任一模型都输出完整 20 期向量。评价起点限制为同年完整 H20，避免不同期限使用不同起点形成混杂。

`p_t-p_{t-1}=0` 只表示两个记录端点的净变化为零，不能解释为没有交易、没有信息或没有日内波动。缺失日期不补齐，同价记录不删除。模型没有交易级事件、真正的等待成交时间或未来日历间隔。

固定的 pre-2021 描述性诊断显示，各序列零净变化比例约 1%–12%，较长零串主要来自上海，因此采用年龄 `0/1/2+` 的小状态空间，没有扩张成长年龄或复杂连续时间强度网络。诊断仅给出结构可试的条件，未证明均值信号可预测或长期稳定。

## 2. 信息与尺度

所有神经模型、同条件消融和岭回归使用完全相同的历史 token：20 个报价增量除以发行起点的过去 60 增量 RMS、已观察日期间隔、当前尺度相对训练期尺度的对数、各历史 token 的上一非零符号和 capped 零龄，以及 EEX 已知历史的拍卖量、覆盖率和竞价者数量。

记过去尺度为 `s_t`，它只由 `p_{t-60:t}` 与事前训练前缀决定的下限计算。GRU 输入的是 20 个 token；这**不等于信息范围只有 20 步**。上一非零符号沿整个已观察前缀维护，尺度使用 60 个增量。训练期固定尺度与协变量标准化统计只使用清除区之前的训练价格前缀，不用验证或评价后缀拟合统计量。

所有神经输出 `m_{t,h}` 的单位为 `Δp/s_t`；预测价格是

\[
\widehat p_{t+h}=p_t+s_t m_{t,h}.
\]

本轮不使用跨市场实时供体。EU_REPORTED 的具体工具／币种／换月定义尚未充分认证，不硬设它与 EEX 具有一比一的共同均衡价。两个 EU ETS 相关序列也不能充作彼此独立的市场复制。

## 3. 单起点的有限状态过程

状态为最近非零符号 `ℓ∈{-1,0,+1}` 与 capped 连续零变化数 `a∈{0,1,2}`，编码

\[
z=3(\ell+1)+a.
\]

全恒定的足够长历史用中性状态 5。9 个名义状态中的 3、4 在正常研究起点不可达；参数数目报告为名义训练参数，不能把这些状态的合成梯度当作市场有效容量。

GRU32 将当前历史编码为 `c_t`。对每个未来源状态，模型产生三分类概率与两个正幅值均值：

\[
(q_0,q_-,q_+)(z,c_t)=\operatorname{softmax}(W_qc_t+b_q),\qquad
b_\pm(z,c_t)=\operatorname{softplus}(W_bc_t+b_b)+10^{-4}.
\]

零变化保持最近符号，零龄增加并截断为 2；负／正变化分别转移到状态 0／6，零龄重置为 0。三个分支的条件平均 reward 为 `0,-b_-,+b_+`，在整个发行向量中均使用发行时固定尺度 `s_t`。

给定本次发行的固定上下文，递推

\[
F_0(z)=0,\qquad
F_{h+1}(z)=q_0(z)F_h(T_0z)
 +q_-(z)\{-b_-(z)+F_h(0)\}
 +q_+(z)\{b_+(z)+F_h(6)\}.
\]

输出 `m_{t,h}=F_h(z_t)`。这是标准有限状态 reward 的条件期望计算。无采样推理是该模型类的计算性质，不构成新理论。

**精确性的范围仅限本模型。** `c_t` 在这次发行之后冻结；未来实际价格不会重新进入 GRU。真实下一起点会使用新的历史上下文，所以不能据此声称跨发行起点的条件期望必然满足 tower 一致性。这一有限闭合也会遗漏依赖更早未来符号或未来幅值的高阶结构；它不是对事件驱动未来 LSTM 的无损替代。

## 4. 学习目标与公平控制

除专门的标准化损失对照外，训练用原价风险：

\[
\mathcal L_{\rm point}
=\frac1{NH}\sum_{t,h}
\frac{(s_tm_{t,h}-\Delta p_{t,h})^2}{V_h^{\rm train}},
\qquad
V_h^{\rm train}=\frac1N\sum_t\Delta p_{t,h}^2.
\]

加上同单位的输出收缩 `α mean((s_t m)^2/V_train)`，α 只取事前固定的 `0,0.1`。它与局部尺度标准化误差 `mean((m-y)^2/h)` 的样本权重不同。这是普通加权最小二乘修正，必须由强基线共享，不能包装成 SMP 创新。

完整 SMP 另加权重 0.05 的一阶 hurdle NLL。原价绝对变化不超过 `1e-10` 的分支仅为 `-log q0`；负／正分支为 `-log q_sign + log b_sign + |Δp/s_t|/b_sign`。指数分布是辅助条件幅值模型，不是经济机制定律，也没有把概率评分改为研究主目标。

直接 GRU 加同样的当前状态概率／幅值头、同样的 0.05 NLL，但采用自由的 20 期均值头，用来排除“只是辅助监督改善表示”的解释。SMP 的 `no_aux` 则去掉这项似然，其余结构不动。

| 模型／消融 | 精确约束 | 要排除的替代解释 |
|---|---|---|
| SMP full | 9 个源状态分别条件化概率与幅值，联合全部 20 期风险 | 待检验结构假设 |
| no_clock | 对未来源状态的 age 维精确共享 q/b 参数 | 未来零龄传播是否有贡献 |
| no_sign | 对未来源状态的 sign 维精确共享 q/b 参数 | 未来方向状态是否有贡献 |
| pooled_mark | q 仍区分源状态，b 在所有源状态共享 | 状态与方向幅值的耦合是否有贡献 |
| iid_state | q/b 在所有源状态共享 | 收益是否无需未来状态演化 |
| one_step | 网络与 full 相同，主损失仅 h1 | 多期风险训练是否有贡献 |
| no_aux | 网络与 full 相同，NLL 权重为 0 | 辅助似然是否解释提升 |
| GRU native／normalized | 同一骨干与输入，分别用原价风险／旧式标准化风险 | 普通损失加权是否解释提升 |
| GRU aux | 直接多期均值头加同样的当前 hurdle 监督 | 常规辅助学习是否足够 |
| LSTM native | 同输入、同预算、同原价风险 | 完整循环骨干对照 |
| PatchTST native | 固定作者核心、相同多通道输入、公开任务读出适配 | 常规 Transformer 对照 |
| 岭回归 | 同 token 展平、训练标准化、原价尺度平方加权 | 普通线性模式是否足够 |
| Markov counts | 同 9 状态，平滑计数／幅值估计，NumPy 精确传播 | 常规同状态统计模型是否足够 |

`no_clock/no_sign` **保留当前输入中的年龄／符号**，只约束预测内部的未来状态作用，不能解释为完全删除当前相关信息。`one_step` 只删高期限的训练梯度，早停仍用所有模型共同的 h1/5/20 验证指标，因此不能称为完全没有多期验证信息。

## 5. 训练、选择与证据范围

每序列在每个年度起点之前单独训练，冻结权重后发行该年的滚动预测。最后 80 个成熟起点用作验证，训练起点的最大 H20 标签必须严格早于第一个验证起点；所有验证标签必须早于年度评价开始。此刷新协议区别于前轮在线更新研究，故不将旧 RRC/SOLID 的数值与本轮直接排名。

每个神经配置均从精确 RW 点均值开始，独立以自身最终发行输出选择完整检查点。所有模型早停与局部岭回归选择使用验证 h1/5/20 原价 MSE/RW_MSE 等权；训练主目标通常用全部 20 期，二者明确分开。

2022 是第一阶段开发筛选，2023 的多种子复核是否启动由事前资源门决定。所有这些年份都已经在项目中暴露，不构成真正未见确认。若复核再通过点风险、同条件结构对照和事先规定的相关性区间规则，才会冻结单独的 EEX 2024/2025 确认方案。本文件不表示已经运行后续阶段。

资源门里的 1%、2% 等数字是本研究为控制后续计算设定的阈值，不是期刊通用接受标准。基于重叠预测起点得到的行数不能当作独立样本量，三个随机种子也不能当作三个新市场。

## 6. 一手最近邻与实际执行层级

- Türkmen 等，*Forecasting intermittent and sparse time series: A unified probabilistic framework via deep renewal processes*，PLOS ONE 2021，DOI [10.1371/journal.pone.0259764](https://doi.org/10.1371/journal.pone.0259764)。读方法及作者指定 GluonTS 核心。其需求支持域与事件驱动 LSTM 不直接等同于 signed 碳价净变化；本轮没有执行作者 MXNet 类或复现其 benchmark。
- De Brouwer 等，*GRU-ODE-Bayes: Continuous Modeling of Sporadically-Observed Time Series*，NeurIPS 2019，[正式论文](https://papers.nips.cc/paper_files/paper/2019/file/455cb2657aaa59e32fad80cb0b65b9dc-Paper.pdf)。读官方论文、固定 MIT 作者核心；没有执行该作者模型。已存在跨维异步观测更新，故不把共享隐藏状态本身当新方法。
- Schirmer 等，*Modeling Irregular Time Series with Continuous Recurrent Units*，ICML 2022，[正式页面](https://proceedings.mlr.press/v162/schirmer22a.html)。读方法边界，未完整审查／执行作者代码。
- Nie 等，*A Time Series is Worth 64 Words: Long-term Forecasting with Transformers*，ICLR 2023，[作者预印本](https://arxiv.org/abs/2211.14730)。沿用项目中已固定并核验的作者 PatchTST 源；本轮确实在统一任务适配内重新训练该核心。相同多通道输入、`RevIN=False`、新 `C→1` 读出均已公开，不声称重现作者原始 benchmark。

逐来源实际阅读层级、访问限制、代码版本与许可证保留在 `literature/`。有限检索不能证明不存在任何同类模型。当前能够提出的贡献问题是“有限的未来方向／零龄结构在同信息、同原价风险下是否具有可重现的泛化收益”，而不是“首创 Markov 数学”或“神经模块组合即创新”。
