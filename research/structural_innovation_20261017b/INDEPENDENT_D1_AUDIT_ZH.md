## 结论

**审核通过，模型晋级失败。** 独立程序完整读取了本轮 160 个预测文件，重算所有 20 个期限的指标，并独立重做 2022 年配置选择。它与主程序在全部选择和四项晋级判断上完全一致。SMP full 总分为 **1.3237867710853686**，未通过 D1；本次决策不触发 D2、市场数据 bootstrap 或确认集评估，也不改变事前门槛。[指标收据](audits/D1_independent/METRIC_AUDIT.json)、[独立选择](audits/D1_independent/SELECTION.json)、[交叉核验](audits/D1_independent/SELECTOR_AGREEMENT.json)和[停止收据](audits/D1_independent/STOP_DECISION.json)保留了完整证据。

独立程序核对每个预测文件的 SHA256、任务与协议身份、全部 20 期 MSE、RW MSE、相对 MSE、MAE，以及 h1/h5/h20 主分数；核对配置间日期、原点、基价、尺度、状态和目标数组完全一致；核对支持收据的训练成熟、验证成熟、purge、数据来源 SHA 和年度边界；并利用保存原点之间重叠的未来标签检查内部一致性。它读取了每任务的 METRICS、SUPPORT、STARTED，另读取 150 份 FIT 收据。[冻结审核程序](source/independent_results.py)仅依赖 NumPy 和标准库，不导入主选择器、生产指标函数、Torch 或训练器。

此次独立审计未重新加载原价 CSV，未读取训练权重，未执行市场拟合，也未读取 D2 或确认文件。因此 PASS 的含义是保存预测、指标、共同支持和选择流程一致；它不等于从原始价格及全部权重重新验证训练全过程。主模型和生产管线的合成检查由独立的数学审核材料覆盖。

## 事前规则与实际停止原因

D1 评价年为 2022，神经模型种子为 17。每族按五序列、h1/h5/h20 各格的相对原价 MSE 等权平均选配置；精确同分偏向更大的候选值。神经模型 shrink 候选为 0 和 0.1。所有神经族均选择 0.1。ridge 全局选 100；ridge_val 分别只依据年度开始前的验证分数选择参数：EEX、广州、湖北为 100，上海、EU_REPORTED 为 10。验证分数同样是 h1/h5/h20 各格相对 RW 的原价 MSE 等权平均，须与多数模型的全 20 期训练损失区别。[正式协议](provenance/PROTOCOL.json)

| D1 冻结晋级条件 | 实际比较 | 结果 |
|---|---|---|
| full < RW | 1.3237867711 < 1 | 不通过 |
| full < 同 shrink 的 iid 消融 | 1.3237867711 < 1.3384011070 | 通过 |
| full < 同 shrink 的 one_step 消融 | 1.3237867711 < 1.0350920473 | 不通过 |
| full ≤ 1.02 × 预定基线族中最优者 | 1.3237867711 ≤ 1.0442659332 | 不通过 |

八个预定基线族中最强者是平滑 Markov，分数为 1.0237901306。该基线是标准统计对照，不是本研究的创新模型。四条件须全部成立，实际仅一项成立，故按协议停止。此处没有 D1 显著性检验或事后改变比较对象。

选择与审核所用指标全部来自 2022 开发阶段；它们不能充当独立确认结果。EU_REPORTED 与 EEX 也不是独立市场样本，不能据五序列平均值构造 IID 跨市场置信度。保留全部候选结果，不能只发布某个较好的市场或期限来替代冻结总指标。

## 复算命令

从研究目录运行。目标输出目录或文件必须尚不存在；现有结果不会覆盖。对新的完整重放，可用新的目录名替换示例中的 D1_independent，并在第二条命令中同步替换。

```bash
python -B source/independent_results.py \
  --protocol provenance/PROTOCOL.json \
  --phase D1 \
  --output audits/D1_independent

python -B source/compare_independent_selection.py \
  --independent-dir audits/D1_independent \
  --root-selection results/D1_SELECTION.json \
  --output audits/D1_independent/SELECTOR_AGREEMENT.json
```

第一条读取当前隔离工作区的完整 D1 预测和收据，不训练模型。第二条只读取两套已生成的聚合选择及独立重算指标。需要实际 D1 预测文件才能重算指标；公共包仅包含聚合和哈希，不包含 EEX 逐点价格或预测。D1 不通过后即停止，后续阶段没有本轮门槛授权。
