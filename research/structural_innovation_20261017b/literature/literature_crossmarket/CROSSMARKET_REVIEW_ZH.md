# 异步跨市场碳价预测：一手文献、作者源码与创新性审查

研究时间：2026-10-17。范围：EEX EUA 一级拍卖与 EU_REPORTED 的历史信息，以及不依赖同日发布时间的跨序列预测。状态：文献和源码审查；本阶段未读取价格 CSV、预测 NPZ、模型权重或确认区，未导入或运行模型，未增加实验网格。

## 1. 结论与可执行取舍

**跨序列历史信息有研究价值；本次有界核查没有找到足以诚实宣布为新算法的独立学习约束。** 建议保留一个信息增量问题：在严格排除其他序列同日记录后，EEX 与 EU_REPORTED 的过去观测，是否在相同支持、训练预算和预测目标下提供目标自身历史之外的信息。这个问题可以支持新的实证发现，但“加入供体价格”“共享一个连续隐状态”“用时间间隔调节更新”本身不足以构成方法创新。

只选一个完整已发表主线 **GRU-ODE-Bayes**；以 **CRU** 和一篇神经协整预测论文作为必要近邻，不提出三个待训练候选。GRU-ODE-Bayes 已明确让一个被观测维度的信息改变未被观测维度的预测。CRU 已将神经编码、观测不确定性和连续离散 Kalman 状态更新组合起来。神经网络与误差修正项的组合也已有早期论文。因此，普通神经 ECM、共同价格状态、时间衰减、正值噪声参数化、缺测门控或跨市场共享训练，均不能直接登记为本轮原创机制。[P1–P3]

这不是“证明不存在新方法”。检索范围刻意有限，结论是：**当前提出的机制尚未越过已核实直接近邻，不能仅靠命名或新数据宣布原创。**

## 2. 价格定义先决定能施加什么约束

EEX 的既有冻结范围是官方成功 EUA 拍卖，随后附录限定 T3PA。一天多场时按实际拍卖量加权清算价；这不是二级市场每日收盘价。EU_REPORTED 的既有来源说明则明确：具体工具、交易场所、币种、滚动规则尚未充分核实。[D1–D3]

这个差异有明确而有限的影响：

- **允许**将 EU_REPORTED 原名保留为历史统计供体，检验其滞后信息是否有预测增量。
- **不支持**直接设定“两列就是同一 EUR/tCO2 资产价格”，或把价差必然平稳、固定一比一关系、无套利回归速度当作已验证经济结构。
- **不支持**把跨序列相关性或共同隐变量命名为已识别的“共同公允碳价”“价格发现”或因果传导。
- EEX 与 EU_REPORTED 相关于同一 EU ETS 环境，不能作为两个独立市场重复增加统计证据。

元数据还显示，既有 EU_REPORTED 全来源止于 **2024-03-27**；截至 2023 年的开发文件有 1,515 条。若不另行获取、冻结新的供体来源，2025 年 EEX 预测只能使用陈旧供体或此前学到的迁移关系，不能声称使用了 2025 年实时跨市场报价。[D1,D2] 本审查没有为验证这点打开任何价格文件，也没有打开 EEX 2024/2025 确认报价。

### 3.1 主方法与作者实现

P1 的主结构是连续隐藏状态与有观测时的跳跃更新。用统一符号表示：

\[
\frac{dh(t)}{dt}=(1-z_\theta(h(t)))\odot
\bigl(g_\theta(h(t))-h(t)\bigr),\qquad
h(t_k^+)=\operatorname{GRU}_\theta\{h(t_k^-),u_k\}.
\]

观测编码使用值、掩码和当前预测；解码器输出各维的高斯均值和方差。观测前负对数似然监督预测，论文另以观测后分布接近贝叶斯更新分布的 KL 项监督状态更新。已有隐藏状态可把某维的新信息传到另一维。[P1]

固定作者源码为：

- 仓库：[edebrouwer/gru_ode_bayes](https://github.com/edebrouwer/gru_ode_bayes)。
- 提交：[ddd0b34e884dbee1c09b6a3927d1e9ab10443af8](https://github.com/edebrouwer/gru_ode_bayes/commit/ddd0b34e884dbee1c09b6a3927d1e9ab10443af8)，提交时间 2022-05-26。
- 许可：该提交的 MIT [License.md](author_gru_ode_bayes/License.md)，已连同作者版权声明保留。

### 3.2 一项必须公开的论文与代码差异

论文 §2.4 定义：

\[
p_{\mathrm{Bayes},j}\propto p_{\mathrm{pre},j}p_{\mathrm{obs},j},
\qquad
L_{\mathrm{post}}=\sum_jm_j
D_{\mathrm{KL}}(p_{\mathrm{Bayes},j}\Vert p_{\mathrm{post},j}).
\]

作者固定源码的主类 NNFOwithBayesianJumps 调用 compute_KL_loss。该函数把当前模型均值/标准差传为 gaussian_KL 的第一个分布，把观测及默认标准差 0.01 传为第二个分布；函数体的公式确实是第一个分布对第二个分布的 KL。因此该分支实际约束为：

\[
\sum_jm_j D_{\mathrm{KL}}\{
p_{\mathrm{post},j}\Vert\mathcal N(y_j,0.01^2)\}.
\]

这既省略了完整先验融合，又反转了论文写出的 KL 方向。论文提及小观测噪声下可用观测分布近似后验，但该近似本身不解释方向反转。[P1；作者 models.py 中 compute_KL_loss 与 gaussian_KL]

如果以后运行，必须提前选定“忠实固定代码”还是“忠实论文公式”，并把另一种列为明确的复现差异。此处只做静态算式核对，没有执行损失函数；**纠正这一差异不能登记为本研究原创模型。**

### 3.3 对本数据任务的真实适配缺口

1. **预测时间定义不同。** 连续时间路径方法通常预测给定未来日历时间处的值。本任务 H=1/5/20 是未来第若干条报价，未来实际日期不一定已知。把测试记录的真实未来日期交给求解器，或事后从预测曲线按该日期取值，不等价于在起点已经给出的 H20 事件预测。若改为由当前状态直接输出事件步长向量，应声明这是新的任务适配层，不能说原作者模型天然满足同一任务。
2. **原始管线不能直接移植为金融时间切分。** 已读的 ODE_Dataset 支持轨迹 ID 与 T_val，collate 组织时间、掩码和验证观测；作者原数据预处理脚本和完整实验流程未全部核查。这里没有证据说它自动满足本项目的年度冻结、完整 H20 标签成熟和窗口隔离。
3. **代码依赖与时点数值处理需要显式兼容工作。** setup.py 未锁版本，旧数据辅助函数使用 np.int/np.bool；README 要求另装修改版 torchdiffeq。固定 Euler 步长在非网格观测时刻可能跨过目标时点；extract_from_path 有最近网格时刻映射。这些是运行前应固定、审核的数值/接口问题，不是模型创新，也不据此推断它一定有价格泄漏。
4. **隐藏状态有界不是无条件价格趋势理论。** 固定有限权重的连续解码器作用于有界状态，其均值输出也有界。这不能在全时间域表示无界随机趋势；有限样本仍可能近似得很好。采用锚定、标准化或增量输出能改变实际适配，但这些常用处理不能单独充当原创贡献。此结论是对已读源码的数学推论，不是对碳价成绩的推断。

## 4. 不假定同日发布顺序的准确因果规范

令 A 为目标序列，其第 n 个已知报价日期为 q；B 为供体。预测在 A 当前报价已知以后发出，信息集合定义为：

\[
\mathcal F^A_q=
\sigma\!\left(
\{(d,A_d):d\le q\},
\{(d,B_d):d<q\}
\right).
\]

对多供体，对每个非目标序列都使用严格小于号。最后一个可用供体日期与陈旧度为：

\[
s_B(q)=\max\{d_B:d_B<q\},\qquad
a_B(q)=q-s_B(q).
\]

没有历史供体时，保留缺失掩码；陈旧度不能假装为零。最后一个历史值可以作为“此前观测值”输入，但不能日历补齐成一串新的真实报价或零收益事件。

实现上应保留一个只处理所有日期严格早于 q 的公共状态；当前 q 的目标报价只在该目标视图中更新。**不能先把 q 当日 A、B 都写入共享状态，再从这个状态为 A 发出预测**。这样即使文件排序稳定，也使用了被规范排除的 B 同日报价。并发目标可以各自从日期前状态建立视图；各目标预测完成之后，才可把当天观测加入下一日期的公共历史。

H20 向量只能依赖上述信息集合。目标未来第 n+h 条报价的真实日期、未来交易间隔、未来供体是否到达、未来实际拍卖量、未来封存数据的归一化统计，都不能作为起点输入。只有在另一份事先冻结协议明确允许、且能证明起点已发布的日历信息，才可能改变这个边界；本次没有使用这种信息。

这个规范保证“不使用其他序列同日或以后记录”的离线比较。它**不自动证明**历史数据库的每个日期标签对应实时公开版本：时区、迟报、修订等仍需原始发布记录才能认证。因此可以称为“严格日期过滤的历史预测”，不冒称逐时点数据版本已经完全重建。

## 5. 为什么几种直觉约束还不够原创

考虑常见共同趋势模型：

\[
Y_t^{(i)}=\lambda_i C_t+B_t^{(i)}+\epsilon_t^{(i)}.
\]

其中 C 是共同非平稳成分，B 是平稳基差。即便忽略数据口径，尺度变换 C'=cC、λ'=λ/c 也不改变观测；如果没有额外约束，B 还可以吸收共同成分。命名一个隐藏维度为“共同价格”并不能完成识别。把短期漂移改成神经网络，或在

\[
\Delta Y_t=\alpha\beta^\top Y_{t-1}
+\sum_{\ell=1}^{p}\Gamma_\ell\Delta Y_{t-\ell}+\varepsilon_t
\]

中用神经网络表示系数或非线性项，是神经误差修正的大类，不应在缺少进一步差异时重新宣布为新模型。[P2,P3；上述识别说明为本审查的推理]

| 拟议改动 | 它真正增加什么 | 本次判断 |
|---|---|---|
| 对供体使用严格历史日期、年龄和掩码 | 改正可用信息范围 | 必要实验规范，非新学习规则 |
| 一个共享状态，供体观测后更新目标预测 | 相关多变量的信息融合 | P1 已明确实现这一作用 |
| 神经编码器、共同连续状态、可学习噪声 | 非线性观测映射和不确定性权衡 | P2 属于直接近邻，不能复活旧 learned-Kalman/RKN 并改名 |
| 价差进入神经漂移、对均衡偏离施加回拉 | 误差修正归纳偏置 | P3 已证明神经网络与协整组合有先例；本数据还缺工具认证 |
| 强制同日更新对顺序不敏感 | 集合观测一致性 | 贝叶斯独立观测融合/集合编码已有这一性质；本身不足以原创 |
| 无新供体时不重复同化、重复记录不改变状态 | 事件去重与缺测正确性 | 属于正确实现 |
| 对供体做差分、标准化或量纲不变处理 | 改善尺度与趋势适配 | 普通预处理，不是新模型；也不能补足资产身份 |
| 共享预训练后转移目标参数 | 学习历史共同表示 | 可检验迁移收益，但需与实时供体信息分开 |

因此，本次不提出新模型名称，也不把上述约束登记为候选算法。若未来出现一种新规则，至少需要写清：相对于 P1/P2 或明确线性状态模型改变了哪个学习算子、该改变为什么不等价于已有滤波/集合编码/ECM，以及移除这一约束而保留相同信息和预算时应出现什么可证伪差异。

## 6. 如继续做一个信息增量实验，最少需要哪些对照

下表是以后协议应解决的因果归因问题，**不是本次授权训练或待扫参数表**。本次不新增成绩阈值，也不沿用旧 RRC 门槛为这个方向背书。

| 对照 | 保持一致 | 它排除的替代解释 |
|---|---|---|
| 目标自身历史模型 | 同目标、支持、输出 H20、时间切分、预算 | 改善是否仅来自增加模型容量或重训 |
| 线性 ARX / ridge，使用同样的供体过去值、增量、年龄和掩码 | 与新模型完全相同的可用信息 | 普通线性外生信息是否已解释收益 |
| 共享训练但预测时没有活供体输入 | 同训练数据、同目标头和预算 | 历史迁移与实时跨序列更新是否混淆 |
| 只保留供体日期、年龄和掩码 | 相同观测日历 | 改善是否来自报价频率/缺测模式而非价格 |
| 移除新约束但保留同一状态架构和供体信息 | 同参数量或明确的匹配预算 | 所声称的新学习约束是否必要 |
| 若采用共同趋势/ECM结构：相同观测的线性状态或误差修正模型 | 相同输入、尺度和成熟标签 | 神经化是否比已知结构本身多出作用 |

若选择 P1 作为具体神经基座，应先冻结第 3 节的代码/论文损失选择、事件目标桥接与数值求解适配。全量训练前用合成时间标签检查严格小于关系、同日顺序、没有供体和标签成熟等行为；本阶段没有运行这些检查或模型。

模型选择只可用已暴露的开发材料。2023 已用于机制开发和筛选，不能重新命名为独立确认。EEX 2024/2025 仍保留现有封存状态；本次未读取它们，不能为了挑跨市场方向先查看其表现。统计比较应处理时间与重叠期限相关性，也不能把相关的 EU/EEX 当作独立抽样单位。

## 7. 明确的失败与停止条件

出现以下任一情况，就不能推进相应创新主张：

1. 严格排除同日供体后，所谓跨市场效果不再存在；这时不能恢复同日输入挽回成绩。
2. 匹配线性外生变量模型已解释收益，新增学习约束没有稳定的独立作用。
3. 只有共享训练有用，而预测时的供体报价没有信息增量；此时结论应归于迁移，不能称为实时信息传播。
4. 年龄/掩码对照已解释效果；此时应研究观测过程，不能把结果解释为碳价发现。
5. 优势依赖事后提供未来报价日期、未来供体到达模式或未来尺度。
6. 模型仍只等价于标准 ECM、连续状态滤波或集合更新；新名字、少量额外参数或修正原作者代码差异不能补足原创性。
7. 主张需要同一工具、币种或固定价差的身份条件，而来源仍无法证实；这阻断相关经济解释，但不阻断如实标注的统计供体测试。
8. 2025 没有新鲜供体却声称验证了实时跨市场机制，或重复使用已经看过的期间作为“未见”确认。

本次审查支持继续提出清晰、可证伪的研究问题；**不支持现在声称已有一个达到发表标准的新学习算法。** 不开启确认、不运行模型，也不恢复已停止的 RRC 或残差效用检索路线。
