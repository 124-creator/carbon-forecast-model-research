# 独立模型与训练管线审查

**审查结论：已核验的数学实现、目标窗口、成熟时间、训练期尺度和价格信息隔离均通过；这些结果允许执行已固定的有限开发实验，不构成原创性或市场预测有效性证明。**

本审查由独立于模型实现的审阅过程完成。拟合前阶段只读取代码、协议和来源审计文档，只对合成数据执行拟合；正式实验完成后，另从已保存权重进行不计算市场评分的数值重放，详见第六节。没有读取真实市场预测分数，没有打开既有 EEX 2024–2025 确认集，没有修改真实来源价格。审查发现的问题由实现者修复；审阅者未改动 `model.py`、`pipeline.py` 或 `run.py`。

可执行审计及机器结果为 [model_review.py](audits/model_review.py)、[model_review.json](audits/model_review.json)、[pipeline_review.py](audits/pipeline_review.py)、[pipeline_review.json](audits/pipeline_review.json)。后两者保留执行当时的旧代码指纹；最终仅对修复后的模型重跑数值审计，没有重复追加市场或合成拟合来刷新指纹。

## 1. 数学与数值核验

最终核验的 `model.py` SHA-256 为 `01da25349d1e0a18778b6b1a5ab2cf2c0cb4dad77ef80f2faad294f493e3ef37`。

| 核验项 | 独立方法与结果 |
|---|---|
| 条件均值与方差 | 用逐步状态递推及方差/协方差递推，独立复算候选模型的二十步条件对数均值、方差和逐条样本价格；最大价格差约 2.84×10⁻¹⁴。 |
| 自由路径对照 | 用逐日累计共同因子和独立创新，独立复算 `FreePath`；最大价格差约 2.84×10⁻¹⁴。 |
| 解析原价均值 | 复核 −V/2 方差补偿及 E[P]=P₀exp(M)；32,768 个独立 scramble Sobol 节点的数值积分相对误差，候选最大 7.41×10⁻⁶，对照最大 6.11×10⁻⁵。这是积分检查，不是无偏性检验。 |
| 累计窗口 | 构造明确的二十步数列，确认 h=1/5/20 取未来索引 1…h，窗口不含起点；P 取末端，H/L 分别取实际累计最大/最小，未误用 close 极值。 |
| 有限分布 ES | 用四个样本手算包含对角线的双重距离和，与代码 V 统计一致至 2.23×10⁻¹⁶；重复样本情况下梯度有限。 |
| 消融标签 | 改动 h=5/20 真值不改变一步梯度消融的训练损失；改动未来 H/L 真值不改变 `state_price` 的损失。 |
| 几何约束 | 合成样本 P>0、H≥L>0；累计 H 非减、累计 L 非增。没有施加 P 被 H/L 包含的约束。 |
| 数值护栏 | 极端输入确实触发状态模型和 GRU 护栏计数；runner 对正计数硬失败。较大初始半径 100/1,000 不再被逆 softplus 的无必要上界裁断。 |

解析均值属于未裁剪的连续高斯模型；ES 对有限积分样本分布精确计算。有限积分点无裁剪不能证明连续高斯尾部无越界概率。二者的定义差别已写入方法说明，不能声称裁剪后连续分布仍具有同一个精确均值。

零初始范围仍用 10⁻⁵ 的有限逆变换代理。未来 softplus 范围没有零宽度原子，无法精确表达来源中的零宽度质量，这是模型局限，不能通过删除零宽度真值消除。

## 2. 时间与信息流

静态审查与合成后缀扰动检验均确认：任何起点的输入只依赖该起点及以前记录；起点当前值属于已观察历史，不是未来标签。将测试起点及之后的全部 P/H/L 改动，不改变更早输入，也不改变拟合好的训练期 scaler 和损失分母。

测试首起点为 a 时，选择训练最后一个 h=20 标签为 a−121，验证首起点为 a−120；最终训练最后一个标签为 a−1，测试首起点为 a。合成实例 a=1,100 得到 979<980、1,099<1,100。一步消融使用同一个二十步成熟训练池，不能因标签较短而获得更多起点。

均值、标准差、价格与范围分母均只从相应训练起点池拟合。最终重训可以使用当时已经成熟的验证区标签，并重新拟合该训练池的固定尺度；这个过程不访问测试标签。滚动测试时可以更新已观察历史输入，但不在测试段更新模型参数。

价格专用 GRU 在模型中屏蔽历史后七通道，两个 context 均只依赖历史 P。进一步任意改变全部 H/L/Open/Volume 后，价格专用的输入、context、尺度和预测逐位不变。`state_price` 则保留全部历史输入，只去掉未来范围监督，两者用途不同。

通用 ES 的 mask 是投影乘法，不能自动消除 NaN，因为 0×NaN 仍是 NaN。本轮来源加载器要求 P/H/L 有限且完整，`OriginData` 再断言所有目标有效，所以该局限不在本轮路径中触发。若将来加入缺失标签，需要先写入有限占位值并明确缺失机制；不能直接把现在的 mask 当成完整缺失数据模型。

## 3. 审查发现与已修复项

首次审查发现 resume 只检查代码与预测哈希，没有比较当前数据字节，也没有验证神经模型 checkpoint。当前实现已增加输入 SHA-256 对照和每个 checkpoint 的回执哈希检查，输入变化或文件不匹配会拒绝恢复。

首次审查还发现 GRU 点模型有数值裁剪却不返回计数。当前模型已返回计数，统一由 runner 硬失败；最终独立审计用极端输入确认该分支可触发。逆 softplus 的上界 30 已移除，仅保留公开说明的零范围有限代理。

验证同信息基线按 `gru_full`、`ridge_full`、`hgb_full` 的验证分数选择，不能看测试最低者。首次实现的完全同分结果可能受并行任务完成先后影响；当前代码已修为按 `(验证分数, 模型名称)` 的固定顺序破同分，审阅者已只读核实。

## 4. 合成预检的完整账目

完整账目见 [SYNTHETIC_PREFLIGHT_LEDGER.json](audits/SYNTHETIC_PREFLIGHT_LEDGER.json)。实际共执行 **16 次合成拟合调用、每次固定 10 轮、每次 150 个优化步，共 2,400 个优化步**。这些调用不计入真实市场预定的 84 次选择拟合和 126 次最终模型构建。

第一次八次拟合使用两种生成器、四种模型。正控制让持续状态 z 同时进入当前范围坐标和下一步有符号价格变化；负控制最初使用零均值高斯对数收益。后者是 log-price 鞅，但由于指数变换的 Jensen 项，原价格不是严格鞅。发现后，负控制加入固定 −0.5×0.01² 的对数漂移校正，成为 E[Pₜ₊₁|历史]=Pₜ 的真正原价鞅；同一脚本完整重跑八次，所有模型设置、轮数、学习率、种子和正控制定义均未改变。没有根据预检分数调模型或成功门槛。

每个调用都通过有限前向/反向、真实优化步数、保存解析均值、原始真值和目标索引以及保存回执哈希检查。修正后，候选在正控制的 h=1/5/20 描述性 MSE/RW 为 0.927/0.768/0.729，在原价鞅上为 1.003/1.024/1.242。所有正控制中的完整信息模型都能学习到人为植入的信号；候选与 `state_price` 非常接近，因此这个预检尤其不能用来证明未来范围辅助监督的独特价值。鞅上的有限样本误差也不能解释为发现或否证市场普遍可预测性。

该预检只要求管线可运行及信息流符合定义，不要求任意模型在单次随机实现上胜出。没有保留最佳合成种子或把合成指标并入真实市场主表。

## 5. 协议与解释边界

主指标口径已核对为：先等权平均三个种子的解析预测，再算每个 source×fold×h 的原价 MSE；每单元除以同起点 RW MSE，再等权平均 18 单元。比较其他模型也先计算对应单元误差比，再等权平均，不能以两个总体 R 相除替代。验证选定的点基线与测试最优基线是不同对象，协议只使用前者。

一步模型只在训练梯度中使用 h=1；它的轮数/学习率仍按三期限验证 MSE 选择，协议已正确称为“一步梯度监督”，没有声称完全不接触较长期限标签。轮 0 可以被选中，最终模型构建与实际梯度拟合次数必须分别报告。

ES 是次指标。每个 seed 独立计算有限分布 ES 后平均，不等于三 seed 混合分布的 ES；协议已明确。所有主成功门槛仍要求价格 MSE，不能用范围有序率、概率评分或某一来源的局部胜出替换。

`FreePath` 的共同因子协方差不是状态模型 AR 创新的严格超集。其参数更多，只能作为一项强结构对照，不能由单次比较唯一识别状态机制。辅助范围、边际联合评分和一步梯度消融需要共同解释。当前实现整体属于已知状态空间、变换及辅助监督组件的一次受限实证研究，尚无原创性认证。

协议提出配对移动块 bootstrap，并保留非平稳及跨折训练依赖的局限。对独立评分器 `score_independent.py` 的交叉代码审查进一步确认：`relative_cells` 先取逐单元候选/对照误差比；`comparisons` 再等权平均三个期限与六折；每次 bootstrap 用相同的起点计数矩阵绑定全部模型和期限；`energy_v` 的 `pdist` 无序对距离和除以 S² 恰好是 V 统计双和的二分之一；五组成功门槛及其置信区间要求与协议一致。此步骤只读代码，没有执行真实市场评分。

最终评分过程仍需实际从原始序列重构真值、核对所有文件回执，再计算主表和 bootstrap；不能把代码审查通过当成未执行的最终数值评分已经通过。

冻结方式为实际拟合前的本地 Git 提交，完成全部实验后连同结果提交一并上传。这可以形成可核验版本链，但不冒称在外部服务提前公开登记的独立预注册。

## 6. 全部正式模型完成后的权重重放

正式 runner 完成全部 72 项任务后，运行 [replay_checkpoints.py](audits/replay_checkpoints.py)。脚本在读取观测前强制检查全部 72 项任务回执、126 个神经 checkpoint、156 个预测文件和六折 manifest 已齐全。然后对每个 checkpoint 独立从本折已成熟最终训练池重新计算 scaler 与损失分母，从保存权重恢复模型，重放该测试折的首、中、末三个起点。

全部 **126 个 checkpoint、378 次起点重放通过**。比较 1,134 个解析均值，最大绝对差为 1.4211×10⁻¹⁴；比较生成模型的 311,040 个累计摘要样本值，最大绝对差为 4.2633×10⁻¹⁴。五类预处理状态及分母重算差均为零，所有数值护栏计数为零。输入数据、代码、checkpoint、预测和回执哈希均核对一致。

公开结果为 [REPLAY_AUDIT.json](audits/REPLAY_AUDIT.json)，只包含标识、哈希、计数与最大数值差，不包含逐条价格、预测或样本。重放没有计算市场 MSE、选择模型或追加训练；它验证保存文件可由对应权重及训练期预处理重现，不代替独立评分，也不证明预测有效性。
