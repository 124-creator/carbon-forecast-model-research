# 报告价格与累计范围联合学习：一次有限开发实验

**状态：在本轮真实市场拟合及测试分数计算前固定。协议不是原创性认证。** 2026-10-19（北京时间）；UTC 日期为 2026-10-18。本地 Git 冻结的代码、数据字节指纹和协议在完成实验后一起上传；这不冒称外部独立预注册。

## 1. 目标与停止规则

延续既有项目的价格点预测目标。唯一主假设是：在相同历史信息下，低维随机状态生成器利用未来累计报告高低价的联合监督，能否改善报告价格 P 的样本外均方误差。h 固定为未来 **1、5、20 条观测记录**。Quantum 缺日期，不能把这些期限叫日历日，也不能认证为连续交易日。

已有文献覆盖状态展开、ES、变换评分、max/min 摘要、OHLC 变换及普通多任务学习。因此模型暂称 `summary_state`；不将这些组件重新命名为原创理论。九维摘要不识别完整二十步路径分布。模型估计的是报告数字的条件分布，不是潜在有效价格、订单簿或可交易报价。

本轮完成下述全部预定比较后停止。不根据测试结果追加结构、调参、源数据、期限或删样本。失败时保留全部结果；不能用范围预测、概率评分改善替换价格 MSE 成功。不打开 2024/2025 价格确认集救分。

所需条件仅为 P>0、H≥L>0。坐标 d=log(sqrt(HL)/P)、q=0.5log(H/L)≥0 精确还原 H=P exp(d+q)、L=P exp(d−q)。不要求 P 在范围内，不夹紧 P、不改 H/L、不删除越界行。

设测试首起点 a。选择阶段：训练起点 [60,a−140)，验证起点 [a−120,a−20)。训练最晚标签 a−121，早于验证首起点 a−120；验证最后一个 h=20 标签为 a−1。最终重训使用 [60,a−20)，最晚标签 a−1，严格早于测试起点 a。每折参数固定，测试时只更新历史输入；不在测试段做梯度更新。下一折可以使用当时已经成熟的上一折标签，属于扩展窗口评估。

所有模型共同使用完整成熟的二十步标签训练起点池。`state_step1` 仅 h=1 产生训练梯度，但统一使用验证段 h=1/5/20 的主 MSE 选择轮数／学习率；故它是“一步梯度监督”消融，不能称完全只接触一步标签。

## 4. 输入、尺度与模型

历史窗口20条。八通道：P的对数收益、d、q、log(O/P)、log(1+V)变化、O可用掩码、H/L可用掩码、V可用掩码。前四通道除以起点过去60条P对数收益样本标准差 s；s 限于 [0.003,0.2]，输入数值再限于 [−10,10]。两项context只用P：log(s/0.02)与过去20条收益和/(s sqrt20)。连续输入的均值/标准差只由本折相应训练起点拟合；训练和预测用同一组固定尺度。

报告价格损失以训练期 RW 误差 RMS 按期限标准化；范围损失以训练期 (未来范围−当前P) 的 RMS 标准化。所有分母下界为训练起点P均值的0.001倍；最终重训重新只在最终训练池拟合。价格和范围单位保持源数据单位，不做跨来源单位拼接。

候选模型：GRU16 编码历史，输出13个有界/正参数；一个条件AR(1)高斯状态驱动二十步对数价格和 d/q 的条件响应。对数价格逐期限作条件高斯方差补偿，直接计算原价格解析均值 E[P_h]；训练 MSE 不用有限模拟均值。日级 P/H/L 样本经真实 cummax/cummin 生成九维 (P_h,U_h,L_h) 摘要。精确参数化、方差及损失见 `model.py`、`METHOD_ZH.md`。

| 名称 | 训练与用途 |
|---|---|
| summary_state | 三期限价格均值MSE＋0.1×九维联合ES；完整候选。 |
| state_price | 同一结构，只保留价格均值MSE与三维价格ES；检验未来范围辅助监督。仍有全部历史输入。 |
| state_marginal | 同一结构，各期限三维(P,U,L) ES的平均；检验跨期限联合评分。 |
| state_step1 | 同一结构，仅第一期限的价格MSE和三维ES；训练起点数量/最晚成熟期限不变。 |
| free_path | 同历史编码器，更自由的日级联合生成系数，同累计范围和九维ES；参数更多，需报告参数数目。其common-factor协方差不是候选AR协方差的严格超集，不将一次胜出解释为唯一机制识别。 |
| gru_price / gru_full | 同宽度GRU，直接输出三期限原价均值，仅MSE；price版屏蔽非P历史通道，两项context都是P信息。 |
| ridge_price / ridge_full | 原价变化的多输出Ridge；同历史窗口及context；alpha∈{0.1,1,10,100}。 |
| hgb_full | 每期限Histogram Gradient Boosting；同全部历史信息；叶子数∈{7,15}，100轮，lr=.05，L2=10，叶最小20。 |
| rw / drift | 当前P；或当前P＋折内历史平均价格增量×h。均不使用未来外生变量。 |

非线性模型的训练损失和概率评分不能被叫观测似然。生成器中的指数保护边界若在实际积分点触发，runner立即失败，不悄悄依靠截断改善分数。解析均值对应未裁剪的底层连续高斯价格模型，ES 对有限积分样本分布计算；有限样本未触边不等于连续高斯尾部没有质量。

## 5. 预算与随机性

七种神经模型，每源每折两次选择拟合（lr .001/.003，seed11），最多30轮，patience5，固定batch64、AdamW weight_decay1e−4、梯度范数上限5。验证指标是全部三期限按选择训练尺度标准化的价格MSE。轮0可被选中，含义为验证选择退回初始化均值RW；必须单列零轮重训，不把它计成已进行梯度更新。

每折选定轮数/学习率后，用全部已成熟训练池，从头按seed17/29/43各拟合一次。七家共享相同预算，不能将最佳测试seed拿来作主分数。主均值是三个seed解析均值的等权平均。预计84次选择拟合、126次最终模型构建（其中实际梯度更新次数取决于所选轮数）；完整记录epoch、optimizer steps、耗时和指纹。经典模型另行完整记录选择/重训。

全流程CPU float64，单进程数学线程1，最多3任务并行。Sobol训练节点32条，每epoch固定新scramble seed 70000+epoch；评估128条，seed908113。节点共享不构成独立蒙特卡洛样本；ES 使用包括对角线的有限经验分布 **V统计**，不称为连续分布的无偏U估计。

## 6. 评分、统计与事先判据

主指标 R：每个 source×fold×h 单元先算模型原价MSE / 同起点RW原价MSE，再等权平均18单元。两来源等权，各来源三个时间段及三个期限等权。R<1才表示相对RW改善。先平均seed的解析预测，再算MSE；另报各seed、各源、各折、各h。对其它模型的比率也用对应单元误差比等权平均，不能混成“两个总体R的商”。

每折的最强同信息点控制，仅在验证段的 gru_full/ridge_full/hgb_full 三者中选取，完全同分时按模型名称字典序破局，最终在测试段评价这个预先选择的流程；不能按测试最低者选择后当未选择比较。

置信区间：按源／折在原始顺序上进行配对移动块bootstrap，同一个抽样起点绑定所有模型和期限；主块长20、敏感性10/40，2,000次，seed20261019。这个短样本条件下的区间是稳健性近似，不声称消除非平稳性或跨折训练依赖。完整保留所有负面单元。

只有下述全部通过才进入新的独立数据确认；否则停止本候选：

1. 候选总体 R≤0.98（至少2%相对RW MSE改善），且20块的95%CI上界<1。
2. 候选／验证预选同信息点控制的单元误差比均值≤0.99。
3. 候选／state_price≤0.99，且95%CI上界<1，证明范围监督有价格效益。
4. 候选／free_path≤0.99，且95%CI上界<1，防止只胜弱结构对照。
5. 两来源的候选/RW均<1；至少六折中的四折均<1。

概率次指标：对每个seed的128条九维样本按训练固定分母计算经验ES并除以sqrt9，再平均seed；这不是三seed混合分布的ES。范围有序/嵌套率应为100%，它属于构造核验，不是预测准确率。概率校准只在辅助表中呈现，不用于改写上述主门槛。

## 7. 审计、复现和结果处置

拟合前进行独立解析均值、方差、梯度、V统计、窗口与尺度审计，以及已声明的合成持续状态正控制和鞅负控制。合成数据只检验管线与假设，不代替真实市场证据；正控制特意有状态信号，不能推断现实有同种信号。

每次结果均保存模型/预测/data/code hash；resume必须验证数据字节、预测及模型checkpoint。独立脚本从原始序列重构真值、成熟边界、分母和MSE/ES，不依赖runner输出的汇总分数。完成后保存训练收据、所有主比较、bootstrap、失效门槛、直接近邻及复现说明，再上传GitHub独立研究分支和Draft PR；不合并既有PR、不覆盖旧结果。
