# 阶段 e：学习贡献与响应机制复放

## 1. 结论与证据身份

本轮已经解决“模型只能保留初始化、没有实际非线性学习”的执行问题，但**没有建立主模型条件持续度门的预测增量**。所有 10 个非线性市场×模型单元最终均采用 80 次更新；全国 CEA 的主模型优于其同 alpha、固定初始持续度的精确线性读出，但这一改善主要也能由无上下文的全局持续度学习得到。天津的主模型相对自身固定持续度参考反而变差。

完整数值在 [SIGNED_RESPONSE_LEARNING_DIAGNOSIS.json](SIGNED_RESPONSE_LEARNING_DIAGNOSIS.json)，程序为 `audits/diagnose_signed_response_learning.py`。本报告由模型及运行器实现者在正式运行完成后撰写。它使用独立 NumPy 前向公式和增广最小二乘复核，但不是完全外部盲审。正式配对统计与置信区间由另一审计承担，本报告不新增 p 值、时期筛选、模型选择或梯度优化。

风险记为 \(R=\frac13\sum_h\operatorname{MSE}_h/\operatorname{MSE}_{RW,h}\)，越小越好。文中“百分点”是 \(100(R_{参考}-R_{模型})\)，并非相对于参考风险的百分比降幅。天津是已暴露开发数据；CEA 是本固定设计的新评分确认数据，不能合并成两个新市场确认。

## 2. 数值实现与真实训练均已核对

共重放 **176 个选择检查点和 12 个最终检查点，共 188 个**。NumPy 重建历史指数特征、上下文门、几何响应和价格预测；使用增广设计矩阵最小二乘重解带罚线性读出，没有直接重复原 torch 正规方程求解。

| 核对量 | 最大绝对差 |
|---|---:|
| 检查点前向复放与原验证 loss | 3.33×10⁻¹⁶ |
| 最终前向复放与原价预测 NPZ | 2.66×10⁻¹⁵ |
| 独立增广最小二乘与保存的线性系数 | 2.44×10⁻¹⁴ |
| 训练列 RMS 与保存的列尺度 | 1.15×10⁻¹³ |
| 保存系数的标准化 Ridge KKT 残差 | 3.64×10⁻¹⁵ |
| JSON 与二进制检查点参数 | 0 |

本轮选择拟合共执行 **9,576 次非线性更新，9,576 次梯度范数为正**；最终重新拟合共 **800 次更新，800 次梯度范数为正**。响应模型在这些选择与最终训练中实际进行了 **10,564 次精确读出求解**，另有运行器事先约定的 12 次固定初始持续度描述性读出求解。交互 Ridge 与价格 Ridge 各有 18 次选择/最终拟合。

全部非线性臂选定 alpha=1、学习率 .01、epoch=80；固定响应只选 alpha=1 并拟合线性系数。epoch0 的响应模型本来就包含监督拟合的线性读出，不能与阶段 d 的未更新固定先验混同。选中最大 80 次更新只是本冻结训练预算的结果，不证明找到了非线性全局最优，也不授权继续利用已评分 CEA 延长训练。

主模型选择试验中，天津带罚训练目标从 .976141 降至 .969903、验证风险从 1.037232 降至 1.024545；CEA 分别从 .844671 降至 .828202、从 .893530 降至 .861559。这些下降证明它实际学习并在对应验证期获得改善，不能自动推出后段预测增量。

## 4. 同 alpha 去门：条件映射有没有额外价值

根代理在完成运行后授权以下两种描述性检查。它们都保留主模型最终学到的全局持续度，把上下文门置零；一项保留原线性头，另一项在相同 alpha 下仅用最终训练标签精确重解头。后一项总共新增 **2 次描述性线性求解**，没有超参数搜索、梯度更新、新时期或候选选择。这些检查不同于事前独立调参的 `static_response`，不能替代正式主比较。

| 市场 | 正式主模型 | 去门、保留原头 | 去门、同 alpha 重解训练头 | 门的增量，重解头参考减主模型 |
|---|---:|---:|---:|---:|
| 天津开发 | .920781190 | .894903254 | .902974983 | −1.780621 个百分点 |

## 5. 失分的幅度与方向，以及“带符号”实际用了什么

对每市场等权三个期限定义

\[
A=\frac13\sum_h\frac{\operatorname{mean}(\widehat y_h y_h)}{\operatorname{mean}(y_h^2)},\qquad
B=\frac13\sum_h\frac{\operatorname{mean}(\widehat y_h^2)}{\operatorname{mean}(y_h^2)},
\]

则严格有 \(R=1-2A+B\)。这是预测误差的代数分解，不是新增拟合或检验。

天津从初始持续度参考到主模型，A 从 .055526 降至 .046079，B 从 .015484 降至 .012940。预测能量虽然更低，预测与真实变化的对齐损失更大，最终风险升高。因此天津失分不能简单说成预测振幅过大。CEA 中 A 从 .087549 升至 .098151，B 从 .064193 升至 .074819，对齐增加超过额外预测能量，带来净改善；但去门后的对齐稍好，主门仍未贡献该改善。

两个主模型的最终模式系数为：天津 **(−.178561,−.342892)**，CEA **(−.795853,−.375842)**，均是两个负系数。模型理论上能学习一正一负的延续/回撤组合，合成表达检查也已通过，但本次主模型**实际没有学出这种混合符号系数组合**。

实际预测路径中仍会出现未来增量变号：天津约 17.86% 原点、CEA 约 64.94% 原点；截至期限的累计未来变化变号约 11.73% 和 10.39%。这些现象可以由历史状态符号、两个响应速度与漂移项共同产生，不能直接叫作“模型识别了一个正冲击随后延续再反转”。尤其 CEA 的正漂移在瞬态效应衰减后会影响远端增量。必须把未来单步增量、累计未来变化、以及包含已发生变化的总价格路径分开解释。

## 6. 对主研究问题的影响

正式主模型在 CEA 的风险 .878516 低于 RW，但高于价格 Ridge .851062、同上下文自由期限头 .854695、交互 Ridge .855321、静态 .876992、条件振幅 .876827 和无量时长 .876821。在天津，它也不如固定拟合响应、静态、无量时长和价格 Ridge。具体不确定性由已冻结的成块配对统计给出，本报告不依据点估计宣称显著性。

可以保留的证据是：拟合确实发生；数值与保存结果一致；有符号模型确有更宽表达能力；固定小基底上的精确线性读出和 CEA 的全局持续度学习存在局部改善。当前证据不足以把这些局部改善归为**新增条件持续度门**或**跨期限共享约束**的有效创新。CEA 的自由期限臂更好，也提示共享限制本次没有显示其预期优势；不能据此在结果后把该控制晋升为本轮已确认的主候选。

本报告不据这些结果更改候选身份、门、alpha 网格、训练上限、市场范围或既有统计计划。
