## 3. 唯一模型的数学定义

### 3.1 因果参考

固定31成员：精确RW，以及rho in {0,.25,.5,.75,.9,.97}与永久创新方差比例v in {.02,.1,.25,.5,.8}的组合，暂态方差r=1-v。它是既有低维高斯模型，不是新架构。对每个成员：

    e_t = delta_p_t - (rho-1)*z_(t-1)
    S_t = (rho-1)^2*P_(t-1) + 1
    C_t = rho*(rho-1)*P_(t-1) + r
    z_t = rho*z_(t-1) + C_t*e_t/S_t
    P_t = max(rho^2*P_(t-1)+r-C_t^2/S_t,0)

z0=0、P0=r/(1-rho^2)。首次origin60、以后每20观测，在不含当前观测的过去W条创新上最小化剖面似然：sum(log S)+n log(mean(e^2/S))；数值均值下界1e-12，平局取低索引。候选W=240，独立强对照W=120/480。此调度与之前阶段不完全相同，因此不能拿旧分数当本轮逐点复现。

签发参考变化b_(o,h)=(rho_o^h-1)*z_o，h=1..20。当前参考状态为q_o=[tanh(z_o/s_T),rho_o*(1-v_o),1-v_o]；s_T只由当前训练子集估计，RW状态精确为零。模型选择与状态只用当前/过去价格；过去已签发参考不回写。

### 3.2 直接循环修正

完整GRU(1,16)处理60步标准化原价增量。令u=GRU(x)_last-GRU(0)_last，a=Uu，c=Vq；U为8x16，V为8x3，偏置beta为8维，O为20x8且无输出偏置。唯一候选：

    correction = O*[tanh(a+c+beta)-tanh(a+beta)-tanh(c+beta)+tanh(beta)]
    p_hat_(o+h|o) = p_o + b_(o,h) + s_T*correction_h

它学习历史与参考的混合差分。1232个分配参数；O零初始化，起点等于参考预测。不是状态滤波增益、末状态平移或最终标量组合。

q=0或u=0时修正为零。这是强归纳约束，可能丢掉有用主效应，绝非风险保证。评价起点中参考选择RW的比例实际为0，因此本轮失败不能解释为全部被强制退回RW。

### 3.3 配对对照与等价性

相同参数结构、初始化、优化支持：
- RESIDUAL: O*[tanh(a+beta)-tanh(beta)]；V无数据梯度，有效容量不完全相同。
- ADDITIVE: O*[tanh(a+beta)+tanh(c+beta)-2*tanh(beta)]。
- FULL: O*[tanh(a+c+beta)-tanh(beta)]。
- MIXED: 唯一候选。

对于相同固定参数，FULL=ADDITIVE+MIXED；这不是分别训练后的模型也相等。仿射读出时混合差分为零；一般tanh下非零。零锚点的主效应消除不等于依赖输入下的总体L2正交，更不识别真实经济状态。混合差分是已有anchored decomposition思想，不是新定理；统计神经混合和结构化交互也已有直接近邻。
