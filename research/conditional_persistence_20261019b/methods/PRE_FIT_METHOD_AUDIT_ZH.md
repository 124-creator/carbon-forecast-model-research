## 1. 裁决

**保留一个条件性候选：以同一个小状态转移核传播未来全部期限的 Gaussian 混合分布，历史条件持续性只改变累计收益的尾形。** 它比此前 SMP 的均值传播及 PR22 的整体尺度修正更明确地改变了预测分布本身，可以进行数值审计和有限合成检验。但保持/重抽的转移核、Markov 波动模型、混合分布传播及 CRPS 都已有直接近邻；不能把这些部件或它们的名称当成新算法证明。

目前不建议直接为这个“仅持续性”版本追加数百次市场拟合或打开新确认集。原因不是只因存在近邻，而是一个更实质的问题：固定一步形状与方差后，持续性在平均 CRPS 下的总体收益可能很小。本文事前指定的二值历史正例，即便历史完美识别真实持续性，也只比总体最优常数持续性获得约 **0.06461%** 的 h1/h5/h20 平均相对 CRPS 空间。有限样本估计误差很容易超过它。

可以接受的下一步是：先冻结最小合成与匹配消融，证明该学习问题在拟用样本量下确实可学，再决定是否只做一轮低预算开发实验。若无法胜过同结构的训练常数持续性，应停止此版本，不能再根据结果调宽方差格点、挑混合权重或增加极端状态来“修复”正控制。

## 3. 对“完整未来路径提供无假设学习改进”的边界

设未来路径为 R，终点目标 Y=T(R)，原损失梯度为 g_theta(X,Y)。如果某个逐样本统计量 h_theta(X,R) 对**每一个可能的数据分布**都满足

\[
E_P h_\theta(X,R)=E_P g_\theta(X,T(R)),
\]

那么令 P 为任一 (x,r) 上的点质量，即得

\[
h_\theta(x,r)=g_\theta(x,T(r)).
\]

因此，在没有已知条件矩、随机化设计或分布族约束时，不存在一个统一更低数据噪声、又处处保持原端点风险梯度的逐样本“未来路径修正”。若引入算法随机性 U，只要求 E[h|X,R]=g，则全方差公式给出 Var(h)≥Var(g)，不能凭额外随机化降低观测样本本身的方差。

这不是所有多样本估计、所有半监督学习或所有辅助学习的不可能定理；它只是排除本项目此前容易混淆的逐样本无偏梯度主张。完整未来路径可以通过**明确的联合生成族和联合监督**改善参数估计，但必须承认模型限制及误设风险。Cross-fitting、detach 教师或给辅助项取新名称都不能自动改变上述边界。

## 4. 保留候选的精确定义

### 4.1 单起点内的生成分布

给定预测起点全部已知历史 X，用一个低容量编码器输出

\[
\pi(X)\in\Delta_3,\qquad f(X)>0,\qquad \rho(X)\in[0,1].
\]

固定状态方差

\[
q=(1/4,1,4),\qquad
P_X=\rho I+(1-\rho){\bf1}\pi^T.
\]

令 Z_1~pi、Z_{j+1}|Z_j~P_X，条件各步标准正态噪声独立，

\[
r_j=f\sqrt{q_{Z_j}}\,\epsilon_j,
\qquad D_h=\sum_{j=1}^h r_j.
\]

整个发行向量内 pi、f、rho 均冻结。pi 是这个发行核的稳态；它不是经独立经济验证的真实市场状态概率。可将 q 除以 m=pi^Tq，让 f 直接表示单步标准差。两种参数化生成相同类型的分布，必须在实现和公式中选择一种并保持一致。

该模型只有零条件对数收益均值。它不承担发现方向信号或必然改善价格 MSE 的任务，也不把报价不变解释成无成交。第一版不加入零原子：精确零值的出现及交易语义另需来源证据；零原子/renewal/hurdle 本身已有近邻，且项目 SMP 已处理过零变化状态。

### 4.2 持续性独立改变什么

固定 X，记 m=E_pi q、v=Var_pi(q)。标准 Markov 计算得到

\[
P_X^k=\rho^k I+(1-\rho^k){\bf1}\pi^T,
\]

\[
E D_h=0,\qquad Var(D_h)=h f^2m,
\]

\[
Cov(r_i^2,r_j^2)=f^4v\rho^{|i-j|},\quad i\ne j.
\]

由于给定状态路径时 D_h 为零均值正态，其超额峰度为

\[
\kappa_h
=\frac{3v}{h^2m^2}
\left[h+2\sum_{k=1}^{h-1}(h-k)\rho^k\right].
\]

这些等式基于初始状态处于 pi、同一 f/P 及条件独立正态发射。它们不是金融市场普遍定律。它们给出一个可检验的机制：rho 在**不改变一步完整边际及任何期限累计方差**的条件下，改变长期方差混合和尾形。

当 v>0、h≥2，峰度严格随 rho 增大；因此固定 pi/f 时 rho 可由多步分布识别。h1 对 rho 的任何损失梯度都应严格为零。若 pi 三权重严格正、f>0，已知不同 q 的 h1 Gaussian 混合先在总体内识别有序尺度及权重，再由任一 h≥2 端点分布识别 rho。有限样本识别强度不由这个总体可识别性保证。

rho=0 是每步独立重抽状态；rho=1 是整个窗口固定一个状态。后者不是单一 Gaussian，而是三成分 Gaussian 尺度混合。不能把这两个端点消融命名为“没有分布”或“没有波动信息”。

### 4.3 精确压缩传播

令 c=(0,1,5)，则 q_z=1/4+(3/4)c_z。累计方差只取

\[
V_{h,m}=f^2(h/4+3m/4),\quad 0\le m\le5h.
\]

用 d_j(z,m)=Pr(Z_j=z, sum_{l≤j}c_{Z_l}=m|X)。初始化

\[
d_1(z,c_z)=\pi_z,
\]

递推

\[
d_{j+1}(b,m+c_b)\mathrel{+}=\sum_a d_j(a,m)P_{ab}.
\]

最终 w_h(m)=sum_z d_h(z,m)，

\[
F_h=\sum_m w_h(m)N(0,V_{h,m}).
\]

每一期只有 O(h) 格点，逐期三态递推至 H 的总复杂度为 O(H² K²)，K=3；不需要3^H状态路径枚举。h20 在内部 pi>0、0<rho<1 时有95个非零方差格点。计算普通混合 CRPS 的成分两两项仍是每期限 O(S_h²)，不能把整个训练目标称为 O(H) 或忽略这部分成本。

定义

\[
A(y,s)=2s\varphi(y/s)+y[2\Phi(y/s)-1].
\]

那么

\[
CRPS(F_h,y)
=\sum_m w_mA(y,\sqrt{V_m})
-\frac12\sqrt{\frac2\pi}
\sum_{m,n}w_mw_n\sqrt{V_m+V_n}.
\]

它是有限 Gaussian 混合的已知解析 CRPS，不是新评分规则。权重递推可直接反向传播，没有离散状态采样梯度或样本式 CRPS 的 Monte Carlo 误差。

若目标为价格 P_{t+h}=P_t exp(D_h)，则

\[
E[P_{t+h}^a|X]
=P_t^a\sum_m w_m\exp(a^2V_m/2).
\]

模型数学上具有全部有限价格矩，数值实现仍须检查指数溢出及尺度界，不得通过静默截断改变预测。Student-t 若直接用作对数收益分布，一般没有这些指数矩；不能照搬一个 t 输出基线后仍声称其价格均值有限。

### 4.4 不能隐藏的结构代价

1. Var(D_h|X)=h f²m 强制平方根期限尺度；它不能表达任意期限波动率结构。如果用已有 F0/GAS 的每期限尺度独立缩放各 F_h，应把它单列为“共享持续性形状、自由期限尺度”消融，该输出不再是上面同一增量核的端点。
2. pi 同时承担当前状态分布和该发行核稳态，遗漏“当前状态偏离长期均衡后回归”的常规波动机制。解除它会使模型更接近完整的常规 HMM 波动预测，同时改变本次固定二阶矩的识别问题；不能悄悄加入后仍沿用同一实验解释。
3. 同一起点内联合生成一致，不等于跨起点 tower 一致。下一起点重新编码 X 后，新 pi/f/rho 未必等于原模型按已实现收益条件化后的状态更新。
4. 单个正持续性不能描述多时间尺度、负相关波动、依赖未来增量符号/大小的转移或杠杆效应。Gaussian 尺度混合也不能表达收益偏斜。

## 6. 未来路径监督的合法用途

主目标可以是同一批 H20 已成熟起点上的端点 CRPS：

\[
L_{end}=\frac1N\sum_t\sum_{h\in\{1,5,20\}}
\omega_h CRPS(F_{t,h},D_{t,h})/s_h^{train}.
\]

分母和一切静态尺度只由训练前缀确定；相同起点、相同期限权重必须适用于所有匹配对照。

一个明确辅助消融是完整路径 NLL，利用标准 HMM forward 递推：

\[
\ell_{path}(r_{1:H}|X)
=-\log\{\pi^T E(r_1)P E(r_2)\cdots P E(r_H){\bf1}\},
\]

其中 E(r) 为发射密度对角阵。数值上采用 log-space 或每步归一并累计 log-normalizer。这个辅助项可以识别平方增量的连续性，而不是只拟合每个终点的边际。

在正确指定、正则性允许求导的同一参数族中，路径似然 score 与压缩标签 T(R) 的似然 score 满足

\[
s_{T(R)}=E[s_R|T(R)],\qquad I_{T(R)}\preceq I_R.
\]

这是已知信息单调性，不是本项目新定理，更不能直接改写为“辅助 NLL 必然降低 CRPS 梯度方差/必然提升有限样本风险”。路径模型错误、辅助权重过大或重叠样本重复加权，都可以损害端点 CRPS。无辅助、固定权重辅助、纯路径似然应明确区分，权重不可由评价成绩改选。

未来价格只在**标签已经成熟**的训练块计算 NLL；推断不读取未来路径、不更新发行上下文。预测窗口重复造成依赖，不因多了一项似然而获得更多独立样本。

## 7. 已执行的纯模型内总体计算

### 7.1 固定设置与计算式

### 7.2 最小正负控制与反例

**正控制 P1：历史识别持续性。** 使用上述 X二值、rho=.1/.9、pi/f固定的分布，训练数据为独立条件路径块。小模型只能学习 rho(X)，不能偷偷学习不同条件均值/尺度。总体风险由上述解析式评分。对照是同样标签下拟合的常数 rho，以及固定 rho=0/1。主要观察参数识别、有限样本风险与梯度噪声，不要求每个随机样本必然有增益。

**正控制 P2：已知正确的固定持续性。** 真 rho=.8、X纯噪声。训练常数模型应具备学习真 rho 的能力；条件网络不应被宣称有额外真实信号。它可以验证从 h≥2 端点损失学习 rho 的管线，与 P1 的有信息历史区分。

**负控制 N1：仅h1监督。** rho 的解析分布梯度严格为0。如果端点h1损失改变 rho，首先排查共享尺度实现、标签泄漏或不同损失，不能解释为高效隐式学习。共享编码器下其他头训练可能改变rho输出，所以检查应固定pi/f并只暴露独立rho参数，或核分布的偏导。

**负控制 N2：退化状态方差。** q三个值相同，或允许的特例pi集中在单个状态时，所有期限分布与rho无关。用相同q单独做实现负控制，不能将真实实验的固定格点在训练中改成相等后仍沿用同一识别假设。

**负控制 N3：无历史条件变化。** 真rho=0或真rho为常数，X独立噪声。神经rho优于训练常数只可能来自有限样本/优化差异，不能成为条件机制证据。有限n下无需断言每次都不优，必须报告重复分布与总体期望趋势。

**误设反例 N4：杠杆。** r1=epsilon1；若r1>0，r2=2epsilon2，否则r2=epsilon2，其中epsilon独立Rademacher。两个增量分别是条件鞅差，但D2取3、−1、0、−2各1/4，三阶矩4.5；对称 Gaussian 尺度混合族不能表达它。端点误设可被完全自由的偏斜分布修正。这个例子只证明结构有偏差，不给任一未经拟合的基线保证胜利。

**误设反例 N5：均值回归的未来方差。** 初始波动状态概率alpha不同于长期pi，即使仍为普通Markov模型，也有

\[
E\sum_{j=1}^h q_{Z_j}
=h\pi^Tq+(\alpha^Tq-\pi^Tq)\frac{1-\rho^h}{1-\rho}.
\]

稳态初始化候选一般无法同时匹配其所有期限方差。该式以Z1~alpha为约定，rho=1取连续极限。它直接暴露本候选不应宣传成完整波动期限结构模型。

## 8. 最小公平对照与停止标准

| 对照 | 保持相同 | 唯一要检验的差异 |

常数rho与条件rho的参数数目不同，应公开数目。可增设一个精确同参数量对照：两者都保留一个条件标量头，主臂用它作rho，对照用于预先定义的形状或尺度变化并将rho限制为常数。这个对照的目标是排除容量解释，不能谎称两个函数类完全相同。

不应为了证明创新而只选择方差错配的Gaussian、rho=0或旧弱scale-only F1。也不应给主臂全部已成熟未来路径，而让自由GMM只看更少的训练起点；如果自由端点模型无法自然接路径似然，必须增加共享骨干的同辅助任务对照，避免把普通表示监督收益归为传播结构。

数值门槛应先核：DP与h≤5全路径枚举、各h概率守恒/非负、梯度有限差分、h1rho偏导零、端点方差和四阶矩、混合CRPS数值积分、正价格矩、rho边界。验证只针对具体机制风险，不需要再次重跑旧市场模型。

## 10. 不再保留第二个候选的理由

本轮没有把“零活动原子+非零大小”作为第二个独立新方法：原子与renewal/hurdle近邻明确，项目已做过零变化状态和类似辅助学习；若缺乏新的识别机制，它只是分布支持域修正。现有来源的净零变化也不能证明无成交。

## 附录：总体风险计算的可复现最小代码

以下仅用 NumPy/SciPy；不读取文件，不抽样市场，不训练预测网络。

```python
import numpy as np
from scipy.optimize import minimize_scalar

pi = np.array([.45, .40, .15])
q = np.array([.25, 1., 4.])
c = np.array([0, 1, 5])

def law(h, rho):
    transition = rho * np.eye(3) + (1-rho) * pi[None, :]
    d = np.zeros((3, 5*h+1))
    d[np.arange(3), c] = pi
    for _ in range(1, h):
        propagated = transition.T @ d
        d = np.zeros_like(d)
        for z in range(3):
            d[z, c[z]:] = propagated[z, :len(d[z])-c[z]]
    weights = d.sum(0)
    variances = (.25*h + .75*np.arange(5*h+1)) / (pi @ q)
    return weights, variances

def risk(candidate, truth):
    w, v = candidate
    p, u = truth
    cross = (w[:,None] * p[None,:]
             * np.sqrt(v[:,None] + u[None,:])).sum()
    own = (w[:,None] * w[None,:]
           * np.sqrt(v[:,None] + v[None,:])).sum()
    return np.sqrt(2/np.pi) * (cross - .5*own)

for true_rho in [.5, .8, .95]:
    for h in [1, 5, 20]:
        truth = law(h, true_rho)
        oracle = risk(truth, truth)
        comparisons = {
            rho: risk(law(h, rho), truth) / oracle - 1
            for rho in [0., .5, .8, .95, 1.]
        }
        print(true_rho, h, comparisons)

truths = {
    (rho, h): law(h, rho)
    for rho in [.1, .9] for h in [1, 5, 20]
}
def objective(rho):
    return np.mean([
        risk(law(h, rho), truth) / risk(truth, truth) - 1
        for (_, h), truth in truths.items()
    ])

answer = minimize_scalar(
    objective, bounds=(0, 1), method='bounded',
    options={'xatol': 1e-12})
print(answer.x, answer.fun, objective(0), objective(1))
```
