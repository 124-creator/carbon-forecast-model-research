# 数据来源、首次使用边界与准备回执

## 已完成的结果

按冻结的 `provenance/PROTOCOL.json` 与 `MARKET_PROTOCOL.json` 完成13个年度面板的数据准备：11个此前已用于训练、验证和评分的开发面板，以及2个PLOS深圳来源的2020、2021年度面板。数据准备没有拟合任何市场模型。13个训练—验证边界、13个验证—测试边界和13个共同期限的年度限制均通过检查。

深圳纳入序列为1857条，2013-08-05—2021-12-31。所有纳入的有限数值价格均严格为正，非正值数为0，所以冻结的“出现任何非正值就整条深圳来源退出”条件没有触发。这里的通过只说明对数价格的数值域可用，不证明数据口径已得到交易所认证。

公开文件 `PREPARATION_START.json` 是下载和新工作簿读取之前的快照，锁定两份协议、数据准备代码和原始源哈希。`DATA_PREPARATION_RECEIPTS.json` 提供全部年度的原始行号、日期边界、计数和私有NPZ哈希，未包含价格、收益、特征、逐点预测或权重。准备程序的运行哈希为 `9b71d032bd6c401622b9f0b0e4d23b1ee9bf303d58540b90564d9506ab49f164`。

### 出版版本注记

[2025-08-05更正通知](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0329804)，DOI `10.1371/journal.pone.0329804`，说明出版社此前误发了不完整版本，文章已于2025-06-05重刊。这不是本轮核到数据错误的证据，也不是撤稿通知。当前原文Data Availability称，来自 `k.tanjiaoyi.com` 的技术指标在Supporting Information中提供；金融和商品Wind数据因共享权限限制不能公开。通过锁定这份S1的精确哈希，使本次复现实验不依赖日后网页或附件的无声变化。

### 冻结的行规则与执行边界

从零基行2开始，按旧机械规则解析第0列日期：Excel日期按工作簿datemode转换，文本只接受 `%Y-%m-%d`、`%Y/%m/%d`、`%Y%m%d`、`%Y.%m.%d`。第1列必须为Excel数值单元格且有限；不把文本数字另行强制转成有效报价。

经冻结规则检查，截至2021年的2232个有日期行中，有375行价格缺失或非数值；它们按原作者文件的机械资格定义排除，没有填0或插值。剩余1857行唯一且原顺序严格递增；有限非正值为0。另有59个日期落在2022年的行全部在访问其价格字段之前跳过，2个非日期行也未纳入。缺失价格不能被解释为零成交；没有按收益、误差或模型表现挑删行。

使用成熟的xlrd工作簿解码器时，加载该sheet可能在库内部解码2022单元格。本次没有声称这些单元格从未解码；只有截至2021年的行被转换为实验数组，不导出或训练2022价格。这个执行语义已在重新下载之前写入冻结的市场协议。2024及以后的保留价格限制始终不变，其他未来确认文件没有打开。

新证据的准确说法是：**这是本项目首次用这份作者深圳来源进行2020、2021年度模型训练与评分的准备**。旧项目已经机械解析过该附件，并获取过另一来源的深圳2015—2017年均价；不能称整个深圳市场、附件或者全部1857个数值从未接触。实际模型拟合和评分由后续运行回执记录。本准备步骤的模型拟合数为0。

2020和2021对应完整年度的作者有效报价范围，分别201、206条；这不等于官方每个交易日都已覆盖。2022附件只到3月，继续整年排除。SZA配额年份、汇总规则以及工作簿价格单位未得到独立认证，不与旧深圳均价或fsdf作者文件拼接。

## 3. 统一时间切分与数据接口

所有h=1、5、20共享最大预测期限20的训练、验证和测试起点。令年度首报价索引为T：验证末origin=T−21，验证首origin=T−146，共126个；训练末origin=T−167，训练首origin固定39。因此最大训练标签在T−147成熟，严格早于验证首origin；最大验证标签在T−1成熟，严格早于测试首originT。训练起点至少128个的规则在全部13面板中满足。

测试只保留origin和origin+20同时落在规定年份的起点。即使某h较短，也不扩展测试起点，从而保证期限和模型之间可以按同一观察起点配对。报价步长不是自然日时长；不填充节假日或稀疏报价日。

上海2022的126个验证起点仍横跨2020—2021，反映原数据的稀疏性；删除专用校准段没有消除这一数据限制。126个重叠标签也不是126个独立样本。

每个origin保留20×3的历史矩阵：日对数收益除以当时因果EWMA尺度、尺度的对数、日历间隔的log1p。第一个origin39之前有40条报价，实际网络输入是20个历史特征行；不把它误写为40行网络特征。EWMA在第20个真实收益处用20个收益的平方均值初始化，之后按0.94/0.06递推；更早但未用于模型的槽位也只用其已有前缀，不给index0赋混合单位。

尺度下限为训练标签成熟前缀的 `max(1e-8, 0.1×median(abs(return)))`，末端固定 `train_end+20`；训练窗口的均值和标准差只由训练窗口计算，标准差数值下限固定1e−5。验证和测试使用这些冻结的量。没有训练F0、GARCH或任何神经模型。

私有NPZ以角色前缀 `train_`、`validation_`、`test_` 保存：`X`、`daily_scale`、`future_returns`、`future_normalized`、`y`、`unit`、`indices`、`dates`、`origin_price`、`target_price`、`target_indices`、`target_dates`。其中future_normalized是20个增量逐一除以origin日尺度，不含√h；y是h期累计增量除以日尺度×√h。完整schema见 `prepare_data.py` 顶部文档。

`all_returns[0]` 是0哨兵，不是一个测量收益；真实收益从索引1开始。GAS基准应重构各h的已成熟目标过程 x_t^(h)=log(P_t/P_(t−h))，只拟合成熟时刻h至train_label_end，不能把日收益哨兵当作GAS观察。本次为GAS提供的基准只有11个既有面板；新增深圳2面板只在候选方法的附加分层单独报告，不能声称深圳已有同一GAS对比。

## 4. 可复现执行与公开边界

先取得四个固定开发CSV和上面固定哈希的PLOS附件，保存在公开Git目录以外。原始公开下载可调用现有 `research/distribution_shape_diagnostic_20261017c/data_sources/plos_shenzhen/reproduce_plos_supplement.py download` 子命令；不要调用其全sheet `inspect` 或 `extract` 来替代本轮冻结的截止规则。

新准备脚本默认只处理11个既有面板。显式提供 `--shenzhen-workbook`、`--market-protocol` 和 `--market-protocol-sha256` 才会尝试追加深圳2面板；脚本验证协议哈希、合成资源门槛标记及源身份后再打开工作簿。实际冻结市场协议SHA-256为 `f2ac9d5aac5a8bbc7d6f7a785e943e307b903d2fc3ab56cc8484b9e1375adc9d`。

原始XLS、逐点价格、收益、路径、特征及后续模型权重只留私有运行目录。本目录仅公开代码、固定来源、时间边界、计数和聚合审计。数据准备完成不是模型有效的证据；后续两套runner仍需独立检查拟合端点、预测信息集和模型选择边界。
