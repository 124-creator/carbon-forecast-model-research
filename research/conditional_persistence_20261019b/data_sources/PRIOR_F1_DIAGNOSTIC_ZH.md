# 上轮提议模型的结构诊断与下一轮数据可用性

日期：2026-10-19。性质：**对已经用于开发、验证、校准和评价的 ≤2023 数据做事后结构诊断，不是独立确认。** 本轮没有市场拟合、梯度或优化器调用，没有改变 epoch、阈值或超参数，没有新读取保留期价格，没有修改已有研究目录。

本报告中的“本轮”仅指这一步事后诊断；其后冻结的新数据准备见本目录 `SOURCE_AUDIT_ZH.md` 与独立运行回执。

## 1. 结论先行

46/132 次选择 epoch 0 的直接原因已经查清：每次随后 60 个 epoch 的验证 CRPS 都不优于初始 F0。没有任何一例是“确实改善但被 1e−8 容差挡住”。训练确实执行了，epoch 0 是验证选择的回退。

更关键的失败出现在**提议的跨段泛化**。对已选检查点做 eval/no_grad 推理后，所有 86 个非恒等提议在训练和验证段均改善；平均改善没有延续到后面的校准与年度评价。其余 46 个完全等于 F0。因而无法把失败简单归因于训练没开始、训练步数不够或只需取消早停。

数据方面，现有四个开发市场可以继续用于方法开发，但不再提供盲测。PLOS 深圳 2020、2021 年是可在新方法和协议冻结后首次用于模型评分的候选时期；2022 年附件只到 3 月，应完整排除这个年度评价。既有 d4 包还提供能源与股票协变量的较长日期覆盖，但合约、发布时间和价格类型限制仍然存在，不能把“多变量可下载”写成已认证的实时信息集。

## 2. 如何诊断以及没有做什么

使用公开的 FIT_AND_GATE_RECEIPTS、CELL_METRICS、PREPARATION_RECEIPTS，四个固定哈希开发 CSV，22 份 prepared、132 个已选检查点与132份归档预测。四 CSV 均先只读日期并确认止于2023，再读取价格；每份 prepared、检查点、预测的 SHA-256 与旧回执匹配。

原回执只保存逐 epoch 验证损失，没有保存逐 epoch 训练损失。因此本次只对**原来已经选中的模型**补做训练/验证前向推理，使用独立审计中已有的架构重放类，eval/no_grad，不恢复优化器、不反向传播、不再选模型。校准与测试直接用原归档因子。验证重放的双精度CRPS与原单精度回执最大差1.07e−7；测试重算与原归档及22格公开聚合一致。

下文比例先对每个训练任务在对应角色内计算 F1/F0，再按既定任务/格等权汇总。每格都有两骨干×三种子，所以全132平均也等于22格等权平均。重复种子不是独立市场；不同角色比值的分母是各自角色的 F0。数值负号表示CRPS降低。所有输出是聚合摘要，没有导出逐点价格、因子、预测或模型权重。

## 4. 可见事实与因果猜测

### 4.1 尺度和跨时间状态变化：有直接现象，没有因果识别

上海2023H20是最清楚的失配例子：训练−3.356%、验证−7.355%，随后校准+2.898%、测试+8.499%。平均尺度因子从验证0.778变为校准1.276、测试1.291；但测试归一化标签标准差只有验证的0.640倍。湖北2023H20也从验证−0.296%变为测试+1.994%，测试标签标准差仅验证0.541倍。因子是模型对当时历史的响应，不是测试期又训练了模型。

这些是“已学尺度映射没有稳定延续”的事实。它们与条件关系变化、输入分布变化、有限样本拟合误差或尺度族错设都相容，不能单凭这些聚合统计断言哪一个原因占主导。反例也保留：广州2023H20尽管校准较差，年度测试却改善2.674%；不能把标签标准差变动当成已经验证的统一失败判别规则。

四角色所有已选因子都落在(0.5,1.5)设计范围内，精确等于上下边界的数量为0。最极端训练因子约0.5012和1.4989。没有记录逐点梯度，所以“未精确触边”不证明没有sigmoid梯度饱和；扩大范围也尚未被试验支持。

### 4.2 验证与部署隔得远：源于上轮协议，不是时间泄漏

126个验证起点、252个校准起点并不等于同样长度的自然时间。上海2023H20的验证起点为2020-01-13—2020-10-23，校准起点为2020-11-26—2022-12-01，测试从2023-01-10开始。上海2022H20的验证还在2018-06—2019-05。稀疏日期使同样的观测数横跨更长时期。

时间成熟边界已在上一轮独立审计通过。因此这里观察到的是旧验证状态与后来部署状态差距大，不能称为泄漏。新方案若删除专用校准门控，应重新明确训练、验证和年度测试边界；不能沿用旧实验收益证明新分段会更好。

### 4.3 样本量：小而高度重叠，但不是唯一解释

每格训练起点217—2149；GRU1025参数、MLP2497参数。126条连续验证标签，H5最多可选26个互不重叠的未来增量窗口，H20最多7个；这些窗口仍可能相关，不能称为独立样本。252条校准相应最多51/13个不重叠窗口。多h、多种子都不增加独立市场日数。

但“多一点数据就能解决”也没有被当前证据证明：EUA2023H20有2104个训练起点，六次均回退；上海没有一次回退，却是平均测试最差的市场。22个相关组合的训练起点数与测试变化的描述性Spearman为−0.123，验证变化与测试变化为0.013；没有做独立样本显著性或因果解释。

### 4.4 信息与输出族限制

上轮网络只有20×3历史信息：归一化价格增量、log EWMA和日历间隔。提议只给冻结的零中心三正态混合乘一个0.5—1.5因子，不能改变混合权重、均值、尾部相对形状，也不显式传播未来潜在状态的持续性。这是源码可直接确认的表达限制，不等于证明那些额外自由度一定可学。

因此三态Markov尺度混合及完整多h分布传播可以作为一个不同、可检验的假设，但本次诊断没有训练它、也没有验证其优越性。若使用这类模型，状态应称统计潜在状态；目前没有政策/配额/真实机制标签来把状态解释成特定经济制度。其收益需要与同信息集、同混合复杂度、去掉持续性的匹配对照区分。

### 6.2 暴露历史必须准确表述

旧distribution_shape报告明确“新深圳数据用于模型次数0”，prior_transport和本轮四市场实验也未纳入它。更早的ScienceDB深圳596条实际覆盖2015-05-18—2017-12-29，已机械获取并分357/119/120段；cross_market主报告明确七试点均价队列未拟合，后续定向审查亦未找到其模型使用记录。
