# SegRNN 分段相位诊断与方案否决（2026-10-14）

## 结论

**硬非重叠分段确实存在单点平移下的采样格相位敏感性；但本次唯一审查的“共享编码器 + 可学习相位加权汇聚”就是多相位特征集成，不作为新的模型贡献继续训练。** 不把“存在缺陷”直接当成“修复方案首创”。没有读取市场数据、训练市场模型、下载权重或推送代码。

本报告的数值证据来自 `diagnostic.py` / `results.json`。实际训练的是纯合成任务上的岭回归读出头，不是端到端 SegRNN。随机冻结的编码器用于结构诊断，不能证明真实训练后的 SegRNN 必然表现较差。

## 1. 作者源码到底做了什么

已下载并阅读作者 `models/SegRNN.py`，保存为 `upstream_Segrnn.py.txt`。源码同时包含完整实现和注释掉的简洁实现。[1]

- 默认式路径先减去最后一个观测值，再从 `[B,L,C]` 变成 `[B,C,L]`；可选 RevIN 则不同。[1]
- `reshape(-1, seg_num_x, seg_len)` **硬切非重叠连续段**；`Linear(seg_len,d_model) + ReLU` 将每个段编码成一个向量；单层共享 GRU 按段顺序更新，保留最终状态。[1]
- PMF 并非直接线性读出编码状态：位置/通道嵌入作为单步 GRU 输入，以复制的最终编码状态为初态，然后才做线性段预测。[1]
- RMF 则反复预测、重新嵌入、更新循环状态。因此不能把本报告的线性读出探针误称为完整 PMF，也不能将“池化后 PMF”直接证明成“PMF 预测值平均”。[1]

原始工作明确将减少循环迭代次数作为设计目标；改成步长 1 后循环次数增加，本身就是需付出的代价。[2]

令段长 s，段嵌入为

`e_k(x) = ReLU(W [x_{ks},...,x_{ks+s-1}] + b)`，

`h_k = GRU(e_k,h_{k-1})`。

这一嵌入等于 kernel=s、stride=s 的一维互相关/卷积再 ReLU。**Linear 与卷积在这里是精确重写，不是新组件。** 单点平移后的窗口支撑集合不再落在原来的 s 倍采样格上，不能一般地通过已有段 token 的置换获得。这里讨论的是结构性质，不是每个输入必定产生大误差。

## 3. 唯一审查方案：可学习、共享参数的相位鲁棒编码

对每个起点相位 p∈{0,...,s−1}，使用同一 W 和同一 GRU：

`h_p = G_theta( [ReLU(W win_{p+ks}(x)+b)]_k )`。

共享评分 `a_p = softmax_p(q^T h_p)`，编码结果

`H(x) = sum_p a_p h_p`，预测 `y = PMF_theta(H(x), position, channel)`。

这是具体可训练图；可以学习 q、编码器和原 PMF，但**本次在等价审查阶段否决，不声称完成了它的端到端训练**。

### 3.1 与普通滑窗 GRU 的区别

所有相位的段嵌入交错排列，精确等于步长 1 的同一个卷积/滑窗 Linear+ReLU。因为 `{p+ks}` 恰好枚举窗口起点，没有新的观测信息或新的局部表示运算。

但相位 GRU 是 s 条独立状态链，各自每 s 个点更新；普通滑窗 GRU 是单条状态链，每点更新一次。GRU 非线性且有状态，不能把二者等同。相同参数的数值反例误差为 **0.455397**。

### 3.2 与多相位平均/集成的关系——否决点

q=0 时，H 就是多相位隐藏状态平均。q≠0 时是同一相位编码器 bank 的自适应加权特征集成，即普通 attention/mixture pooling。重命名为“相位鲁棒编码”并没有改变运算图。

若读出 `D(h)=v^T h+c` 为线性，则

`D(sum_p a_p h_p) = sum_p a_p D(h_p)`，

也精确等于加权预测集成，数值误差 **1.67e−16**。但真正 PMF 在读出前经过 GRU，**该交换等式不适用于 PMF**。仍然可成立的否决理由是：原方案在编码层本来就等于“共享多相位特征集成 + 原 PMF”，并没有独立于已有集成/池化的编码机制。LPS 提供已有共享相位评分的先例，但这里不声称它与整个 SegRNN-PMF 数学等价。[4][5]

因此：**拒绝把这个方案作为独立贡献，不再追加另一个方案来绕过否决。**

## 4. 实际数值验证

### 4.1 不混入容量或输入信息增量的代数诊断

NumPy float64，L=48，s=8，d=16，编码器种子 11；所有对照共享同一组数值参数。GRU 按 r/z/n 门及 reset-after 候选项实现，与作者单层 GRU 的结构对应；本机已检查的 Python 环境没有 torch，因此**没有直接运行作者 PyTorch 实现做逐位 parity 校验**。

| 检查 | 实际结果 |
|---|---:|
| 多相位段嵌入交错后 vs 单点滑窗嵌入 | 最大差 0 |
| 多相位原始窗口交错后 vs 原窗口集合 | 最大差 0 |
| 原始硬编码 vs p=0 相位路径 | 最大差 0 |
| 稠密窗口编码的一点圆周移位等变误差 | 0 |
| 硬切编码的一点移位相对变化 | 1.176603 |
| 显式可逆 `ReLU([I;−I]x)` 重构误差 | 0 |
| 上述无信息损失嵌入仍有硬切移位相对变化 | 1.153131 |
| 仅 s 个相位平均，移位 s 点后的最大差 | 0.205445 |
| 全 L 个圆周起点的群平均，一点移位最大差 | 1.11e−16 |

硬切“相对变化”没有与粗采样格上不存在的半步/分数步平移对齐，因此不是同尺度预测误差。可逆嵌入反例的用途是证明：**这个现象不需要段内压缩或信息丢失作为前提**；分段 reshape 本身也不丢点。

重要细节：只平均 s 个相位未必对任意输入移位不变。移位跨过相位编号边界时还会循环改变每条 token 链的起始位置，最终 GRU 状态并不对 token 循环排列不变。全 L 起点平均在圆周协议下不变，但会消除绝对时间/近期方向信息，不适合作为价格预测的默认目标。

### 4.2 纯合成任务的实际训练

生成长度 48 的低噪声序列，插入 `[A,A·label]` 二点事件，label∈{−1,+1}；相同潜在样本仅改变事件相对段切点的位置。所有样本最后一点为 0，原始 `subtract_last` 完全相同。300 个训练样本只使用位置相位 2，200 个独立测试样本逐一评价 8 个相位。三个随机编码器种子 11/22/33；每个方法实际拟合同样的岭回归头，lambda=0.01，独立训练/测试随机种子。

这是一项事件符号读出任务，不是价格外推；移动事件也改变其绝对时刻，因此不能把全部任务差异只归因于切点。上一节精确窗口代数用于隔离采样格结构，这一节仅提供任务层面的失败实例。

| 方法 | 相同参数总数 | GRU 步数/样本 | 三种子平均最差相位 MSE | 样本内预测相位标准差均值 |
|---|---:|---:|---:|---:|
| 原硬切编码 + 读出 | 1793 | 6 | 2.457668 | 0.598677 |
| 8 相位共享编码均值 + 读出 | 1793 | 48 | 0.185657 | 0.163853 |
| 有限区间左补零滑窗 GRU + 读出 | 1793 | 48 | 1.008382 | 0.012766 |
| 全 48 圆周起点共享编码均值 + 读出 | 1793 | 288 | 0.022649 | 0.008943 |

输入均为同一条 48 点已观测历史，没有未来信息。圆周对照只重排/重复使用历史值，不是可部署的因果边界处理。有限左补零滑窗没有拼接真实序列两端。所有方法的编码器数值参数、隐藏维数和读出头容量相同；**计算量不同，循环步数已经明确列出**。可学习 q 的演示有额外 16 个参数，未放进这张等容量表中。

滑窗的预测变化小，但 MSE 接近 1，说明可能只是忘掉远处事件或几乎输出常数；不能用“低相位标准差”单独宣告有效。全群平均在这个刻意构造的平移不变目标上表现好，也不能推广到有近期方向的预测目标。

## 5. 决策与贡献门槛

当前决定：**直接等价否决，不给市场实验准入，也不报告新模型成果。** 已完成的是缺陷诊断、共享输入/容量的反例、真实源码对照以及唯一方案的等价审查。

后续任何贡献声明至少需要：保留历史末端/时间方向而消除人为分段起点依赖；在有限非圆周边界明确规定等变作用；证明不能重写成共享滑窗编码、相位选择或特征/预测集成；在参数、输入和计算量分别匹配的条件下，端到端训练并同时检验任务误差与相位变化，不能依靠常数化获得“鲁棒”。这些是准入条件，不是本次提出的第二个模块方案。
