# 最后一次有界稳定性修复：停止当前实现

原 autograd 的 tanh VJP 使用 `g / cosh(x)**2`，大幅输入时 cosh 与平方会溢出。本次只在独立进程中采用局部 primitive，VJP 为 `g*(1-stable_tanh(x)**2)`，递归调用同一个可微 primitive，避免缓存的普通 numpy 输出截断高阶导数。所有算法入口共享此编码器，没有修改安装包和历史代码。验证了饱和输入 ±1000 的一至三阶解析导数、候选完整目标的方向有限差分、负梯度下降和父级等价/未来不变性检查。RuntimeWarning 转为异常，本轮没有触发异常。

协议在训练之前写入并记录 SHA256，固定种子 11/29、总预算 600 秒，普通正二维每次最多 120 秒、1200 步。实际训练与检查共 7.565 秒，达到停止条件就结束，没有为了消耗预算继续训练。未加入尺度/协方差约束，也没有第二轮。

|普通正二维|接受步数|新计算梯度无穷范数|测试 MSE|随机游走 MSE|结论|
|---|---:|---:|---:|---:|---|
|seed 11|179|9.00049e-6|0.00402321|5.26158|收敛且通过性能门槛|
|seed 29|430|9.48395e-6|2.71451|1.18701|收敛但性能失败，甚至劣于随机游走|

两种子均获得 scipy 梯度停止并通过独立梯度复算，但这只证明一阶驻点，不证明全局最优。两种子两个测试任务的编码器均未达到预定塌缩判据。因而本轮失败不能归结为已观察的秩塌缩，不能为了改善得分临时增加协方差约束。已知正确编码器的估计算子 MSE 分别为 1.00866e-6 和 2.63548e-7，精确算子误差约 1e-31；表达能力存在，普通训练却不能双种子可靠恢复。

**决定：停止当前实现。** 双种子普通正对照有效性门槛失败，严格跳过候选合成网格，不能评估元适配增量，不能宣称模型创新或市场收益。稳定导数属于已有数值技术。

真正模型改造需要解决的具体缺陷：
1. 编码器、岭估计算子、读出联合目标存在不良驻点；应提出能在已知可表达二维动力学上稳定恢复预测的参数化或学习目标，而不是继续延长本实现训练。
2. 仅靠预测损失不能识别完整潜坐标基。未来若采用尺度/协方差约束，必须先给出识别依据，并在无元学习与普通适配对照中完全一致使用；约束本身不是创新。
3. 元适配的比较依赖可靠的普通学习基础。基础训练失败时，即使某个候选得分较好，也不能解释为元学习贡献。

普通与 `python -O` 独立读回验证均通过四行结果、预测、最新梯度和历史文件哈希。所有新产物只在 stable_final，历史结果保留；没有读取市场数据，没有提交。

## 验证命令
在 prototype 目录运行：
```bash
python optimization_audit/stable_final/run.py --verify
python -O optimization_audit/stable_final/run.py --verify
```
父级验证命令仍保留，未覆盖父级结果：
```bash
python optimization_audit/verify.py
python -O optimization_audit/verify.py
python verify_parent.py
```
父级验证器会重写它自己的 verification.json，因此不要在随后继续核验本轮历史哈希时运行它；父级原代码的 cosh 警告不代表本轮修复失败。
