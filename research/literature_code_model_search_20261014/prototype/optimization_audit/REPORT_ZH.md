# 同一候选的有界优化审计

## 结论边界
本轮没有换题，也没有访问任何市场价格。只实施一项已有的计算修复：用高阶自动微分替代嵌套中心有限差分。没有加入防塌缩约束、改变编码器尺度、调节 alpha 或改动原生成器。该修复不算模型创新。新正控制是观察旧结果之后建立的诊断，不是为赢市场重新定义任务。

## 先核实原预算与实际优化步
原 protocol 总预算1200秒，外层 maxiter=8，maxfun=180，16维参数。一次完整中心差分外层 value+gradient 消耗33次共同目标调用；candidate 每次共同目标对两个任务合计58次内层/查询 loss 计算。180调用仅能完成5批完整外层梯度，并进入第6批，不等于180步。
重放原设置，通过 callback 记录实际接受步：

|seed|candidate|no_adaptation|pretrain_adapt|non_tail|
|---|---:|---:|---:|---:|
|11|3|2|2|2|
|29|1|4|4|2|

各项都在180调用处终止。旧 results 的 nit=0 是异常分支未更新的默认值，不是真实零步。旧代码还把有限差分探测点纳入 best，不保证返回点是接受迭代。本轮只返回最后接受迭代，并同时保存所有接受参数与调用值/梯度。

## 单项修复与公平性
在独立 audit.py 中实现相同数学目标与完整内层梯度的外层反传。原种子11、29，原三类过程、六种方法、tasks、ridge、alpha、初值、留尾/非留尾定义均保留。所有需训练对照统一使用同一 AD 路径、400步/1000次 value-gradient 调用上限；原过程每项20秒，正控制普通模型每项60秒。RW无需优化。共同上限并非相同 FLOPs；AD的一个 value-gradient调用也不等同旧目标的一次标量调用。实现中的两次 adapt 表达式会重复构图，调用数字指最外层 value-gradient，而不是内部 primitive 或内层loss总数。
本轮预设总计算预算900秒，实际完整训练317.512秒，独立核验1.480秒。40条记录完整保留，不以训练下降当作收敛。收敛需要 scipy success 且独立重新计算的梯度无穷范数不超过1e-4。
AD与原FD梯度相对最大差6.6006e-9，目标差4.9712e-11；未来扰动预测差为0。

## 2维已知动力学正控制
采用收缩旋转二维状态，输入前两维为 arctanh(z)，模型的 tanh 编码器能够精确表示状态；保持原1/5/20预测步长、累计读出和原切分。oracle不用于普通模型初值。

|seed|真算子oracle MSE|同样ridge估计算子oracle MSE|普通非元模型步数|普通模型测试MSE|RW MSE|独立梯度无穷范数|充分收敛|
|---|---:|---:|---:|---:|---:|---:|---|
|11|3.163e-31|1.009e-6|187|0.004011|5.261576|1.477e-5|是|
|29|1.717e-31|2.635e-7|400|2.980766|1.187005|0.112447|否|

结论：表示能力与算子预测正控制通过；普通模型仅种子11训练成功，固定双种子的训练成功门未通过。没有挑掉29，没有增加第二项修复，也没有把oracle误当成普通模型已经学会。

## 塌缩与可辨识性
原生成器状态为一维，训练目标只有标量累计预测误差，没有满秩状态恢复要求。两个相同编码坐标的显式秩一输入见证得到奇异值[1.73487,2.55165e-16]，说明该目标不保证二维编码可辨识。还存在符号翻转/坐标置换等潜坐标等价性。这个事实不证明原塌缩解是全局最优，也不能把饱和、优化困难和任务维数混为一种原因。
修复后 nonlinear 两种子中 candidate/no_adaptation/pretrain_adapt/non_tail 均在两个测试任务之一仍被判塌缩；其余任务不塌缩。表达能力正控制不塌缩。因此塌缩与原过程维数/目标欠约束相容，但根因仍只能作结构性风险判断，尚不能证明单靠可辨识约束就能解决。

## 原任务优化与增量判断
nonlinear candidate 种子11实际138步/190次value-gradient调用，梯度0.23274；种子29实际188步/279次调用，梯度4.16852，都不充分收敛。no_adaptation及pretrain_adapt达到400步仍不充分收敛。non_tail种子11仅9步，出现自动微分的cosh/sinh溢出与异常线搜索；种子29为214步也未充分收敛。异常/预算/步数上限如实保存在每行 message。
因此元适配和留尾增量仍不具备评判前提；既不能宣布创新成功，也不能用这些尚未充分优化的比较否定方法。维持同一候选及合成阶段，不进入市场，不改写旧结果。
