# 既有机制失败地图与下一轮边界

日期：2026-10-19。范围：只读既有方法、报告、决定与来源清单；没有读取 2024+ 报价、确认预测或旧权重，没有新拟合。下列成绩来自相应冻结实验的已公布结果，未在本次重新验分。各行任务、数据和评分不同，**不能跨行排名或连成改进曲线**。目标仍是有正向证据的模型或学习方法创新，不改写成负结果论文。

## 一、哪些机制已经实际试过

| 机制 | 既有结果及应保留的裁决 |
|---|---|
| 条件持续性与路径辅助 | 最新候选改变未来波动状态持续性，固定当前平稳概率与累计二阶矩。GRU 对固定持续性 CRPS **+0.183892%**，对同容量尺度 **+0.258964%**；路径辅助对仅端点 **+0.352520%**。六门仅过一门，`STOP_FIXED_CANDIDATE`。[1] |
| 路径控制的分布更新 | 主方法对同预算无路径控制改善 **0.045856%**，仅广州 2021 H20 有效，其余 **21/22** 格相同；未优于标量消融和在线 BOA-CDF。不能将一个格的六种骨干/种子计成六次独立成功。[2] |
| 动态边际形状 | conditional/global shape 为 **0.994666769 / 0.991848009**；shape+scale/scale 为 **1.017943136 / 0.994536684**。动态形状没有超过关键控制；不能靠增添分位头或改正既有评分重命名。[3] |
| 跨市场条件矩 | BCM 的既有确认分数 **0.970974738**，匹配粗化增强 **0.970963789**；两主要比较 Holm 单侧 p 均 **0.606539**。新增条件矩没有机制增益。这里的跨市场主要是共享参数与市场 ID，不是发行时输入其他市场价格。[4] |
| 符号、零龄与多步状态传播 | SMP 为最近非零符号×截断零龄的九状态模型，含 hurdle 辅助。full **1.323787**，no_clock **1.317674**，one_step **1.035092**，普通 Markov **1.023790**；未来年龄结构没有获益。[5] |
| 先验运输与目标头适配 | transport **1.116561**，固定 profile **1.211713**，当前二阶矩控制 **1.070761**，RW=1。两种窗口预算能恢复相同底层标签，不能称真实信息冷启动；学源权重与固定源权重几乎相同。[6] |
| 拍卖清算结构 | 修正日历后的 SDMC **1.225753**；尺度分离 FDMC **1.004985**。尺度分离有局部支持，随机清算与供给结构未超过必要控制；不得将未认证 bid median 视为同资产二级价格锚。[7] |
| 报告价格与范围联合学习 | summary_state **1.020229**；对去范围监督仅改善 **0.156%**，完整模型仍不胜 RW。大量 Price 位于报告 Low/High 外，不能强行采用真实同场 OHLC 约束。[8] |
| 循环响应、过滤、反馈、检索 | 已试固定/自适应响应、永久/暂态 Kalman、条件观测方差 RKN、学习创新增益、成熟/部分标签更新、反馈年龄、低秩与节点、梯度冲突、分解、残差效用记忆、输出头运输和普通有限调优。效用记忆 **0.885317940**，同条件 GRU **0.885312432**，无效用监督记忆 **0.884469378**。不能再次把常规模块组合叫新增机制。[9] |

这些结果否定的是各自固定候选，**没有证明碳价不可预测**。早期普通网络在某些开发协议中能胜 RW；后验选优、跨协议比较或挑种子均不能将其升级成方法贡献。

## 二、零回报、陈旧报价和观测时钟已经排查

旧 pre-2021 描述性诊断的零净变化比例为 EEX **2.18%**、广州 **5.27%**、湖北 **4.33%**、上海 **12.21%**、EU **1.35%**；更早广州 2021 同价评价起点只有 **2** 个。SMP 已实际加入年龄并消融；普通同价持续性、已发生日期间隔及趋势交互 Ridge 也已执行。[5,10]

“随机业务时钟＋条件半群”仅作过理论审查，未作该模型市场训练；简单 OU 加独立指数时钟的事件步条件均值退化为 AR(1)。Deep Renewal、Latent ODE、Neural Jump SDE、GRU-ODE-Bayes 和 CRU 的直接近邻已记录，不能换成 signed mark、零原子或 duration 名称就宣称原创。[10,11]

必须区分：报价相同只表示记录净变化为零；缺失日期不等于零变化；as-of 持有上次供体报价不构成新观测；缺乏成交和发布状态时不能识别无交易或陈旧价格。潜在路径不动与先涨后跌可以给出相同端点。删除零行也会改变 h 的观测步任务。

## 三、效果弱的原因，哪些有证据

1. **当前持续性机制本身效应很小。** 在已知尺度/概率、明显条件差异的合成正控中，主样本量 1,024 的总体 CRPS 改善仅约 **0.066077%**。这不是普遍上界，却说明该具体机制的理想收益量级已经很小；真实市场还要估计编码器、尺度与概率。[1]
2. **重复训练没有增加独立信息。** 重叠窗口和期限共享大量标签；多个来源可能同价，上海部分年份极稀疏，跨市场来源和产品未完全认证。它们限制可辨识性，不能从这些事实直接证明过拟合是唯一失败原因。
3. **时间外迁移与初始参照很强。** 最新 312 个候选有 103 个验证选 epoch 0，但都完成 40 轮；上一轮 132 个有 46 个选初始模型。不能将其误作漏训，也没有依据只靠延长训练解决。[1,2]
4. **观测语义缺口是真实约束。** 未知首发版本、收盘/Latest、合约换月、OHLC 字段和未公布外部量，不能通过更深网络补齐。活动/波动可预测也不推出有符号均值可预测。[5,8,10]

## 四、尚未覆盖的优先入口与严格定位

**最重要的未覆盖实验是：把其他国内市场当时可见的真实历史价格输入目标预测。** BCM 的共享训练不等于这个信息集；过去煤价公告一次注入已失败，也不等于全部供体碳价均已否定。[4,9,11]

第一步应固定日期规则 `donor_date < target_origin_date`，比较本地 Ridge、加供体日期/年龄/mask、再加真实供体价格，以及同信息普通 GRU。日字段只能支持保守日期滞后，不能认证历史首发时刻。先检验真实供体数值是否在日期信息之外增加预测价值，再决定结构实验；这是一项进入方法研究的信息资格检查，本身不是经济实证论文，也不是新算法。

价格单变量方向中，“过滤当前状态概率”也尚未做与最近持续性候选完全匹配的实验。旧模型各起点从固定 π 开始；学习当前概率会改变方差期限结构，因此与只调 ρ 不同。但 HMM/Bayes、GAS、广义 Bayesian filtering 和隐式在线学习已覆盖基础原理；旧报告 §7.2 的整体 CRPS＋KL 步仅是未执行的实例，**应列为基线，不自动立为创新**。[1]

下一候选应先给出与这些基线不同的可执行算子和合成反例，且先量化可达到的效应规模。只有在匹配控制之外保留可重复增量，才扩大市场训练。不得据旧成绩重启已停候选、打开 2024+ 救分，或把正确推导与大量运行数替代正向模型证据。
