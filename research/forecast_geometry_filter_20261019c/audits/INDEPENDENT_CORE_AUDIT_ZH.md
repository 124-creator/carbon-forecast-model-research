# 有限状态预测几何：独立数值资格审计

## 结论与边界

固定人工数值例上的资格审计 **PASS**。这只核验公式、求解器、概率传播、真分布评分和时间索引的一致性，不是模型效果结果，也不证明原创性。未读取市场数据，未运行任何正式验证网格或测试预测流。

可执行脚本为 `independent_core_audit.py`，机器收据为 `INDEPENDENT_CORE_AUDIT.json`。收据中的 `source_hashes` 绑定被审的核心源码、运行脚本和协议；最终冻结前若其中任何文件变动，必须以同一审计脚本重跑，不能沿用旧哈希的 PASS。

## 独立核验结果

| 项目 | 独立参照及覆盖 | 最大观测误差 |
|---|---|---:|
| 未来条件分布的 DP | 3 种转移，各自直接枚举 $4^h$ 状态路径，$h=1,2,3,4,5$ | 概率质量 $4.45\times10^{-16}$ |
| 当前及未来 CRPS | 对当前发射、$h=1,5,20$，共 16 例直接积分 CRPS 的 CDF 定义 | $3.11\times10^{-15}$ |
| CDF 距离 Gram | 直接积分两混合 CDF 差的平方，不调用绝对距离公式计算参照 | $3.13\times10^{-17}$ |
| 7 种 QP 几何/约束配置 | 336 例，以独立 SLSQP 在原单纯形及可选线性赔率约束上最小化原目标 | 缩放后的目标差 $2.58\times10^{-13}$ |
| QP 解的可比性 | SLSQP 336 例全部正常返回；原核心 KKT 独立报告 | 权重差 $1.69\times10^{-6}$；核心 KKT $3.53\times10^{-12}$ |
| Native CRPS + KL | 48 例，直接求原始三个 log-odds KKT 方程的根，未使用核心的低秩对偶 | 权重差 $7.37\times10^{-13}$；原 KKT $2.55\times10^{-13}$ |
| 观测污染下的真 oracle 分数 | 4 种 DGP、$h=1,5$，共 8 例，枚举状态路径与 $2^h$ 污染路径，再积分条件期望 CRPS | $7.78\times10^{-16}$ |
| 正确模型 Bayes 遗憾恒等式 | 核验条件期望 CRPS 差等于真实未来 CDF 距离 | $5.04\times10^{-17}$ |
| 未来累计标签 | 直接求 `y[t+1:t+h+1]` 的和，与运行脚本前缀和索引比较 | 0 |

SLSQP 与精确面求解器之间的最大权重差出现在弱目标变化的方向，目标差同时小于 $2.58\times10^{-13}$，核心 KKT 也在容差内。审计同时保留权重差、目标差和一阶最优条件，未只检查两个求解器输出的表面相似性。

## 必须成立的机制边界

- 两状态、非均匀平稳分布下，不同非零二次几何经过同一归一化得到相同切空间度量；本候选的方向差异不能来自 $K=2$。
- 真正重复的条件分布拆成两个状态、同时拆分平稳概率，不改变距离归一化；按原比例拆分权重也不改变预测距离和 $\chi^2$ 代价。
- 固定反射控制与未来几何同谱、同归一化，且确实改变矩阵方向。
- 所有转移行相同的情况下，未来 CDF 和未来方差几何都退化为精确零矩阵。
- 交换本协议的慢、快因子只是交换两个相同发射的中间状态；独立例核实这个状态重命名恒等式。正式错误动力学场景已在看分数前改为慢因子持久性 0.6。
- Bayes、tempered Bayes、污染似然 Bayes、native CRPS + KL 及赔率约束 QP 都保持当前发射相同的两状态之间的先验赔率。审计使用有界交叉乘积，不靠对零权重加下限来定义 log-odds。
- `eta=0` / `beta=0` 的四种调用逐位保留先验；下一次名义转移从所有单纯形顶点都得到严格正先验，最小值为 0.00675。

## 数值修复和协议核验

本次固定例实际求解了 387 行 QP，0 行触发负坐标修复或重新归一化；其中 153 行需要检查小于全支持的面。Native CRPS + KL 的 99 行正步长调用全部收敛，总计 189 个逐行 Newton 迭代，单行最多 5 次。这些是本审计的计数，不能代替正式实验计数。

协议为 4 场景、20 种子、10 家族、7 候选参数，即 5,600 个验证过滤试验及 800 条选定家族流。最后验证标签在索引 659 已成熟；第一测试预测也在观察索引 659 后发布，标签从 660 开始。静态源码审查确认，家族内和组合竞争者选择只使用经验验证 CRPS，其冻结文件在计算 oracle 状态及测试分数之前写出。正式运行后还须核查输出记录，并对所有选定测试更新复算最优条件。
