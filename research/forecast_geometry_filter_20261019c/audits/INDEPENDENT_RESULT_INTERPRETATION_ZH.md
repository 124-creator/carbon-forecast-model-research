# 固定未来几何候选：结果解释复核

日期：2026-10-19。**角色披露：本审查者此前参与了 KL 求解器算术修复，当前属于与主报告分开进行的科学解释复核，不是完全外部盲审。** 本次只读取协议、方法推导、公开结果 JSON/CSV、独立轨迹审计和新增文献审查；没有拟合、更改源码或改动结果。以下百分数统一为 `候选分数 / 对照分数 − 1`；负数表示候选更好。

## 1. STOP 正确，但必须披露 1% 门槛的可达性缺陷

原协议要求各门全部通过。本次有三门失败：相对验证集预选对照的正场景 expected CRPS 没有改善 1%；该差异 bootstrap 上端不小于零；经验 CRPS 均值也没有改善。其余门通过，独立测试轨迹审计亦为 PASS。故 `STOP_FIXED_GEOMETRY_CANDIDATE` 符合原协议，不能靠改网格、换场景或更名把本轮改判通过。[1–3]

**同时，1% 门槛在本轮固定轨迹和对照下确实不可达。** 本审查直接从每条 `SELECTED_RESULTS.csv` 记录取真实 oracle 的 expected primary 分数，除以该种子、场景在验证集已选定的对照分数；先同种子两正场景等权，再平均 20 个种子，得到：

| oracle 相对预选对照 | 比值减一 |
|---|---:|
| 稀有大冲击 | −0.77302180% |
| 频繁中等冲击 | −0.34570107% |
| 两正场景等权 | **−0.55936143%** |

真实 oracle 给出同一历史信息集下的真实未来条件分布，是 proper CRPS 条件期望的下界；它甚至拥有可行对照所没有的正确未来污染模型。故在本次已实现的固定测试轨迹和同一对照上，任何同信息集预测器的 expected CRPS 平均改善均不可能超过这个约 **0.5594% 的乐观上界**。要求至少 1% 的原资源门槛缺少对剩余可改善空间的检查。此结论是**结果后解析诊断**，不是追加实验；也不是所有可能 DGP、种子或未来研究都只能改善 0.5594% 的普遍定理。[2,4]

该门槛缺陷应保留并公开，不得事后改值重判。本轮 STOP 也不只依赖这一门：即使暂不考虑 1%，候选相对强对照的实际改善方向仍不成立。

## 2. 可保留的正向证据与阻止主张的对照

两正场景同种子等权结果如下。区间是对 20 个独立模拟种子的配对 bootstrap 区间；40 个场景—种子单元不能视作 40 个独立种子。

| 对照 | expected CRPS 相对差 | 95% 区间 | 可以得出的结论 |
|---|---:|---:|---|
| 当前 CDF 几何 | −0.451459% | [−0.501380%, −0.393969%] | 在所列污染机制中，未来方向优于只保护当前 CDF；两场景单独均为负。 |
| 同谱旋转未来几何 | −0.139992% | [−0.170440%, −0.112641%] | 给定同谱尺度，这个原方向优于预列反射方向；不证明优于所有旋转或全局最优。 |
| 保持同发射状态赔率的消融 | −0.132574% | [−0.160322%, −0.103320%] | 允许预测决策权重改变赔率在这些场景有局部效用；不表示当前观测识别了同发射隐藏状态。 |
| **未来方差几何** | **+0.008911%** | **[+0.005957%, +0.012459%]** | 全 CDF 几何没有显示超出预列未来二阶矩的增量；差异很小，不宜夸大其实际损失。 |
| **Tempered Bayes** | **+0.119871%** | **[+0.052528%, +0.179852%]** | 普通似然温度调节已提供更好的平均成绩，未来几何不能认领一般抑制异常观测的全部收益。 |
| **验证集预选对照** | **+0.082077%** | **[+0.022619%, +0.142870%]** | 主要比较方向为候选更差；对照由验证集选择，不能改用测试集上更容易战胜的对照。 |

未来方差对照在 40 个正场景—种子单元中有 39 个 expected CRPS 优于候选，Tempered Bayes 有 31 个，预选对照有 27 个。这不证明未来 CDF 与方差几何数学等价，也不否定所有可能的未来分布几何设计；它阻止的是**本固定候选已经提供不可被更简单强对照解释的有效增量**这一主张。[2]

经验 CRPS 对预选对照为 **+0.063945%**，区间 **[−0.000983%, +0.129653%]**。原门只要求均值为负，故确实失败；该区间跨零，不能另说经验分数“显著更差”。干净正确场景相对预选对照为 +0.061004%，通过原 +0.5% 非劣资源门；转移错设场景为 −0.032867%，可以保留为有限压力测试结果，但不能替代预先指定的两正场景主比较。[1,2]

## 3. 创新与碳市场解释的边界

新增文献审查已经把 CRPS 诱导度量、可预测矩阵预条件、隐式近端过滤和对混合预测分布评分的构件分别与 NGBoost、PRADA/ISD、PrO 等近邻对应。本复核读取了该审查及其代数对应，没有重新逐篇进行全文核验，也不把它的文献工作冒充自己的完整独立检索。[5]

现有框架内的具体设计可以有研究贡献，无须要求所有构件都是全新理论；但本轮剩余主张主要依赖“未来完整分布几何有非冗余且可重复的增量”。未来方差与 Tempered Bayes 的结果尚不支持这一主张。正确的定性是：**候选有可复现的局部几何效应，但未通过面向后续模型创新研究的本轮资格判断。**

此外，本轮为已知转移和 Gaussian 发射参数的四状态模拟，污染机制也是预列且可计算的；所有可行方法共享名义未来预测族，真实 oracle 只作评价。市场价格、2024+ 确认数据、碳市场信息可得性、市场制度变化与真实预测收益均未在此检验。因此数值审计 PASS、局部优势或 oracle 上界都不是实际碳价格有效性或论文投稿就绪证明。[1–4]

## 4. 独立复算与计数核对

本审查没有调用生产 `aggregate` 函数；从公开 CSV 逐场景、逐种子重算 130 个比较的均值、20 个 seed 相对值和固定 `9999` 次、随机种子 `20261019` 的配对 bootstrap 两端，与公开 `SUMMARY.json` 相应值的最大差均为 **0**。1040 条结果中的 `expected_primary` 也均恰等于 h5/h20 分数均值。[2]

计数核对：正式验证配置 5600，选中 family 流 800；1040 条汇总记录 = 800 条 family + 80 条 nominal Bayes + 80 条 fixed prior + 80 条 true oracle；模拟为 4 场景 × 20 种子 = 80 个场景—种子序列，每条 1703 观测，共 136240。独立随机种子只有 20。正式递归验证更新为 3690400 次，选中测试加额外名义 Bayes 为 901120 次。神经网络、发射和转移参数训练次数均为 0。[1–3]

此前 5600 条无评分数值资格回放与这些正式配置重复，不能相加成 11200 个独立验证实验；独立轨迹审计也不是新确认样本。未发现此次公开结果比值、区间或计数矛盾。
