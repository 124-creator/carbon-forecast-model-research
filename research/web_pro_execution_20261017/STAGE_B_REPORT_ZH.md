# Stage B：PROCEED 固定迁移实验报告

研究与运行日期：2026-10-17。

## 结论

**本次固定配置没有得到概念漂移适配增益的支持，应停止这一轮迁移方案，不追加调参。**
完整 PROCEED 的三种子平均主风险为 1.125524，普通在线 NLinear 为 1.113662，
独立重训的 no_drift 对照为 1.100613；完整机制未胜普通在线更新、去漂移对照、
RW 或既有统计参考。这里的风险越低越好，RW=1。

这是否定本次广州短窗、小样本、固定维度和优化协议下的迁移结果，不是证明
PROCEED 在其他数据或设置下无效。PROCEED 本身是已发表机制；即使迁移取得
正向结果，也不会自动变成本项目的原创方法。广州 2020/2021 均为已暴露开发区，
本报告没有独立测试、统计显著性或论文录用水平的结论。

## 3. 实际学习机制和公平比较边界

作者来源是 SJTU-DMTai/OnlineTSF 提交
`0a8646199f6dcbf5346f933508b33c5e35b5708b`；16份文件的 SHA-256 和 Git blob SHA-1
均已核对。许可依据为作者 pyproject 中的 Apache-2.0 声明；该提交未见独立
根 LICENSE，实际情况完整记录在
[vendor/proceed/LICENSE_NOTICE.md](vendor/proceed/LICENSE_NOTICE.md)，没有虚构
作者许可证文件。主入口执行未经改动的作者 NLinear 和 Proceed 类；没有执行
其 run.py 或上游完整实验框架。

三臂都为 L20/H20/C1，复用 fair_data.support 的训练、purge 和验证支持。
scaler 只由训练输入价格窗口的重复观测计算。Adam 预训 lr=.003、batch32、
最多60轮、patience12、最小改善1e-6，epoch0可以被保留，无梯度裁剪、无额外
权重衰减。预训目标为全部20个标准化未来价格。对应种子的 NLinear 初始参数
一致；每臂还使用同 seed 的独立随机数生成器排列训练批次，避免较大模型的
初始化消耗随机数而改变同臂配对的批次顺序。

PROCEED 两编码器维度为16、生成器瓶颈为4、EMA=0、默认概念范数裁剪开启。
预训遵循作者 §4.4：当前随机小批次使用先前随机训练批次的输入和完整历史标签
来估计概念差，联合训练骨干、编码器和生成器。它是历史训练集内部的合成漂移，
不声称这些随机训练批次按真实时间推进。

验证严格逐起点 t 推理，每次将完整成熟样本 t−20 作为单例 recent_batch；
其最后标签恰为 t。冻结参数，验证不产生梯度更新，完成后恢复训练 recent_batch。
因而没有把整批验证 origin 的不同 recent 标签平均后泄漏给更早 origin。
训练每轮只看合法内部验证，不计算2020/2021开发评分。

no_drift 实例化完全相同的两个编码器和生成器，但把提供给生成器的概念差
替换成 detached zeros_like。其后完整生成器仍参与训练和前向，没有使用
flag_basic，也没有从完整 PROCEED 复制已训练权重。因为输入依赖被移除，
编码器和生成器输入权重不产生有效更新；**相同模块和名义形状不代表相同的
有效函数类**。这个消融用于区分漂移信息与额外静态适配能力。

| 参数分组 | 普通在线 NLinear | PROCEED / no_drift | PROCEED 在线状态 |
|---|---:|---:|---|
| 基础线性权重 | 400 | 400 | 更新 |
| 原始基础偏置 | 20 | 20 | 按作者默认冻结 |
| 动态编码器和生成器参数 | 0 | 1844 | 冻结 |
| 生成器最后的固定适配系数 | 0 | 60 | 更新 |
| 总参数 | 420 | 2324 | 在线可训练460 |

“固定适配系数”是生成器输出端的全局偏置参数，影响输入缩放、输出缩放和
加性位移；固定指其不依赖当前概念输入，不表示它在线不能学习。作者
freeze_adapter(True) 特意保留这一组可以更新。普通 NLinear 则更新全部420个
参数，所以只战胜普通臂并不足以证明动态概念机制有效。

Stage A 神经模型按年冻结，本阶段三臂每个观测步都更新；此外本阶段独立 sampler
及验证 context 协议也有明确适配。因此，A/B数值差不能直接归因为在线更新或
漂移模块的净效应。本报告的直接机制判断只使用 Stage B 三个同频在线臂。

## 4. 每步成熟边界与实测审计

年度 cut 前重新初始化并训练，两个年度没有复用权重或在线优化器状态。
在线开始时，recent_batch 为起点 cut−21 的完整样本，最后标签是 cut−1。
随后每个预测起点 t 的函数只收到 `price[:t+1]`：

1. 构造唯一最新完整样本 s=t−20，输入 s−19..s，标签 s+1..s+20=t。
2. 保留旧 recent_batch，通过“骨干＋适配器”的完整前向计算该成熟样本的
   损失；仅对允许更新的参数执行一次 Adam（lr=.0003）。这与论文 Appendix D
   的在线路径一致，不绕过适配器来训练骨干。
3. 将 recent_batch 更新为刚成熟的样本 s。
4. 仅由 t−19..t 输入签发未来20步预测。此时不构造 t 的未来标签。

每次年度在线流使用新 Adam，不继承离线动量。每步检查旧 context 最后标签
为 t−1、新 context 最后标签为 t、当前输入最大索引为 t；冻结参数与年度在线
初始值逐项比较。完整1844个动态参数和20个基础偏置保持不变，允许学习的
固定60维系数和400维基础权重有实际更新；每份 receipt 包含起止哈希与变化量。

合成检查还验证了不完整标签请求会被拒绝、三臂初始化输出一致、前向及反向
有限、单样本输出形状正确、未来后缀扰动不会改变边界预测和更新后的状态。
合成训练后，完整模型的 context 扰动产生非零输出差，no_drift 严格为零。
这些是具体实现检查，不用于证明市场机制有效。

正式前独立静态审查已通过，记录在
[audit/AUDIT_STAGE_B_PREFLIGHT.json](audit/AUDIT_STAGE_B_PREFLIGHT.json)；它在
市场计时与正式运行启动前完成。完成后另一审查代理以独立 NumPy 前向实现
复算，结果为 **PASS**，详见
[audit/AUDIT_STAGE_B.json](audit/AUDIT_STAGE_B.json)。该审查核对4,239次在线
trace 的成熟和 context 索引、1,080个验证预测向量、18个边界预测、18个最终
在线预测和18个首步成熟损失，同时复算15行种子结果和90行六格结果。

87,617次独立数值比较中的最大绝对差为7.1054×10⁻¹⁵。保存的起止参数证实
冻结组逐元素完全一致，固定适配系数确有变化；运行器记录的逐步冻结检查也
完成核对。审查没有运行 PyTorch、反向传播或优化器，没有增加市场拟合或在线
更新次数。它是对批准数据、公式、保存状态、边界及评分的独立复算，不是一次
第三方重新训练，也没有把所有在线梯度重新执行一遍。

## 5. 交付和停止决定

18份公开 receipt 位于 `stage_b_receipts/`，包含完整预训 trace、选择轮次、
参数分组哈希、在线聚合 loss/梯度统计、成熟边界和计数；概要见
[STAGE_B_TRAINING_SUMMARY.json](STAGE_B_TRAINING_SUMMARY.json)。所有新逐点预测、
在线逐点 trace、验证预测、最佳/最终模型参数和各 recent_batch 仅保存在
`local_only/stage_b/`，没有列入发布文件。

本次执行实际完成了一个有明确反证条件的已发表机制迁移检验。四个预先明确的
比较——完整机制对普通在线、no_drift、RW、统计参考——在平均主风险上全部
未通过。继续调整维度、学习率、更新顺序或只挑有利种子会改变这次有限检验的
含义，因此本轮停止；不会将阴性结果改写为“创新已经成立”。
