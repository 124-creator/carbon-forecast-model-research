### 离线验证

每个验证起点 t 的概念参照均由起点 t−20 的完整历史样本构成，其最后标签恰为已观察价格 p_t。验证参数冻结，每条验证起点单独重建参照，不聚合未来验证起点的参照。验证结束后恢复训练 `recent_batch`。早停使用全部 20 个标准化输出的 MSE，epoch 0 是候选，patience 为 12，最小改善为 1e−6；不逐 epoch 读取 2020/2021 主评分。

审核重建了每个 fit 的 60 条验证预测，并独立核对最佳验证损失、三 horizon 的内部诊断分数及全部 18 个最佳 epoch 的选择。保存的最佳训练参照若来自非零 epoch，其每条样本也与合法训练支持匹配。随机训练 minibatch 可在 fit 已知历史内打乱；验证参照采用逐起点因果方式是明确的本地协议适配。[证据：`stage_b.py` 的 `fit`、`validation_predictions`，以及 `AUDIT_STAGE_B.json` 的 `fit_checks`。]

### 在线更新

每个 origin t 的更新函数只接收 `price[:t+1]`。它使用最新完整成熟样本 s=t−20，输入为 t−39…t−20，标签为 t−19…t。先保留上一轮参照，以包含适配器的完整前向计算该成熟样本损失并执行一次 Adam 更新；再把参照替换为刚成熟样本，最后以 t−19…t 作为当前输入预测未来 20 步。签发预测时不构造该预测的未成熟标签。

审计对全部 4,239 行 trace 的前 10 列下标进行独立逐项重建，确认目标最大下标等于 t、旧参照最大标签为 t−1、新参照最大标签为 t。也核对了每个年度初始参照和最终参照的实际数组；每个 stream 首次更新前的完整成熟样本损失由保存权重独立算回，未进行反向传播或更新。年度间重新拟合并重新初始化在线 Adam，未携带上年优化器动量。[证据：`local_only/stage_b/fits/*.npz` 的 `online_trace` 和三个 `recent_batch` 数组；公开只列聚合审核结论。]

## 3. 作者核心语义与参数冻结

作者实现固定在 `SJTU-DMTai/OnlineTSF` 的提交 `0a8646199f6dcbf5346f933508b33c5e35b5708b`。训练者已逐字节固定 16 个文件；审计者另外独立回取 `adapter/proceed.py`、`generator.py`、`down_up.py`、`up.py` 和 `models/NLinear.py` 五个核心文件，并从本地实际字节重算 Git blob SHA1，均与 GitHub 返回的不可变 blob 身份相符。连接器可能裁掉终端换行，但本地原始字节的 blob 匹配通过，因此未把格式归一化误报为逐字节差异。证据为 `PROCEED_AUTHOR_CORE_IDENTITY.json`。

对单变量标准化输入 x，作者 NLinear 先取最后值 ℓ=x_L，再将 x−ℓ送入线性骨干。概念编码器接受的是减去最后值之前的 x。完整 PROCEED 根据当前编码与已成熟参照编码之差，经 L2 范数上限 1 的裁剪和 sigmoid 瓶颈生成输入尺度 a_i、输出尺度 a_o 及偏移 q，其前向可写为：

\[
\widehat y=\operatorname{diag}(1+a_o)W\operatorname{diag}(1+a_i)
(x-\ell\mathbf1)+b+q+\ell\mathbf1.
\]

**原始骨干 bias b 不乘输出尺度。** 这一点由作者 `down_up`/`up` 的 batch 路径和单样本合并路径共同决定，审计的 NumPy 实现明确保留。概念 MLP 的 GELU 使用精确高斯 CDF，未换成 tanh 近似；生成器共享权重、bias 的广播维度及 60 个适配系数的顺序均按作者实现重建。

| 参数组 | 普通 NLinear：总数 / 在线可训练 | PROCEED 与 no_drift：总数 / 在线可训练 |
|---|---:|---:|
| 基础线性 W | 400 / 400 | 400 / 400 |
| 基础 bias | 20 / 20 | 20 / 0 |
| 概念编码器及动态生成器参数 | 0 / 0 | 1,844 / 0 |
| 最后一层固定适配 bias | 0 / 0 | 60 / 60 |
| 总数 | 420 / 420 | 2,324 / 460 |

作者 `freeze_adapter(True)` 冻结概念 MLP、生成器权重及首层 bias，保留最后 60 维固定适配 bias。`down_up` 还默认冻结基础 bias；本地实现保留了这一语义。审核从保存的年度开始/结束权重验证了 12 个 PROCEED 类 stream 中全部 **22,368 个冻结标量**完全一致；逐组哈希、最大变动量和可训练数均匹配 receipt。完整 PROCEED 的固定适配 bias 组最大变化量在各 stream 为 0.02534–0.03930，no_drift 为 0.02368–0.03505，说明这组确实参与在线更新。

训练器逐步检查冻结的参数张量；审核核对其报告总数为 **33,912 次张量检查**。这个数不能写成审计者独立读取了 33,912 份中间权重，因为这些中间数组没有保存。普通 NLinear 的 optimizer 记录复用了通用的 generator 标志，实际没有生成器；该字段对普通臂不适用，真实可训练参数已按上表及保存权重审核，不据该通用标志得出结论。

## 4. no_drift 消融与数学等价

三个臂均从头拟合，按相同 seed 初始化；完整 PROCEED 与 no_drift 的初始参数组哈希完全一致。每臂使用独立的同 seed `torch.Generator` 生成训练排列，避免构建不同模块消耗随机数后连带改变 minibatch 顺序。该排列生成逻辑已静态核查，但具体每轮排列没有单独记入 trace，审核不能把源码检查写成逐轮排列日志比对。

no_drift 保留完整概念编码器和生成器，并将概念差分置为 detached 零后送入生成器。它没有采用绕过生成器的 `flag_basic`。detach 避免对作者范数裁剪在精确零向量处求导，前向仍是作者生成器对零差分的输出。审核对已训练权重独立替换参照为零或大常数，预测差严格为 0；梯度记录也没有概念编码器或生成器第一层输入权重的非零梯度。

因此，两臂是**同名义模块、同初始化的结构消融**；去掉输入信号同时改变有效可学习容量，不能宣称有效容量完全相等。更具体地，no_drift 的适配系数对样本输入为常量，任一固定状态下可折叠为：

\[
W_{\mathrm{eff}}=\operatorname{diag}(1+a_o)W\operatorname{diag}(1+a_i),
\qquad b_{\mathrm{eff}}=b+q,
\]

即一个 NLinear 前向函数。由于在线 Adam 作用在 W 和适配参数上，其参数化与优化轨迹仍可不同；函数形式可折叠，不意味着 Adam 训练轨迹等价。这个控制臂的作用是检查输入相关概念差分是否值得保留，不能将常量尺度或额外 bias 改名为新模型贡献。[作者代码来源见文末 1–5；本段折叠关系为根据上述前向的代数推导。]

## 6. 审核可以确认与仍不能确认的部分

本次独立重建覆盖 1,080 条因果验证预测、18 条上线前边界预测、18 条最后在线预测和 18 个首次成熟样本更新前损失。所有 4,239 条在线预测均重新评分；所有成熟标签及参照的时间下标均重新计算。上线前改变未来后缀的冻结推理结果严格不变。源代码哈希、参数身份、初末冻结数组和公开聚合与私有 NPZ 的一致性均通过。

**没有保存每一步在线参数快照，因此中间 4,221 条在线预测没有逐条从其当时权重独立重建。** 审核依赖已审查的因果更新源码、已保存预测与 trace 以及初末权重，不能声称对全部优化器轨迹做了独立训练复演。离线每个 minibatch 的权重轨迹也未保存。缺少这些证据不妨碍本次评分与已保存状态的审核结论，但应限制“完整复现”的用语。

作者完整核心在本地项目的数据、长度、早停、验证参照和成熟更新约束下重新训练，不等于复现论文原始 benchmark 或作者整套原始运行环境。2020/2021 已暴露为开发集；这轮 3 个 seed 只描述初始化波动。结果能够否证本轮配置的预定增益主张，不能推导“PROCEED 在所有问题上无效”，也不能用事后调参把本轮负结果抹掉。

审核结论：保留这轮完整负结果及原冻结协议，不追加市场拟合、随机种子、更新频率或补救结构。本轮没有得到可支持发表创新或任务实用改进的概念差分证据。
