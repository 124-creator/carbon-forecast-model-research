# 目标 ridge 先验随表示更新运输：证明、退化与识别边界

日期：2026-10-18。状态：**待验证的增量学习规则假设，不是新颖性认证**。坐标变换、二次型拉回、ridge、隐式辅助学习和协方差惩罚均为已有原理。本文件不声称发明这些原理。

本次只对有限矩阵作解析推导与独立 NumPy 检查，没有市场或确认数据读取、市场拟合、神经模型运行，也没有执行 R2D2 作者核心。

## 1. 固定当前目标支持集的候选规则

设同一目标支持集有 \(n\) 行，旧、新表示为 \(X,X'\in\mathbb R^{n\times d}\)，旧头先验精度为 \(\Lambda\succ0\)，固定 \(\lambda>0\)。用不带额外 ridge 的最小二乘分解：

\[
A=\arg\min_B\|X'-XB\|_F^2,\qquad
E=X'-XA,\qquad X^\top E=0.
\]

提出的状态更新为：

\[
\boxed{\Lambda'=A^\top\Lambda A+\lambda E^\top E/n},
\qquad \Lambda_0=\lambda I.
\]

目标头仅用该目标支持标签 \(Y\) 解：

\[
B^*=(X'^\top X'/n+\Lambda')^{-1}X'^\top Y/n.
\]

目标 query 风险在新表示 \(X'_Q B^*\) 上评价。来源标签可以通过表示更新影响 \(X'\) 和 \(\Lambda'\)，但不能直接拼入目标头右端矩 \(X'^\top Y\)。这一区分仍不能自动保证没有负迁移。

旧 \(\Lambda\) 是有状态的几何；每一步把 trace 归一化或重置为 \(\lambda I\) 会改变本规则。截距若不惩罚，应与被运输的特征列分开，使用同一 support 均值对 support/query 中心化；不要对含零精度截距的整块声称严格正定。

## 2. 正定性：A 可奇异，新的表示不可失去列秩

对任意 \(v\ne0\)：

\[
v^\top\Lambda'v
=(Av)^\top\Lambda(Av)+\lambda\|Ev\|_2^2/n.
\]

两项都非负。若和为 0，则因 \(\Lambda\succ0,\lambda>0\)，有 \(Av=0\)、\(Ev=0\)，于是 \(X'v=XAv+Ev=0\)。只要 \(X'\) 满列秩，便推出 \(v=0\)，矛盾。因此 \(\Lambda'\succ0\)。

这不要求 \(A\) 可逆。旧、新子空间正交时 \(A=0\)，残差项仍能补足精度。若去掉残差项，则这种情形的先验为零，会把 ridge 偷换成 OLS。若 \(X'\) 降秩，则不能保证严格正定；当标签少于表示维度时，也不能无条件使用这个证明。

实现不应为了通过某个样本悄悄加 \(\epsilon I\)。这样的 floor 一般破坏下面的坐标性质。可预先限定维数、数值秩和拒绝策略；数学上正定不代表任意病态 GL 变换下都能保持浮点精度。

## 3. 可逆坐标变换下的预测不变性

设 \(X\) 满列秩，变化是纯坐标变换 \(X'=XC\)，\(C\) 可逆，且 query 同样有 \(X'_Q=X_QC\)。最小二乘给出 \(A=C,E=0\)，故：

\[
\Lambda'=C^\top\Lambda C,\qquad
B'^*=C^{-1}B^*,\qquad
X'_QB'^*=X_QB^*.
\]

因此该纯坐标变化的迁移分数严格为零；固定 \(\lambda I\) 的头一般没有这个性质。

更一般地，把旧、新坐标分别变成 \(XB\)、\(X'D\)，并将旧精度变成 \(B^\top\Lambda B\)，则在旧 \(X\) 满列秩时：

\[
\widetilde A=B^{-1}AD,\qquad
\widetilde E=ED,\qquad
\widetilde\Lambda'=D^\top\Lambda'D.
\]

这叫**给定初始几何后的坐标协变性**。如果另一次运行在任意新初始坐标下仍重设 \(\Lambda_0=\lambda I\)，并不等于把原初始 prior 正确运输过去，不能宣称两个从零开始的运行在所有 GL(d) 变换下都相同。

支持集上 \(E=0\) 也不够：神经表示可以在有限 support 上恰好等价，在 query 上不等价。严格不变性要求 support/query 共享同一个全局坐标映射。

## 4. 精确退化关系：历史差额是从初始值运输来的

在各步使用同一支持集、同一 \(n\) 和内积时，记 \(C_t=X_t^\top X_t/n\)。最小二乘正交性给出：

\[
C_{t+1}=A_t^\top C_tA_t+E_t^\top E_t/n.
\]

所以：

\[
D_t:=\Lambda_t-\lambda C_t,\qquad
D_{t+1}=A_t^\top D_tA_t.
\]

令 \(P_t=A_0A_1\cdots A_{t-1}\)，有闭式：

\[
\boxed{\Lambda_t
=\lambda C_t+
P_t^\top(\Lambda_0-\lambda C_0)P_t}.
\]

由此得到三个必须预先承认的结论：

- 若 \(\Lambda_0=\lambda C_0\)，整个过程恒等于当前协方差惩罚。
- 若初始特征完全白化成 \(C_0=I\)，而 \(\Lambda_0=\lambda I\)，也会在所有后续步上严格退化。将两臂都完全白化后当作不同机制比较没有意义。
- 逐列标准化通常只让协方差对角线为 1；保留的差异来自初始非对角协方差等初始几何差额。应如实表述，不能把差额说成每一步都新增的独立统计信息。

此外，若头同时使用同一个 \(C_t\)，\(\Lambda_t=\lambda C_t\) 时：

\[
B^*=\frac1{1+\lambda}C_t^{-1}(X_t^\top Y/n).
\]

这是在完整白化特征上做 ordinary ridge，也等于相应 OLS 头乘统一缩放。不是新的正则结构。

如果 transport 的支持集在步与步之间变化，上述简洁闭式需加入支持协方差变化项，不能直接照搬。若 transport 用额外无标签 target features、ridge 用较少标签的另一个 support，应明确两个协方差矩阵，不再混为同一个 \(C_t\)。

## 5. 与白化不同的情形及其限制

当 \(C_0\ne I,\Lambda_0=\lambda I\) 时，历史差额一般非零，因此本规则不总等于当前表示白化。其差别是沿表示路径保留或弱化初始 prior 几何。

相同最终表示仍可能具有不同 \(\Lambda\)：一次真正换子空间后再返回旧表示，通常不能恢复原先的 prior。于是最终预测改善有可能来自正则几何改变，未必来自最终表示新增信息。这是规则的实质行为，需要保留匹配的协方差惩罚、可学习正则、完整 profile/长 unroll 等强对照，不能只比较被冻结旧头的较弱方法。

## 6. 反向传播不能丢掉运输项

若使用 query 风险反传，新的 \(A,E,\Lambda'\) 必须参与对新表示的微分。固定旧参考 \(X,\Lambda\) 是一个明确的当前步状态约定；把新 prior detach 则是另一个不等价规则。

例如一维 \(E[x^2]=1,y=x,X'=aX,\Lambda'=a^2\lambda\)。完整预测为 \(x/(1+\lambda)\)，对 \(a\) 的导数为零。若在当前点把 \(a^2\lambda\) 当常数，得到的预测导数为：

\[
\frac{2\lambda}{a(1+\lambda)^2}x\ne0.
\]

因此前向迁移分数不变还不够，实际 Torch 实现还应另测纯 GL 切向的超梯度为零。**本目录的 NumPy 审计只核有限矩阵前向恒等，不声称已经核过 Torch 自动微分。**
