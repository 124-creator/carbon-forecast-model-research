# 跨序列共享：历史重复边界与一个尚未隔离的需求

日期：2026-10-18。父轮次：PR18 后续；父任务给定提交简写为 `1cba2eba`。本审查只使用既有公开方法、调度源码、范围说明和指定的 Stage H/O 摘要；没有读取报价文件、预测/权重数组、封存确认数据或确认成绩，没有拟合，没有修改旧研究。来源、实际阅读范围与文件身份见 [HISTORY_SOURCE_LEDGER.json](../provenance/HISTORY_SOURCE_LEDGER.json)。

## 1. 主要判断

**跨市场 pooling 已经做过。** BCM 将四个市场的训练行合并，GRU 和 H20 读出均共享，每个 token 加入已知市场 one-hot，并按市场等权训练。它还比较过本地 GRU、共享价格 GRU/LSTM、统计与 ridge 基线，以及 100/400/完整历史的学习曲线。每个预测输入仍只有本市场历史；合并样本不等于把其他市场的当期报价输入预测器。[S2–S5]

**尚未隔离的是非对称数据条件：保持源市场监督历史充足且固定，仅减少目标市场的监督窗口，检验共享表示在目标头充分适配后，是否确实减少目标预测误差。** 旧 `cap_labeled_windows` 对每个市场同时截取 cap；补充的 spread100/spread400 也同时作用于全部市场。它们不能回答“富源能否帮助贫目标”。这是本库有限审查下尚未覆盖的需求，不是文献空白证明，也不意味着普通共享网络已成为原创算法。[S4–S5]

本轮可据此推进一个有边界的开发实验。建议先直接检验目标头的适配程度，不再添加经验收益、置信度或不稳定性门控。旧 2021–2023 开发年份已经反复用于研究设计；换切分名称不能恢复独立确认身份。

## 2. 不能重复的机制—本轮仍需回答的具体问题

| 既有机制与实际范围 | 不能作为新贡献重述的内容 | 对本轮需求的影响 |
|---|---|---|
| **BCM 合并训练**：四市场、共享 GRU/读出、市场 ID、训练尺度归一化与市场等权；已有本地和共享对照。[S2–S4] | “多市场＋标准化＋共享网络＋更多窗口”；单独增加市场 ID 或等权损失。 | 可继续使用这些强基线。未隔离的是固定富源、限制目标监督支持，而非 pooling 是否存在。 |
| **BCM 信息视图与条件矩**：同市场 full/coarse 视图、blocked kernel moment，以及 augment、逐点一致性和 MCSSL 对照。[S2–S3] | 将条件矩或数据增强改称跨市场不变性；仅改正则强度、收缩或采样后重启旧机制。 | BCM 的条件关系不是不同市场条件均值相等的证明。新的共享需求必须明确哪些市场差异由目标头保留。 |

| **Stage O GAIN**：可微 ridge 读出、前向块经验增益矩阵、正特征子空间与低秩输出投影；单市场。[O1–O2] | 将前向正增益子空间称为可迁移分量；再加删块方差或“可靠性”阈值就宣称新学习原理。 | 必须把普通 ridge/profile、低秩/变量投影列作近邻。它们可作为实现组件，不能单独承担创新声明。 |
| **RRC/DSOF**：已发行 teacher 的 revision residual，经成熟前缀与上下文校准进入 fast TD；各 market×seed 独立预训。[S6–S7] | 把残差校准器换成跨市场版本、换 head 或重新设置门控，恢复已停止的主机制。 | RRC 的“共同离线设置”不等于跨市场共享参数，不能拿其失败证明 pooling 无效；也不能将其重启为本轮方案。 |
| **HSC、RUM 与 SOLID**：期限竞争、未来效用记忆、成熟近邻检索后局部头更新。[S1、S7] | 用损失/梯度 gate、检索效用、专家权重或置信记忆换名复活。 | 必要时作为明确的旧法/标准对照，不作为本轮新增机制。输入相似也不能识别不同市场的条件响应相同。 |

这些边界禁止的是把已做过或标准的结构重新包装成原创，不禁止合理使用已有组件。上一形状诊断的 STOP 沿用父任务明确决定；本轮不改概率目标来重启该候选。

## 3. 对“前向分块删除收益减不稳定项”的判断

令一次源更新为 d，目标头在支持块 A 上适配为 w_A(θ)。可定义前向块 b 上的经验收益：

```text
g_b(d) = L_b(θ, w_A(θ))
         − L_b(θ+d, w_A(θ+d)).
```

删一块得到均值与稳定性估计，再按 `mean(g) − κ·instability(g)` 决定共享，属于对经验迁移收益加稳定性惩罚或下置信界。它与 Stage O 不是完全相同的算法：O 选择输出投影，这里选择源更新；但两者都用前向目标经验收益决定保留的作用方向。小步展开后，收益首先是目标梯度与源更新方向的内积；平方损失还产生熟知的二次风险项。头的精确适配增加隐式/变量投影导数，不能使删块门控本身成为新原理。[O1]

尤其在目标更少时，删块方差会更大。“不共享”可能只是证据不足，不能识别无可迁移信号；若同一前向块又训练权重又评价权重，收益也不是独立证据。因此**不建议把这项组合立为本轮原创候选**。它若用于后续稳健性分析，应明确是标准估计/选择工具。

一个更直接且可证伪的问题是：源更新的价值是否被尚未适配的目标头系统性误判？纯代数例子为独立单位方差 x1、x2，表示 φ=x1+c·x2，目标 y=x2。风险含 1/2 时：

```text
固定错误头 β=−1：risk = .5·[1+(c+1)^2]
充分适配头 β*=c/(1+c²)：profile risk = .5/(1+c²).
```

对 c>0，提高 c 使前者变差、后者变好。这证明错头判断存在反例；不证明精确 profile 是新方法。稳定步长下，充分多步并对完整路径求导会趋向同一适配解/梯度。该等价边界应成为实验的必要对照，而不是被略去的强近邻。本轮这里只作符号推导，没有执行合成训练。

## 4. 最小公平设计建议

只选择上述一个需求。建议一次已暴露开发切点、两个事前固定的目标监督预算、固定源支持；目标市场与随机种子数由根协议按预算冻结。不能因目标效果差临时删市场或换尺度。不要同步扫描新门控、损失、表示宽度和采样规则。

必要对照按机制适用性去重：

| 对照 | 排除的解释 |
|---|---|
| 本地强 GRU；RW、统计参考与 ridge 保留为低成本锚 | 复杂共享并未超过可部署的简单预测规则。 |
| 已有 pooled GRU＋市场 ID，匹配新实验的风险目标和头设置 | 增益仅来自合并训练行或市场标识。 |
| 普通共享 encoder＋本地 heads/常规部分共享 | 增益仅来自保留市场特有读出，而非新学习算子。 |
| 同一表示与支持上的一步、充分多步目标头适配、精确 ridge/profile | 增益只是解决不足适配或数值近似；充分多步与精确解的时间成本必须同时报告。 |
| 去除待检验算子的同结构版本；若主张表示迁移，则包括常规源预训→目标适配 | 参数量、目标标签使用、初始化、训练步数或预训练预算造成表面增益。 |

有限合成反例即可在真实训练前排除逻辑错误：同 X、同响应的富源应有降方差机会；同 X、相反响应的目标必须能保留其本地映射；复制源行不能被当成增加独立信息。它们不替代真实开发结果，也不授权增开一个大候选池。

## 5. 必须先锁定的审计条件

1. **目标预算定义。** 保留完整目标价格历史作尺度/统计参考、只删训练 origin，叫“监督窗口预算诊断”，不能叫真实短历史或新市场冷启动。真实短历史设定则连尺度、参考、meta、head 与早停访问一起限制。分别列出 inner/support、meta、早停、调参用过的目标 origin 及其并集；相互重叠的 H20 标签窗口不能算独立样本。
2. **源支持固定。** 两个目标预算下，源 origin、标签、归一化、采样次数与更新权重应可核对哈希；较小目标预算嵌套于较大预算，日历跨度匹配，避免把近期性解释为样本量。
3. **共同截止时间。** 以真实日历截止界定各市场已成熟标签，不能用各自相同 row index 冒充同步可见。训练与 meta/验证的标签端分别 purge；任何源训练标签都须在对应可用时点成熟。
4. **信息共享类型。** 参数共享与输入融合分开声明。本轮建议仅参数共享；若另加跨市场报价输入，同日值不能在未核发布时间时自动视为已知，且另需消融识别新增信息的贡献。
5. **风险与资源匹配。** 所有主对照使用同一原价风险/归一化、输出锚与收缩、验证准则、初始化口径和独立 batch sampler。普通 WLS、改变 shrink、改初态可作强基线，不能充当新机制。对额外内层/head 求解如实计时计数。
6. **独立性与结论。** 共享日期、相关市场、重叠期限与多种子都不能按独立观测简单累加。新开发配置不是新的确认数据；本轮不读取旧 C、不追加市场拟合或确认评分。论文贡献需后续实际机制证据和合适的独立确认，不能由此表预先认证。
