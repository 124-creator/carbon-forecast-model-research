# 局部头适配后的辅助价值：数学边界与可证伪条件

日期：2026-10-18。此文是理论与直接近邻边界分析，没有读取市场数据或旧确认集，没有运行模型。研究问题仍可检验，但以下双层公式不是新算法主张。

## 1. 把问题写成可核对的量

令 \(i\) 为目标序列，\(S_i\) 为已成熟历史支持集，\(Q_i\) 为随后、同样已经成熟的目标评估块，\(\theta\) 为共享表示，\(\beta_i\) 为局部预测头。用全部训练阶段可见数据定义：

\[
\beta_i^*(\theta)
=\arg\min_\beta L_{i,S}(\theta,\beta),\qquad
V_i(\theta)=L_{i,Q}(\theta,\beta_i^*(\theta)).
\]

假设内层解在局部唯一、二阶可微，并且 \(H_{\beta\beta,S}\) 可逆。隐式函数求导给出：

\[
\nabla_\theta V_i
=\partial_\theta L_{i,Q}
-H_{\theta\beta,S}\,H_{\beta\beta,S}^{-1}\nabla_\beta L_{i,Q}.
\]

所有偏导在 \((\theta,\beta_i^*(\theta))\) 计算。这里不能因为内层驻点就丢掉第二项：驻点条件是 support 的 \(\nabla_\beta L_{i,S}=0\)，不等于 query 的 \(\nabla_\beta L_{i,Q}=0\)。

如果源 \(j\) 给出候选表示步长 \(\theta_j'=\theta-\eta g_j\)，其有限步价值可以定义为：

\[
U_{ij}=V_i(\theta)-V_i(\theta_j'),\qquad
U_{ij}\approx\eta\,\nabla_\theta V_i^\top g_j.
\]

有限步重新求头会比冻结旧头更准确地回答本轮问题。但隐式超梯度、验证驱动辅助损失以及闭式内层本身都有直接已有原理。将 \(U_{ij}\) 作为权重、门控或任务选择分数不自动带来创新；它也没有对未来未知分布的无害性保证。

## 2. 一个不涉及市场的识别反例

令 \(E[x^2]=1\)、目标 \(y=x\)、单维表示 \(\phi_\theta(x)=\theta x\)。

无惩罚、\(\theta\ne0\) 时：

\[
\beta^*(\theta)=1/\theta,\qquad
\beta^*(\theta)\phi_\theta(x)=x.
\]

从 \(\theta=1\) 改成 2，若冻结 \(\beta=1\)，预测误差从 0 变为 \(E[x^2]=1\)；重新求头后误差仍为 0。于是冻结 head 所显示的负迁移，可以完全由坐标变化导致。

加入 \(\lambda\beta^2\) ridge：

\[
\beta^*(\theta)=\frac{\theta}{\theta^2+\lambda},\qquad
\hat y=\frac{\theta^2}{\theta^2+\lambda}x.
\]

此时扩大表示尺度会降低有效正则，即使表示没有获得任何新信息。这能让“适配后的辅助收益”出现假阳性。它说明本轮若采用闭式 ridge，必须控制表示尺度与 penalty 的对应关系；不能只匹配名义 \(\lambda\)。

更一般地，设计矩阵 \(F\) 变成 \(FA\)、头变成 \(A^{-1}\beta\)，函数预测相同；普通 \(\|\beta\|_2^2\) 通常不同。惩罚 \(\beta^\top(F_S^\top W F_S/N)\beta\) 在同一可逆变换下保持不变，但这是标准广义二次惩罚/白化思路，本身也不能作为新贡献。矩阵奇异、列截断和数值 floor 都会影响实际不变性，需在固定实现中明说。

## 4. 一个可测试的改动及严格的创新范围

**可测试改动：**在既定共享表示更新中，用“同一 target support 上精确重求局部头后的目标 query 风险”替换“冻结局部头下的目标风险/梯度冲突”。其定义就是上面的 \(V_i\)、\(U_{ij}\)。

这是一项机制诊断和已有双层思想的任务化实现建议。它不被本报告认证为原创方法。若根任务要继续主张新学习规则，必须在完整实现上说明它如何超出 R2D2、Auto-Lambda/AuxiLearn 的直接组合，而不只是学习辅助权重、加入一个 adapter 或增加 inner steps。

最低必要对照应在同一成熟标签、相同模型容量与计算预算下区分：

- 目标单独训练＋同一精确局部头；
- 共同训练＋同一精确局部头；
- 冻结旧头的辅助评价与重求头的辅助评价；
- 同一任务划分下的已有双层方法；
- 表示仅作标量缩放/可逆坐标变换的无新增信息控制；
- 源标签没有可迁移信息或已打乱对应的合成控制。

这些不是要求增加一轮无界搜索。应先在纯合成问题验证“只是换坐标”不会被当作有用迁移，再在事前冻结的有限开发对照中评价一种改动。日历 support/query 必须向前分割，所有 H 步标签完全成熟；训练阶段的 query 不能借用最终确认分区。EU/EEX 同源性也不能当作多个独立成功市场。

**停止或否定条件：**

1. 改善可由表示缩放或有效 ridge 强度改变复现，说明没有识别新增信息。
2. 只优于冻结 head 的较弱对照，未优于匹配闭式 head 的共同训练或既有双层方法，不能支持新机制。
3. 对“纯重参数化”源仍学习到非零正价值，机制解释失效。
4. 有限开发对照没有达到预先确定的实际改进阈值，停止该配置，不以继续增加源/学习率/选择指标补救。
5. 即使开发通过，也只能进入下一阶段；它不重置历史开发暴露，更不等于发表标准或确认成功。

因此，当前可以支持的是一个清楚的识别问题和必要对照。尚不能支持一个新的已验证模型名称。
