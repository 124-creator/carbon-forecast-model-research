# 预测先验运输的局部适配迁移：实验前方法定义

本轮是一个有限的学习规则改进假设。新颖性尚未成立，不能把坐标变换、岭回归、可微内层求解、辅助任务加权或几者的拼接本身称为首创。下面定义的具体变化是：评估源更新时，不仅重新拟合目标头，还运输目标头的历史二次型先验，并对表示残差补充惩罚。实证必须把它同充分头适配、当前特征二阶矩正则、可学习对角正则和固定迁移权重逐项区分。

## 1. 问题与信息范围

每次选择一条目标序列，其余符合日历截止条件的序列作为源。EEX 和 EU_REPORTED 属于相关的欧盟 ETS 序列，不允许彼此作为源。任务并不假定五条序列是五个独立市场复制。

输入为最近20条报价的三个因果通道：原始价格增量除以当前 EWMA 波动尺度，已经观察到的报价间隔变换，以及当前尺度相对最初60个增量 RMS 的对数。尺度更新系数0.94，只使用当前及过去增量。输入统一截在[-10,10]，原始价格、日期和零增量不改写。没有未来日历、未来外生变量或插值。

目标为20个累计价格变化，分别除以签发时点的尺度乘以平方根预测期。预测期1/5/20均指观测报价步，不保证对应自然日。

所有学习器以完整20维标准化平方损失训练。验证和报告恢复原价，再在1/5/20期上计算相对于同一窗口RW的MSE。训练风险与报告风险不同，这一口径是固定实验选择，本轮不声称解决风险一致性问题。

目标监督预算100或400分别划为60/20/20或240/80/80个支持、元学习和验证窗口。先定义400组的时间范围，再在每一块内均匀嵌套100组，保持各块起止时间一致；相邻块之间完整剔除20步标签重叠。报价历史仍可作为因果输入，因此这是监督窗口资源诊断，不是短历史、真实冷启动或独立样本量实验。

源市场全部完整20步标签严格早于目标第一条元学习窗口签发日期，且两种预算使用相同源历史。源训练采用64条支持、20步剔除、32条前向查询组成的历史片段；源日程与网络初始化随机流分开。

## 2. 共同骨干与头

共享编码器为60维输入、32维tanh隐藏层、8维线性表示。没有批归一化、dropout、额外输出截距或表示白化。九项机制对照使用相同初始编码器和源片段日程。

设支持表示为X，20维目标为Y，n为支持行数，定义未中心化二阶矩C=XᵀX/n和B=XᵀY/n。给定正定二次型Λ，目标局部头为

\[
W^*(X,Y,\Lambda)=(C+\Lambda)^{-1}B.
\]

它最小化样本和预测期均值平方误差，加上tr(WᵀΛW)/20。初始Λ为0.1I。源片段也用0.1岭头：在源支持拟合，在源前向查询计算平方损失，再对共享编码器求梯度。源头的固定岭核执行MIT许可下的R2D2作者数值函数，外部时间序列任务适配单独实现。

当前目标梯度来自其支持集剖面目标。运输组把当前Λ作为历史状态；对角组当前对角参数在这一步固定。二阶矩对照使用Λ=μC，因此保留C对当前表示的导数。各组的虚拟目标头及元目标也完整求导。

## 3. 唯一运输规则

一个源加权更新把目标支持表示从X变为X⁺。使用完整列秩的X求最小二乘坐标映射

\[
A=(X^\top X)^{-1}X^\top X^+,\qquad E=X^+-XA,\qquad X^\top E=0.
\]

实现用等价的薄QR与三角求解，避免显式形成上述逆矩阵。新旧表示均需完整列秩；失败明确记录，不添加结果驱动的jitter或改用伪逆。

运输并补充先验：

\[
\Lambda^+=A^\top\Lambda A+0.1\,E^\top E/n.
\]

然后在新表示和新先验上精确重解目标头。元学习查询损失对源权重求导时，必须通过A、E、Λ⁺和头求解完整反传；把新的先验detach会破坏所要求的局部性质。

### 能证明的性质

当新表示在支持和查询上均是同一个可逆线性坐标变换，即X⁺=XA及Q⁺=QA时，E=0，且W⁺=A⁻¹W。因此查询预测和元损失完全不变。完整反传对纯坐标方向的元梯度应为零。此性质仅适用于这次比较以及按规则运输的先验，不是整个神经SGD过程对任意参数重参数化不变的保证；在新坐标系重新初始化0.1I也不是相同先验。

若Λ正定、0.1为正、新X⁺完整列秩，则对任意非零z，

\[
z^\top\Lambda^+z=(Az)^\top\Lambda(Az)+0.1\|Ez\|^2/n>0.
\]

如果两项同时为零，则Az=Ez=0，从而X⁺z=0，与完整列秩矛盾。A本身可奇异，残差项提供所需惩罚。

### 不能夸大的性质

固定支持下，令C_t=X_tᵀX_t/n及D_t=Λ_t−0.1C_t，则

\[
D_{t+1}=A_t^\top D_t A_t.
\]

因此新先验等于当前二阶矩惩罚加上运输后的初始差额。若初始表示完全白化、C_0=I且Λ_0=0.1I，规则会严格退化为普通0.1C_t惩罚。当前实验没有做这种完全白化。

即使最后表示回到起点，经过不同中间子空间也可能得到不同先验；改进可能来自历史正则几何，而非永久增加表示信息。仅在有限支持上E=0，也不能保证查询表示遵循同一坐标映射。这两项反例必须随结果报告，不能省略。

## 4. 源权重与实际更新

源权重由带空源的softmax给出。初始空源质量0.5，其余源平分0.5；空源梯度为零，允许减弱整体迁移。

在当前参数θ、当前目标梯度g_T及各源梯度g_j上构造

\[
\theta^+(a)=\theta-0.01\left[g_T+\sum_j w_j(a)g_j\right].
\]

在这个虚拟编码器上，按所在方法求目标头和目标查询损失。对logits作一次学习率0.1的更新。实际编码器再使用更新后的源权重和同一批当前梯度作上述SGD更新；运输组同步更新实际Λ。没有动量、梯度裁剪、反向穿过全部历史状态或额外参数搜索。

最大600次参数更新，每10步验证，连续10次验证未改善1e−6即停止。步0也可被验证选择。恢复验证选中的编码器、先验和权重后，测试输入仅前向一次；目标测试标签不进入学习器。

## 5. 直接对照与预测锚点

| 名称 | 改变内容 | 回答的问题 |
|---|---|---|
| local_profile | 关闭源梯度，固定0.1I目标头 | 迁移是否优于同容量局部学习 |
| uniform_profile | 固定初始源权重、固定0.1I | 学习权重是否必要 |
| aux_one / aux_five | 从当前精确头温启动，在虚拟表示上作1/5步头GD | 充分局部适配是否解释收益；它们不是作者Auto-Lambda逐字重现 |
| profile | 精确重解目标头，固定0.1I，学习源权重 | 已有可微岭头与辅助元学习组合的直接锚点 |
| transport | 历史先验运输、精确头、学习源权重 | 本轮唯一主候选 |
| transport_uniform | 同一运输规则但固定源权重 | 运输与学习源权重的交互是否必要 |
| covariance_profile | 当前未中心化二阶矩正则μC，精确头、学习权重 | 是否只是普通表示尺度正则效果 |
| diagonal_profile | Λ=0.1diag(exp(r))，r由同一元学习损失更新 | 是否只是可学习岭先验效果 |
| local_gru / pooled_gru | 标准GRU16和独立市场输出头 | 强常规神经预测对照 |
| ridge | 60维共同输入加截距，五个固定正则候选由验证选择 | 强低维统计锚点 |
| rw | 累计增量预测为零 | 最小预测基准 |

二阶矩对照的μ不通过测试选择：以初始表示下固定0.1岭头的有效自由度d₀=tr[C₀(C₀+0.1I)⁻¹]为锚，取μ=8/d₀−1，使初始有效自由度一致。对角先验r初值为零，学习率0.1，范围[-4,4]固定。

两项GRU和岭回归可使用预算内全部支持与元学习标签作为监督，验证区只选参数；这避免用只消费60/240个支持标签的局部对照夸大迁移价值。GRU使用Adam、学习率0.003、权重衰减1e−4，同600步/验证频率/停止规则，输出头初始为零。岭回归的五个正则值为0.01、0.1、1、10、100。

## 6. 实证判据与发表边界

主分数是五序列、两预算、三个预测期上的等权原价MSE/RW-MSE。神经方法从开始就运行17/29/43三个初始化种子，并对其损失等权；RW和岭回归每个数据情形仅执行一次，不制造重复种子。合成计时证实预算可承受后、第一次市场拟合前，把最初单种子设想扩为三种子；没有根据市场结果作此决定。所有2022开发区都已被历史研究使用，不能称未见测试。固定资源门槛为：主候选分别比profile和二阶矩对照低至少0.5%，且总分不高于RW；所有任务必须完整成功。这个门槛决定是否投入下一阶段，并不等于统计显著或发表标准。

开发证据不足时停止这个固定候选，不开新深圳或后年确认集来寻找有利子区间，不继续扩大超参数网格。即使通过，仍需另行冻结多随机种子、进一步年份以及新增来源的确认实验，并审查强基线、消融、依赖结构下的不确定性和文献新颖性。
