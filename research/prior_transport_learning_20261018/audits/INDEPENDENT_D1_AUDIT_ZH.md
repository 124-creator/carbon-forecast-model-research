## 3. 数据单位与公平配对

本轮仍使用五个既有、已暴露的开发数据文件，评价年份为 **2022**。公开 [数据准备记录](../provenance/DATA_PREPARATION.json) 分别记录 EEX EUA T3PA 2,255 行、广州 1,434 行、湖北 1,408 行、上海 1,507 行、EU reported 1,515 行，合计 **8,119 行文件记录**。独立数值复算没有再次读取这些价格文件，不能把此合计称作一个模型的训练样本数，也不能据此称为 8,119 个独立观测。

每个目标市场分别给定 100 或 400 个监督起点窗口。三段按时间排序：100 预算为 support/meta/validation 的 **60/20/20**，400 预算为 **240/80/80**，段间使用 H20 排除间隔。100 预算在对应 400 预算各段中等距抽取并保留端点，因此两种预算保留相同日历跨度。输入特征与尺度仍可使用当时全部已知历史价格，故这里控制的是**监督窗口预算**，不是没有历史行情的新市场冷启动。

每个目标的来源市场使用相同且丰富的成熟历史，其完整 H20 标签日期严格早于该目标最早 meta 起点日期；来源日程不随目标预算改变。EEX 与 EU reported 不互为转移来源，这项隔离不能使它们的评价结果变成统计独立市场。每个来源 episode 使用 64 个支持起点与 32 个查询起点，两段之间也有完整 H20 排除间隔。

独立审核逐数组核对了所有方法、种子与预算的测试起点、日期、完整标签、尺度及最后标签日期。验证段的 100 预算也与 400 预算对应子集配对。该审核同时重建了来源完整 episode 日程和 GRU 的实际采样摘要，核对各初始化种子对应的编码器初态哈希。

**三个种子是同一数据上的三次随机初始化，不是三份独立市场样本。** H20 累计标签在相邻起点间重叠；两个预算嵌套；不同市场也可能受共同政策或宏观冲击影响。这里没有基于种子数、预测条数或全部期限坐标计算独立样本标准误。

## 4. 独立重算的指标

设真实累计变化为 \(d_{i,h}=p_{i+h}-p_i\)，保存的归一化预测为 \(\hat z_{i,h}\)，当时可见尺度为 \(\sigma_i\)。原价累计预测为

\[
\hat d_{i,h}=\sigma_i\sqrt h\,\hat z_{i,h}.
\]

在每个市场 \(m\)、预算 \(b\)、期限 \(h\) 的共同起点集合上，先计算每个种子的原价平方损失，再取种子均值：

\[
L_{a,m,b,h}=\frac{1}{|\mathcal S_a|}\sum_{s\in\mathcal S_a}
 \frac{1}{n_m}\sum_i(\hat d^{(a,s)}_{i,h}-d_{i,h})^2.
\]

RW 的原价 MSE 为 \(L^{RW}_{m,h}=n_m^{-1}\sum_i d_{i,h}^2\)。主分数是

\[
S_a=\frac1{5\times2\times3}\sum_{m,b,h\in\{1,5,20\}}
 \frac{L_{a,m,b,h}}{L^{RW}_{m,h}}.
\]

这既不是先平均三个预测后评分的集成损失，也不是把所有市场原价误差合并后求一个比值。ridge 与 RW 每个市场和预算只运行一次，没有复制成三个伪种子。程序还复算全部 20 个期限的测试及验证 MSE、RW MSE、相对 MSE 和 MAE，并重新执行验证检查点选取。训练目标本身是全部 20 期**标准化累计变化 MSE**；它并不等于上述原价相对 MSE 的加权最小二乘目标，这项限制已经在实验协议中披露。

## 6. 实际计算账本

| 项目 | 独立核对的实际数量 | 口径 |
|---|---:|---|
| 神经拟合 | 330 | 11 家族 ×5 市场 ×2 预算 ×3 初始化种子 |
| ridge 预测流程 | 10 | 每个市场和预算一条 |
| ridge 候选正则解 | 50 | 每条 ridge 流程固定 5 个 alpha |
| RW 预测流程 | 10 | 无拟合 |
| 全部预测流程 | 350 | 330+10+10 |
| 神经更新步骤 | 84,010 | 按拟合收据累计，包含实际完成后被早停选择放弃的步骤 |
| 作者来源 ridge 函数调用 | 270,840 | 按实际调用计数，与各流程完成步骤 ×来源数相符 |
| 选择 step 0 的神经流程 | 59 | 按验证选取的最佳检查点计数 |
| test_forward_calls | 340 | 330 次神经测试前向 +10 次 ridge 测试矩阵乘法 |

**340 与 350 不矛盾。** RW 的 10 条曲线直接生成零累计变化，没有模型测试前向，收据计数为 0；ridge 的 10 次是 NumPy 矩阵乘法，不能把全部 340 次统称为 Torch 前向。340 次也不表示所有训练或验证前向的总数。

270,840 次来源 ridge 调用是训练内部的重复函数调用，不能算作独立拟合的预测模型或额外样本。目标头、虚拟更新和 QR 的全部内部运算没有同一口径的独立实际计数，本文不补造“全部求解器调用总数”。

选择 step 0 也不等于“没有利用监督标签”。profile 系列的 step 0 已在初始随机编码器上用目标 support 解过精确 ridge 头，通常不是 RW。只有零输出头初始化的 GRU 对照，其 step 0 预测严格对应 RW。选择 step 0 的流程仍实际执行了后续训练与验证，因而计入真实训练账本。

## 7. 审核覆盖、差异与局限

独立程序使用 Python 3.12.14、NumPy **2.3.5**；训练收据为 Python 3.12.14、NumPy **2.5.4**、Torch **2.3.1+cpu**。不能把两个 NumPy 环境写成完全相同。

审核读取 **350 份本轮专属 NPZ 和 350 份公开摘要**，进行了 **4,052,033 次数值或结构比较**。主程序与独立复算的最大绝对差为 **2.8421709430404007×10⁻¹³**，出现在 `EEX_EUA_T3PA_b100_pooled_gru_s43` 的 h20 测试原价 MSE。全部 13 模型、全部门槛、14,000 行测试/验证全期限单元、2,600 行种子均值单元均通过核对。

另外重放了五个目标的完整来源 episode 日程和 71 组不同条件下的 GRU 采样摘要，检查了六个“骨干类别 ×初始化种子”的编码器初态哈希组。来源日程和初态一致性的证据是公开运行收据及独立重建；初始化哈希没有通过读取权重张量再次计算。

本次复算没有导入 `run.py`、`learning.py` 或生产评分函数，没有执行拟合、反向传播或优化器步骤，没有读取原价 CSV、模型权重、旧研究 NPZ 或任何确认集。它验证输出之间的标签、尺度与日程一致性，但没有重新从真实报价推导标签；这部分信息时点由独立合成数据审核及静态源代码审阅补充，见 [数据审核说明](INDEPENDENT_DATA_AUDIT_ZH.md)。数值评分一致本身不能推出整个训练过程绝对无泄漏。

## 8. 复算入口与公开边界

独立指标程序只依赖 Python 标准库和 NumPy。准备本轮公开摘要和对应的本轮逐点 NPZ 后，在本研究目录运行：

```bash
python source/independent_results.py \
  --protocol provenance/PROTOCOL.json \
  --public-dir results/D1 \
  --private-dir /absolute/path/to/prior_transport_runs_20261018/local_only/D1 \
  --output-dir /absolute/path/to/audit_replay
```

`--private-dir` 必须指向本轮 D1 输出，不能用旧研究数组替代。公开仓库只含代码、协议、摘要、审核与聚合表，不含逐点价格、预测、尺度数组或训练权重。因而**仅 clone 公开仓库不能立即重做逐数组核对**；需要先依复现流程取得合法数据并重跑相同冻结任务，生成所需 NPZ。命令输出目录应使用新路径，避免覆盖本次历史审核收据。

```bash
python source/independent_data.py --output /absolute/path/to/data_synthetic_replay.json
python source/check_independent_results.py --output /absolute/path/to/metric_synthetic_replay.json
```
