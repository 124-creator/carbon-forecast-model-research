# 数据边界与运行接线的独立审核

## 结论与覆盖范围

本轮数据合成审核为 **PASS_SYNTHETIC_DATA_AND_STATIC_SCOPE**。审核在正式市场拟合前完成，只使用自造的五条不规则日期序列、正值价格和重复报价片段，没有读取市场 CSV、NPZ、模型权重或任何确认集，没有调用优化器。实际收据见 [INDEPENDENT_DATA_AUDIT.json](INDEPENDENT_DATA_AUDIT.json)，审核程序为 [independent_data.py](../source/independent_data.py)。

执行了 **1,529 项检查、7,666,975 次数组或标量比较**，最大数值差 **8.881784197001252×10⁻¹⁶**。被审计的数据源 SHA256 为 `24a24c5caba6ca0634522cc3dfd00d199de7098e797057c6cad8b07af12a6ff8`，独立审核程序 SHA256 为 `d7095d29f02df426612f1004855dd050fd47843d8eb6c5a6ad7167d955aa5fe1`。审核环境为 Python 3.12.14、NumPy 2.3.5。

## 时间边界和两种预算

使用独立循环实现的尺度、输入窗口及累计标签计算，核对生产数据 API：EWMA 初始化只使用首 60 个增量，此后递推系数为 0.94；输入为过去 20 步的标准化增量、日历间隔和尺度上下文。评价 h=1/5/20，但训练标签要求完整 H20 成熟。最后一个 H20 标签恰好可见时接受，短一个观测时拒绝；早于允许起点、超出当前可见起点、非有限价格或日期逆序均明确报错。首 60 增量完全恒定、无法形成正尺度时拒绝，不借助未来波动补值。

400 监督预算按 240/80/80 划分 support/meta/validation。100 预算在三个既有块内各取 60/20/20，保留端点并保持同一日历跨度。各段之间完整 H20 排除间隔成立。源市场完整标签日期严格早于目标最早 meta 起点，源市场池和 episode 日程在两种预算间固定。来源 episode 的 64 支持起点、32 查询起点及 H20 排除间隔均独立重建。EEX 与 EU reported 的互相来源排除也被检查。

这里的 100/400 是监督窗口数量约束；较长历史报价仍用于可见输入和尺度。重叠窗口、嵌套预算、种子重复不能当作独立样本。合成收据中的各市场行数和日期是**自造测试夹具**，不是本轮真实数据统计，不应引用到真实样本量表。

## 未来污染检查的精确含义

审核分别改动年度切点之后、来源 meta 截点之后及某个查询起点之后的合成价格，并确认应保持不变的已知特征、尺度、输入状态和训练支持保持相同。改变确实到达未来标签，因此检查不是没有实际改动的空测试。

该证据覆盖**数据构造的前缀因果性**。没有加载已训练网络，没有再做“修改真实未来价格后预测不变”的测试，不能把它写成对训练后模型的毒化预测验证。生产文件加载器的 SHA256、日期范围及五个文件名称限制经过静态阅读，真实加载器在这项审核中被禁止调用；此处没有再次核验实际市场报价值。

## 最终 runner 的静态补充审核

最终 [run.py](../source/run.py)、[learning.py](../source/learning.py) 与 [baselines.py](../source/baselines.py) 的审阅确认以下实际接线；正式源身份以 [协议](../provenance/PROTOCOL.json) 和 [独立程序冻结收据](INDEPENDENT_METRICS_FREEZE.json) 为准。

1. 数据 case 为最终计分保留 test 标签；训练、来源权重更新和早停使用 support、meta、validation。神经模型在恢复最佳验证检查点之后才运行测试前向，测试函数读取 x 和尺度。RW 只按预定输出形状生成零累计变化，标签数值不参与预测。
2. profile 输出与 GRU 输出都使用归一化累计变化单位，runner 只乘一次因果尺度与 √h 还原原价。ridge 使用同一还原规则。
3. 目标、来源和验证数据按已冻结的日期边界分离。来源标签全部完整成熟，目标 meta 在实际来源窗口之后。pooled GRU 使用独立来源采样流；同一目标预算变化不修改来源历史池。
4. 零步验证允许被选中；相同 min_delta 和耐心规则决定检查点，选择后不做额外全训练集重拟合。profile 的初始精确 ridge 头本身使用 support 标签，不能把 profile 的 step 0 描述为零输出。
5. 普通 GRU 和调参 ridge 可以使用目标 support+meta 的 80/320 个监督窗口；profile 的直接头拟合使用 support 的 60/240 个窗口，meta 通过外层学习发挥作用。两种安排的监督角色应明确披露，不能隐藏为“所有方法只用同样 60/240 个标签”。
6. 最终 baseline 配置映射已过滤非基线参数；不合格拟合明确进入失败路径并保存收据，不静默补分。11 个神经家族、两个静态家族和 350 条任务来自冻结协议。主结果只按三项资源推进条件合取决定是否继续。

上述是源级审核及数值接口检查，不是再次执行市场训练。数值独立复算补充核验了实际输出的配对、采样摘要、验证选型和任务计数，见 [D1 独立审核说明](INDEPENDENT_D1_AUDIT_ZH.md)。任何一类检查都不能单独证明方法原创、有效或可发表。
