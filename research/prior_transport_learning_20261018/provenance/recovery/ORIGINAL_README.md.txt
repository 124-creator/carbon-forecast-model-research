# 碳价格预测：先验运输与目标适配实验

**状态：全部正式实验和独立数值复核已完成；主候选未通过事前资源门槛，停止后续确认训练。当前结果不支持模型创新论文的性能主张。**

本轮在固定源市场历史、两种目标监督预算下，检验共享表示改变时运输目标岭先验的学习规则。共 13 种方法、5 条目标序列、2 种预算；11 种神经方法从开始使用 3 个初始化种子。350 条预测流程全部完成，0 失败、0 重试。

主分数越低越好，随机游走为 1：

| 方法 | 主分数 |
|---|---:|
| 随机游走 | 1.000000 |
| 当前二阶矩正则 | 1.070761 |
| 先验运输候选 | 1.116561 |
| 先验运输＋固定源权重 | 1.116568 |
| 固定岭先验＋精确适配 | 1.211713 |

候选比固定先验精确适配改善 7.8527%，但比二阶矩对照差 4.2773%，比随机游走差 11.6561%。学习源权重与固定权重的主分数差仅约 0.00000733。所有成绩来自已经暴露的 2022 年开发区，不是新的独立确认。
