## Single new rule and full predictor
A shared GRU(1,16) encodes each 60-increment window using training-only scale s_T. The parametric correction is the ordinary FULL reference-conditioned head: O(tanh(U h+V q+c)-tanh(c)), with 8 head features and O zero-initialized. This parametric base is preserved, not claimed novel.

At query i, eligible memory origins j are max(60,i-480)..i-21, so j+20<i, including during training. Each input has local past-60 RMS scale s_j>=1e-6. Preselect K=12 candidates by squared Euclidean distance between their own locally normalized 60-increment windows; tie-break by chronological index. Fewer candidates are masked, never duplicated as evidence. Candidate residual values are e[j,h]/s_j. Source labels are actually observed before each query. No latent-state labels, future prices, or externally pretrained weights. Selection never examines candidate continuation values.

Shared learned metric: zeta_i=tanh(W_m[h_i,q_i]+a_m), dimension 8, and relevance pi_ij=softmax(-mean((zeta_i-zeta_j)^2)/0.25) over eligible candidates. W_m uses deterministic orthogonal initialization for each fixed seed, a_m=0. Parameters shared across horizons. No date/age/source-row feature in this metric.

For horizon h define Omega_h[j,k]=max(0,h-abs(j-k))/h on the selected valid origins. This is a positive-semidefinite Gram matrix of normalized future-interval incidence vectors. Under a common-mean independent homoskedastic increment-error working model it is the correlation of overlapping horizon sums. It is NOT proven to be the actual covariance of the carbon residuals, which also include signal and model error.

Define M_h=Omega_h+diag(1/pi), fixed diagonal coefficient 1. The readout solves
  w_h=argmin_{1'w=1} w'M_h w
     =M_h^{-1}1/(1'M_h^{-1}1).
This unconstrained GLS-style layer may have negative weights; do not call it a convex attention mixture. Record negative-weight frequency and max L1 norm. A 1e-12 relevance floor is used only for stable arithmetic. Invalid padded entries are zero-weighted via a masked block-diagonal solve. No optimization iterations or inverse gradient approximation.

Prediction: delta_hat[i,h]=b[i,h]+s_T*parametric_correction[i,h]+s_i*(.5*tanh(beta_h))*sum_j w[i,j,h]*(e[j,h]/s_j). beta_h=0 initially, so every retrieval model starts exactly at the statistical reference. Encoder, metric, head, beta are trained jointly, not a frozen-forecaster post-processing fit. Objective is mean over all 20 horizons of original-price normalized squared error plus mean(total normalized correction squared), coefficient 1 inherited from exposed prior development; not a newly selected value.

## Matched controls, no second candidate
SOFTMAX uses w=pi. DIAGONAL replaces Omega_h with identity (regularized independent-label readout). SHUFFLED permutes rows/columns of Omega by a deterministic query-specific permutation while leaving values/relevance fixed; same spectrum and diagonal, wrong support correspondence. THIN greedily takes similarity-ranked sources separated by >=20 observation steps, then uses DIAGONAL weights; fewer sources are allowed and disclosed, this changes redundancy/support, so not identical input multiplicity. OVERLAP is the only candidate. All five share initial common parameters, loss, training support and budget. FULL without retrieval and ordinary GRU are additional neural baselines; inactive allocations are disclosed, not described as equal effective capacity.

Degenerate/equivalence checks: h=1 or nonoverlapping source intervals implies OVERLAP=DIAGONAL at fixed parameters. Uniform relevance/identity covariance implies uniform weights. With fixed metric, readout is generalized least-squares kernel smoothing and is not a new generic optimizer. beta=0 returns FULL. The working risk is minimized but actual prediction risk need not improve under biased or anticorrelated errors. A constructed negative-control covariance must be retained. Source-overlap awareness is the only prospective incremental mechanism beyond existing retrieval literature.
