## 3. 模型及学习规则

参考b由既有31成员因果高斯库生成：p=m+z，m为RW，z为AR(1)。模型选择采用过去240个创新剖面似然，60起每20观测更新，不含当前价；状态可使用当前观测更新。b[j,h]是当时签发预测，不随以后重新选择模型而回写。完整递推见core.py与协议；工作状态不等于已识别的市场状态。

共享GRU(1,16)编码60个增量，使用拟合训练子集尺度s_T。普通FULL修正为O[tanh(U(h-h_zero)+Vq+c)-tanh(c)]；q=[tanh(mu/s_T),rho*(1-v),1-v]。O零初始化。其有效骨干为已有1232参数基线，不称创新。

每个查询i的记忆来源为j∈[max(60,i−480),i−21]，严格j+20<i。用各自过去60步RMS归一化的历史输入距离选12个来源，距离平局按时间索引。选择过程不读取来源未来残差。检索值是已经成熟的e[j,h]/s_j，其中e[j,h]=p[j+h]−p[j]−b[j,h]，s_j仅由j时刻的过去输入计算。学习度量zeta=tanh(W_m[h,q]+a_m)，8维；pi=softmax(−||zeta_i−zeta_j||²/(8×0.25))。

候选重叠矩阵为Omega_h[j,k]=max(0,h−|j−k|)/h。它是归一化目标区间指示向量的Gram矩阵，因此半正定。在同均值、同方差、独立增量误差假设下描述目标和的相关性；不是实际碳价残差协方差，变量局部尺度、信号、参考模型误差都可使这个工作假设不成立。

定义M_h=Omega_h+diag(1/pi)，权重为

    w_h = M_h^{-1}1 / (1' M_h^{-1}1)
        = argmin_{1'w=1} w'M_h w.

该层用可微线性求解，不迭代搜索权重；负权重理论上允许，不称单纯形注意力。最终

    delta_hat[i,h] = b[i,h] + s_T*FULL_correction[i,h]
                     + s_i*(0.5*tanh(beta_h))*sum_j w[i,j,h]*e[j,h]/s_j.

beta从0初始化；GRU、度量、beta和输出头共同训练，而非把一个已经冻结的神经预测器拿来事后校正。平方误差加总修正幅度平方惩罚，系数1继承暴露开发设置，不是新独立选择。

## 4. 关键对照与等价边界

DIAGONAL把Omega换成I；SOFTMAX直接用pi；SHUFFLED保持Omega谱与对角但打乱来源对应；THIN先强制所选源间隔至少20再用DIAGONAL。五个检索臂全部从相同共有参数开始。FULL禁用检索，普通GRU单独从头训练。

检索及FULL对象均分配1412参数，但FULL多出的180个度量/beta参数没有数据梯度，不能称活跃容量完全匹配。普通GRU1252参数。THIN原则上可能少于12源，实际所有评价查询均取得12个，不表示来源选择等价。

固定参数下，h=1或源目标完全不重叠时，OVERLAP=DIAGONAL；beta=0回到FULL；固定度量时属于广义最小二乘核平滑。GLS、检索、残差记忆不是新概念。构造反例证明工作协方差上的方差下降，在候选均值有偏时仍可使真实MSE上升。因此没有未来风险保证、状态识别或首创证明。

## 6. 后验诊断：局部作用很小，不是再训练的候选

保存参数诊断中，候选20步目标区间的检索源对平均约10.68%发生重叠；并非Omega恒等于I。48个候选fit中12个选择初始化，其他确有学习；平均检索门幅度约0.02477。实际存档未出现负权重，不把此经验事实推广为一般定理。

结果之后固定全部参数，仅用独立对角读出替换重叠读出计算变化幅度，不训练、不评分另一个候选：20步输出变化RMS约0.002402原价单位，最大绝对变化约0.025416；h1变化仅数值精度。mean(abs(weight_change))在h20约0.003035。此诊断证明当前干预较小，不证明它是唯一失败原因，也不授权放大权重再追分。脚本与结果分别标记POSTHOC。
