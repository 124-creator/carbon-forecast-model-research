## 2. 不同市场 / 产品的边界

原始七个试点：北京 BEA、上海 SHEA、天津 TJEA、广东 GDEA、湖北 HBEA、深圳历年 SZA/现 SZEA、重庆 CQEA-1；另外独立记录福建 FJEA。页面上的机构名称变更、深圳配额年份、天津 TJEA16 等，都不是无需核对就能合并的同一合约序列。

**全国 CEA**（强制配额）和 **全国 CCER**（自愿减排信用）是两类不同产品，不能混入地方配额面板。四川转载表是二次行情来源，不等于八家交易机构对字段和单位的逐项认证。历史页面存在少量机构与合约代码互不匹配的行，审计保留，不强制纠正归属。

mean_text 是网站标注的字段，未认证为日 VWAP；'-' 表示未报/未知，不是价格零或没有交易；原文报 0 也不足以自动证明交易所停市。交易量、成交额单位及大宗/挂牌/协议等通道尚未逐市场确认。禁止事后只挑非空日期当成功样本。

## 3. 政策因素：候选而非已经可用的 PIT 因子

保留：文件 URL、公告类别、所属市场、官网当前显示的生成/发布日期（能查到时）、获取 UTC、字节数、SHA-256、HTTP 状态；来源在 policies/。

初步**逐句核对**五个政策事实：全国 2025 年度配额清缴时点为 2026-12-31；发电预分配期限 2026-06-30；钢铁/水泥/铝冶炼预分配期限 2026-04-10；北京 2025 年度预发比例 70%（分母为 2024 年核定配额）；深圳 2025 年度预分配比例 70%（分母为最近履约年度核查排放量）。两地即使都是“70%”，**分母不同，不能直接等价编码**。其余文件暂作为政策公告候选，没有从标题编造数值强度。

政策签署日期、配额所属年度、履约截止日期和**市场参与者实际首次可得日期**是四种不同时间。2026-10-23 才抓到的页面，即使页面自称早年“发布日期”，也未证明原文从那天起一直未修改。因此 policy_event_ledger.json 的条目 **全部 point_in_time_model_eligible=false**，必须先独立校验首次公布与版本历史，才可进入历史滚动预测输入；2026 年政策也不得用作新的确认性检验。湖北的两页因 HTTP 412 没有提取文件实质，不用其他网页“补齐”假装已下载。

## 4. 内容与复现

- scripts/fetch_sceex_snapshot.py：按冻结的起止日逐页获取公开转载表，在私有目录保存原 HTML、逐行原文、逐页哈希/状态审计；
- scripts/fetch_ccer_daily_2026.py：CCER 官方 JSON 索引和 2026 年日公告，默认最多 200 篇；不将累计成交额误判为日额；
- scripts/fetch_policy_snapshots.py + policies/policy_source_catalog.json：15 个官方候选 URL 可复现抓取；
- audit/：历史与新抓取的页哈希、HTTP 结果、逐市场数值覆盖率、CCER 每篇哈希及程序异常说明；
- sources/market_source_registry.json：八个地方市场与两个全国市场的独立代码、变更风险、官网入口；
- policies/policy_event_ledger.json：15 个候选公告与 5 个已核对政策事实；未取得无泄漏特征资格。

在有合法使用权的研究者计算机上、仓库本目录运行示例：

    python scripts/fetch_sceex_snapshot.py --start 2026-01-01 --end 2026-10-23 --out /path/to/private_archive/sceex_2026
    python scripts/fetch_ccer_daily_2026.py --out /path/to/private_archive/ccer_2026 --year 2026 --max-docs 200

政策下载器接受两个位置参数：第一项为来源对象的 JSON 数组，第二项为私有归档目录。来源数组存于 policies/policy_source_catalog.json 的 document_candidates 字段，可通过本地 Python 读取并传入。
