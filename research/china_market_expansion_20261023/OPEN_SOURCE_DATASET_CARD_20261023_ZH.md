## 3. 列与变量定义（不能猜）

| 字段 | 含义及限制 |
|---|---|
| date / session_date | 来源显示的日期；不是下载日或首次发布时间 |
| institution、instrument、allowance_vintage | 来源交易机构、产品、配额所属年份，未认证不能跨年份/机构合并 |
| open_text / high_text / low_text | 来源的开高低字段；只保留字面数值和缺失标记 |
| mean_text / close_text | 来源报告均价/收盘价；**不能**假定等于成交额÷成交量 |
| volume_text / turnover_text | 成交量和金额原字段；量纲、覆盖渠道、单位仍待逐机构核验 |
| trade_channel | 挂牌、协议、协商议价等方式；未知必须明确写未知 |
| source_url / retrieved_utc / raw_sha256 / source_row_index | 行级来源、抓取时间、原网页指纹和行号，不能用后补值覆盖历史 |
| policy_first_public_at / version_hash | 只有独立认证的首发时间及准确版本才可成为时间点可得政策特征 |

值状态 SOURCE_DASH、REPORTED_ZERO、EXPLICIT_NO_TRADE、HTTP_ERROR 必须区分；缺失不可填零；同一原始行可同时有重复键、量纲疑义等多个异常标签。详见 PIT_PANEL_INPUT_CONTRACT_20261023_ZH.md。

## 4. 公共元数据的免费复核

使用 Python 3 标准库，不需要 API token、付费数据库、GPU 或模型训练：
