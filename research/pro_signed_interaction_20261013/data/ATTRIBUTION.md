# Existing author data provenance

Yingying Fan (2025), DOI 10.6084/m9.figshare.28682348.v1. CC BY 4.0 as recorded in the repository's research/pro_data_packet_20261013/DATA_PACKET_MANIFEST.json. This experiment reuses the repository's exact derived CSV blobs, not new source downloads. Derived treatment: Excel date interpretation, ISO date formatting, chronological sorting; price values unchanged. Source row/date-kind fields are excluded from model features.

Author-reported frozen snapshots, not certification of exchange instruments, historical first-release times, contract rolls or depositor ownership. Guangzhou sheet-name inconsistency and numerical matches, Hubei differences, and EU product/unit limits remain as documented in the source packet. No prices from Hubei/EU or Guangzhou after 2021-12-31 were used for model fitting/scoring in Stage F. Full-file hash/structural audit is separate from predictive evaluation.

Prior baseline: prior/lowdim.py is the unchanged Stage D file from commit f78a9a659b03b70d92ca0e97664ea08b12d8eab6, used to recompute the baseline from prices, not to reuse previous prediction arrays.
