## Candidate architecture and moments
A GRU(1,16) processes the full available sequence of observed increments, zero initial state; outputs at origin i only depend on p[0:i+1]. A learned 8-dimensional feature is G_i=tanh(U h_i+V q_i+c)-tanh(c), q_i=[tanh(reference_mu_i/s_T),rho_i(1-v_i),1-v_i]. No state resetting at each query. Readout B_h is linear. Total 1232 estimated coefficients (1072 recurrent/features plus 160 analytic output coefficients). Prediction p_i+b[i,h]+s_T G_i B_h. Reference is an ordinary baseline, not economic state identification.
For each h and training origins i,j, Omega_h[i,j]=max(0,h-|i-j|)/h. This is an interval-incidence Gram matrix, not an empirical carbon residual covariance. C_h=.5 I+.5 Omega_h; P_h=C_h^{-1}, scaled so trace(P_h)=n. Weights depend only on observation-index support, not labels, features, or a fitted covariance.
CAUSAL uses U_h=diag(P_h)+2 triu(P_h,1). Its symmetric part equals P_h>0. Thus only a feature at an earlier/equal origin is paired with a later/equal residual. At fixed parameters and a correctly represented full-history conditional mean, E[J_i^T e_j]=0 for i<=j by iterated expectations. This is a pointwise population moment statement, NOT a theorem that a data-trained finite GRU, clipped optimizer or penalized fit is unbiased, optimal, identifiable, or risk safe. The full-prefix architecture avoids incorrectly invoking nested information sets for rolling windows; hidden-state sufficiency is still an assumption.
For current G, solve each output exactly:
 B_h=[G' U_h G/n + gamma G'G/n + alpha I]^{-1}G'U_h E_h/n,
with gamma=1 (same correction penalty as existing FULL), alpha=.01. Symmetric part of the system is positive definite, at least alpha I. Fixed-feature estimator is a regularized IV/estimating-equation solution, not new generic least squares.
Alternate this output solution with an encoder update using B fixed in that update:
 score_h=U_h(G B_h-E_h)+gamma G B_h;
 encoder direction =2/(20 n) sum_h sum_i (partial_theta G_i B_h)*score_h[i].
Implement score and solved B as detached during the encoder derivative. This is an estimating-equation iteration; DO NOT differentiate the profiled nonsymmetric solve and call it the same rule. For symmetric U it agrees with the partial gradient of the regularized quadratic objective; for CAUSAL it generally is not the gradient of a scalar loss. Log genuine unweighted MSE/validation, score norm, conditioning and steps, not the numerical surrogate as a predictive risk. No consistency, efficiency or convergence theorem for this nonlinear algorithm is claimed.

## Matched controls
IDENTITY: U=I, ordinary analytic ridge-head feature learning.
SYMMETRIC: U=P, temporal GLS including potentially invalid lead-feature/lag-error moments.
SHUFFLED: deterministic support permutation of P (seed202615 fixed per h), then upper-triangular causalization; same eigenvalues before causalization, valid direction but wrong overlap geometry.
FROZEN: CAUSAL head on the same random feature initialization, zero encoder updates; detects a mere readout effect.
All four plus candidate use identical recurrent/feature initialization, all-prefix information, heads, gamma,alpha and fit support. FULL_WINDOW and GRU_WINDOW newly train on60 increments, as strong outside controls. No old predictions are reused.
