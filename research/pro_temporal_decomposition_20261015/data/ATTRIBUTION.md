# Author data attribution and scope
Yingying Fan (2025), DOI 10.6084/m9.figshare.28682348.v1, CC BY 4.0 as recorded in the repository data packet. This run inherits the source and licence receipt, not a new verification of the depositor's rights or exchange definitions.

This folder contains only the first 950 records, through 2021-12-31, of the existing ascending Guangzhou author CSV. No prices or dates were changed. The original CSV is at data/parsed/figshare_28682348/guangzhou_reported.csv in the project. The CSV was originally derived by Excel date parsing and ascending sorting; this run only takes the approved prefix. source_excel_row and source_date_kind are traceability fields, never model features.

Observed quote dates are not certified release times or a complete trading calendar. The analysis is a frozen-snapshot historical simulation, not a real-time vintage replay. The full workbook's sheet-name contradiction and historical source limitations remain disclosed in the upstream data packet. Later records and other markets are not included or evaluated here.
