# 高斯 GARCH、固定 t5 GARCH 与 GARCH-FHS 统计对照

本文件说明本方标准算法实现及合成核验范围。它不是新模型，也不是某篇论文完整实验的作者代码复现。最终模块为新研究目录 `source/statistics.py`，SHA256：

`0b04f619461a937ef0adeb290153f08db03a3366daa6821d78c8cb26802c1a07`

## 1. 接口和训练边界

```python
fit_garch(price_prefix, kind="normal") -> dict
fit_garch(price_prefix, kind="t5") -> dict
forecast_garch(price, origins, params) -> sigma       # [B, 20]
standardized_atoms(kind="normal", n=31) -> atoms, weights
forecast_garch_fhs(price, origins, params,
                   draws=2048, seed=1729) -> atoms   # [B, 20, 31]
```

模块只接受调用者传入的数组，不打开市场文件。`price_prefix` 的时间边界和 purge 由主程序构建。模块保留此前缀的浮点字节 SHA，拒绝不包含同一前缀的预测序列，也拒绝早于拟合前缀末端的起点。滤波只使用至每个预测起点的可见价格。各自独立拟合高斯和固定自由度 t5；FHS 只复用高斯拟合，不再估参。

每种似然使用一组固定初值和一次 L-BFGS-B，不重启、不从多个起点挑选。返回完整每次目标函数与梯度评价轨迹、优化器退出状态、最终参数、环境版本和耗时。优化失败会返回 `eligible=False`，后续预测拒绝接纳，没有静默回退。

## 2. 单步模型与多步方差

用训练前缀原价增量的 RMS 记作 \(s\)，归一化增量为 \(r_i=(p_i-p_{i-1})/s\)。零条件均值 GARCH(1,1) 为

\[
r_i=\sqrt{v_i}\,z_i,\qquad
v_{i+1}=\omega+\alpha r_i^2+\beta v_i,
\quad \omega>0,\quad\alpha,\beta\geq0,\quad\alpha+\beta<1.
\]

初始归一化方差固定为 \(v_1=1\)。高斯版本用标准正态 \(z_i\)，t5 版本用 \(z_i=\sqrt{3/5}\,T_5\)，两者方差均为 1。一般 GARCH 递推属于已有方法；原始定义、平稳条件和似然估计见 Bollerslev（1986），本实现采用最小的 (1,1) 形式。[G1]

设 \(a_1=v_{t+1}\)，则未来条件方差满足

\[
a_{j+1}=\omega+(\alpha+\beta)a_j,\qquad
\sigma_{t,h}=s\sqrt{\sum_{j=1}^{h}a_j}.
\]

该和使用模型的零均值鞅差假设，不把未来每步误差看成已观测值。标准多步解析方差和标准化残差重采样的递推方式也可参照 `arch` 作者维护的预测文档。[G2]

为约束参数，代码对 \(\omega\) 取指数，对 \(\alpha,\beta\) 使用带剩余分量的 softmax，平稳性上界固定为 \(1-10^{-6}\)。固定起点为 \((\omega,\alpha,\beta)=(0.05,0.05,0.90)\)。有界优化最多 500 次迭代，日志并不承担根据验证或测试结果选择参数的功能。

## 3. 31 原子分布和多步形状近似

高斯及 t5 控制分别在 \(\tau_k=(k+1/2)/31\) 取分位数，再按这个 **31 点等权离散分布本身** 的总体矩精确归一到均值 0、方差 1。每个期限乘以 \(\sigma_{t,h}\)，因此点预测都保持原价 RW。

在 \(h>1\) 保持同一高斯或 t5 形状是显式预测近似：GARCH 未来条件方差随机，递归增量和的边际分布一般不等于这个固定形状，t 变量之和也一般不服从原来的 t 分布。这里解析正确的是模型下累计条件方差，不能把固定原子的缩放写成完整递归 t-GARCH 路径模拟。

评分应使用该离散预测分布的精确 CRPS：

\[
\operatorname{CRPS}(F,y)=\frac1{31}\sum_k|a_k-y|
-\frac1{2\,31^2}\sum_{k,l}|a_k-a_l|.
\]

这是带全部有序对的有限分布分数，不能使用把原子视作 iid 抽样的去对角无偏修正，也不等于连续正态或连续 t 的精确 CRPS。

## 4. 复用参数的 GARCH-FHS 路径控制

训练前缀按一步滤波得到 \(e_i=r_i/\sqrt{v_i}\)，只在这个训练池内中心化并按总体方差归一。每个预测起点以 `SeedSequence([1729, origin])` 独立确定 2,048 条残差重采样路径，因此更换批次或起点请求顺序不改变同一预测。

每条路径在当前滤波方差起步，依次生成 \(r^*_{t+j}=\sqrt{v^*_{t+j}}e^*_{t+j}\)，再将该路径刚生成的增量代入 GARCH 递推。每个期限计算累计增量的 31 个中点分位数。分位数在该期限解析标准差单位中使用主程序公共的 `regular_quantiles`：相邻间隔下限为 \(10^{-4}\)，再将 31 原子重新中心化、单位方差化，最后乘回解析 \(\sigma_{t,h}\)。

因此输出是**固定路径数估计分位数、再做 31 原子矩匹配的 FHS 近似**，不是未经压缩的 2,048 路径分布；未来尺度传播与训练残差重采样都被保留。它不使用验证或测试标签更新残差池，不在线重新拟合 GARCH。各期限独立压缩后保留的是规定的边际预测分布，不再声称 31 原子之间是一套可逐条对应的联合路径。

基础实现完成 33 项合成检查，包含两种 NLL 与 SciPy 密度对照、解析梯度的有限差分、一次固定起点拟合、闭式累计方差、未来后缀污染、错误前缀拒绝和离散 CRPS 双重求和检查。两次优化器拟合均针对合成价格，实际市场拟合次数为 0。
