# 条件分布形状诊断：独立冻结前审查

## 结论和适用范围

**当前固定实现可进入已授权的有限开发实验，没有发现执行阻断。** 本结论允许检验“控制预测均值及尺度之后，条件分布形状是否仍有可重复的预测价值”这一必要性问题。它不认证新算法，不预测市场结果，也不把已有开发年份重新视为独立确认。

核心数学与数据检查在正式冻结前已完成并向主代理报告 PASS。采样器微测及作者评分函数反例随后单独完成，执行源哈希未变。正式协议冻结记录由主代理保存；本目录的回执分别记录各自实际完成时间和当时读取的协议草稿哈希，不能将后写回执表述为全部早于正式启动。

本次实际运行只有人工数据、自动微分和模型初始化：数据/评分/聚合检查 **60 项、4,136 个数值比较**，最大绝对误差 **1.8874×10⁻¹⁵**；静态与独立采样器检查 **22 项**；固定作者函数检查 **37 项**，最大误差 **2.2204×10⁻¹⁶**。本审查的市场数据读取、确认数据读取、市场拟合、优化器更新和网络请求均为 **0**。其他代理的模型和 GARCH 合成检查不计入这些数量。

## 因果性与评分

人工序列通过 `Data.initialize` 注入，未调用 CSV 构造器。独立标量递推和显式日期不等式核实了完整 H20 的训练成熟、末 80 个验证起点、训练到验证的清除间隔，以及测试起点和全部标签留在 2022 年的条件。初始化尺度只用前 60 个增量；之后的 EWMA 使用截至自身发行时点的价格。每条历史累计目标按它自己的发行尺度标准化。训练前缀拟合的全局 RMS 是离线训练常数，不能另外宣称每个历史训练起点的该常数也按当时可见前缀重新估计。

滚动 FHS 的最近 120 个样本全部满足 `s+20≤t`，最后一个成熟样本终点恰为当前观察。对当前时点之后的价格和日期同时作人工扰动，当前特征、尺度、基价、训练经验分布及滚动分布均未变化。未成熟标签和未知特征起点会被拒绝。原始中点分位数完全退化时，在加入间距下界之前就会报错，不以人工间距制造可估计形状。

评分采用实际发行的有限概率测度：

\[
\operatorname{CRPS}(F,y)=\sum_i p_i|a_i-y|-\frac12\sum_{i,j}p_ip_j|a_i-a_j|.
\]

独立双重求和与生产排序实现、Torch 实现，以及原子和 softmax 概率的解析梯度一致；平移不变性和正尺度齐次性也通过。因此训练回到原价单位时乘以当期尺度是必要的接线，固定训练 FHS 的每期限分母与协议相符。这里不能将自距离项换成 iid 集合预测的非对角修正；31 个原子就是被评分的分布，而非需要无偏修正的 31 次随机抽样。

两个纯合成世界说明问题的可识别边界：当真实标准化形状固定而只有尺度变化，正确的动态尺度加固定形状已是相应的 oracle，增加条件形状没有额外 oracle 改善；当条件分布的均值和方差相同而形状不同，条件真分布相对静态混合分布有严格的 CRPS 改善。它们证明这个问题可以被清楚定义，**没有证明当前 GRU 能学会该差异，更没有证明碳价数据具有该差异**。

## 配对、协议与预算

冻结前发现并修正了两项实际接线细节：不同大小的预测头会消耗不同数量的初始化随机数，原先的全局 `randperm` 因而不能保证模型间批次相同；现在专用 `torch.Generator(seed=17)` 独立产生训练排列，四种主模型的四个合成人工 epoch 排列逐位一致，三个共享 GRU 的编码器初态也逐位一致。测试张量现在只含 `x/sigma`，实际预测函数不读取标签；验证函数只读取固定验证标签。外层测试标签保留用于发行后的评价和归档。

纯聚合函数使用人工 CRPS 表检查了 **65 个预测流、30 次神经拟合、10 次统计拟合** 的计划计数及五个门槛接线。两个 GARCH 估计各市场一次；GARCH-FHS 复用 Gaussian GARCH 参数，不新增拟合。任何缺失或失败预测流都会阻断推进。

主评价是先取每个市场、每个指定期限相对同格固定 FHS 的 CRPS，再对五个市场及 h1/5/20 等权平均。条件形状相对固定/滚动/全局可训练形状、形状加尺度相对仅尺度、最强统计控制，以及至少三个市场改善的五个条件必须同时通过。1% 是资源推进门槛，**不是期刊标准或显著性证据**。协议不自动运行 D2、bootstrap 或任何确认；即使通过，也只允许另行定义并冻结下一步研究。

运行预算是两进程、各单 CPU 线程、2,400 秒协作式截止。它不是操作系统硬终止保证：已经开始的验证、统计优化或预测可能越过目标时点结束。路径重定位只允许五个固定名称，重新映射后仍验证原文件 SHA 和开发日期边界，不改变数据身份。

## 固定作者评分函数：可以与不可以推断什么

独立直接载入固定 GluonTS 源文件 `DiscreteDistribution.rps`，未使用本方重写替代函数，核实 SHA256 和 Git blob 均与作者清单相符。版本限定为：

- 仓库：`awslabs/gluonts`。
- commit：`d60556ca71167a3ec1ea807b491dd982d1de2112`。
- 上游路径：`src/gluonts/torch/distributions/discrete_distribution.py`。
- 文件 SHA256：`5e0ae9f8b4815c035ae08e63e273a0a8af9bcfae93886635f7fd4a34a48892d8`。
- Git blob：`32fe342e06e048dd8775a00c84afc018cf1e81c8`。

令真分布在 −1 和 +1 各有一半概率，预测在同一支持的概率为 `(p,1−p)`，其中 `0<p<1`。该固定函数的期望损失为 `p/2`，而确切 CRPS 的期望为 `p²+(1−p)²`。例如 `p=.1` 的原函数期望为 `.05`，比真概率 `p=.5` 的 `.25` 更小；相应 proper CRPS 则为 `.82` 和 `.5`，正确偏好真分布。因此该固定函数在一般有限分布族上不是 proper score。

这不等于声称所有 DeepNPTS 版本或论文实验都有同样缺陷。此固定支持的反例也不是本实验“加权中心为零、方差为一的 31 原子”受限参数族，因而不能预先推出两个任务适配臂的实际排名。原作者 score 与 exact CRPS 的配对执行保留了可评估差别；使用已经存在的正确 CRPS 不能成为原创预测算法贡献。

## 必须保留的解释边界

所有发行分布均被约束为零累计变化均值，因此价格均值就是当前价格，均值 MSE 与 RW 相同是结构事实，不是此次训练发现。31 中点原子及间距正则也是有限近似，会改变精确零变化原子及尾部；Gaussian/t5 的多期限形状与 GARCH-FHS 路径投影应据此描述。边际 CRPS、区间覆盖和宽度不能据此认证联合路径分布。

五个来源已被用于旧开发，相关的 EU/EEX、重叠 H20 标签和相同年度均不能被当作独立重复。通过资源门槛不等于满足用户的发表目标，失败也不能证明整个市场不存在条件分布信号。本轮最有价值的结论范围就是：在固定支持、尺度、模型容量、训练预算和强统计控制下，这个具体条件形状需求有没有足够实证支持继续研究。
