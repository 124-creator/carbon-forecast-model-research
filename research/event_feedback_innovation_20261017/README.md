# EEX 数据扩展与 RRC / SOLID 真实实验

**研究状态：本轮预定研究已执行并核验；尚未形成足以支持发表的原创预测算法贡献。** RRC 未通过冻结的推进条件，SOLID 备用参照也未显示总体优于随机游走或相似检索优于近期样本。EEX 2024/2025 确认区保留，未用于模型评分。

本目录是对前一研究的追加交付，不改写历史结果。开发数据从四系列 5,864 条扩大到五系列 **8,119 条**；新增 EEX 官方 T3PA EUA 日记录共 2,681 条，其中 2,255 条开发、426 条确认。记录数、独立统计样本数和训练次数分别计量。

## 核心结果

下表均为同起点原价 MSE / 随机游走 MSE，再等权平均五系列、两个种子和 h=1/5/20。数值越低越好；模型身份在 2022 年选定，2023 年为开发评价。SOLID 是 RRC 停止后的既有方法参照，不能改写为事先一起选出的统一冠军。

| 方法 | 2023 相对 MSE | 解释 |
|---|---:|---|
| RRC 完整候选 | 0.9918290154 | 相对 RW 改善 0.817%；EEX 为 1.055949；未晋级 |
| DSOF 的共同 GRU 适配 | 0.9930043270 | 与 RRC 匹配的主对照；不是作者 DLinear 执行锚 |
| RRC 同参去前缀 | 0.9916271853 | 略低于完整模型，前缀必要性未获支持 |
| RRC 同参加性特征 | 0.9916798753 | 略低于完整模型，交互必要性未获支持 |
| SOLID 相似输入检索 | 1.0130463348 | 相对同状态静态 GRU 改善约 0.0099%，仍高于 RW |
| SOLID 仅近期样本 | 1.0128369118 | 低于相似检索，未支持距离检索的额外总体优势 |
| 同状态静态 GRU | 1.0131467835 | SOLID 的共同离线初态对照 |
| 随机游走 RW | 1.0000000000 | 每格使用相同评价起点 |

RRC 完成 20 次共同离线拟合、10 条教师流、260 条学生流和 90 条校准流，保存 380 条预测系列、2,280 个指标格。SOLID 复用离线骨干，完成 60 条实际适配流、25,332 次头部更新，另有 20 条有证明及回执的等价派生预测，共 480 个指标格。两轮正式市场执行均无失败或重跑。

公开交付包含研究代码、协议、聚合误差、独立审核及科学图。EEX 原报价、派生报价、逐起点价格预测和训练数组需要按官方来源在本地重新生成；不随公共交付分发。原作者 SOLID 的必要文件按 MIT 保留许可证；未声明再分发许可证的 DSOF 原代码以固定版本和文件清单引用。

所有内部冻结均为有时间与哈希的研究记录，不是外部预注册。2023 年已用于开发，旧上海确认段也已暴露；它们不能在后续研究中重新标记为未见测试。
