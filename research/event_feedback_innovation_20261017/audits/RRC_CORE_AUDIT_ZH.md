## 已核实的关键关系

| 项目 | 独立证据 |
|---|---|
| 训练与验证 | 训练最大标签先于首个验证起点，验证全部 H20 标签先于在线开始；越过可用日期的 H20 请求被拒绝 |
| 预训练梯度 | 实际调用两轮预训练；学生反向传播前后，教师各参数梯度保持逐元素相同，支持 detach 和分开目标的语义 |
| 教师路径缓存 | 另写逐事件联合教师—学生更新循环；190 个事件的教师输出、全部学生预测及末参数，与缓存后分支执行一致 |
| ER 前后时序 | ER 学生使用教师同次更新前的输出；TD 与当前发行使用教师该次 ER 后的输出。独立联合循环复现同一结果 |
| 价格与尺度 | 当前剩余期预测先恢复绝对价，再按旧起点价格、旧起点尺度和原期限平方根归一化；独立逐目标索引构造与全部预测一致 |
| 校准标签 | 初始无校准数据；只有当前教师签发记录的完整 H20 到期后加入回归；全 20 期限有训练目标 |
| 事件与 K 权重 | 独立按每发行事件平均的正规方程得到相同 ridge；将 K 视图完整复制一次，β、已发行修正和唯一事件数保持不变 |
| 固定重拟合频率 | 128 事件滑窗填满后仍每 5 个新增成熟事件重拟合；合成 refit 事件从 367 开始至 487，严格间隔 5 |
| 校准器读取边界 | 价格和日期数组通过当前事件访问守卫；提前读取未来元素会失败，本次合成路径全部通过 |
| 已发行预测 | 改写 cut=410 后所有未来价格，或在 cut 截断执行，cut 前教师、校准和学生预测不变；缓存无回写 |
| 退化控制 | RRC 修正严格为零时，完整预测与原 TD 分支相同 |

共比较 **65,691 个数值**，最大绝对差 **1.8263×10⁻¹⁴**。190 个事件包含 155 次教师慢更新、155 次学生慢更新、174 次学生快更新；独立联合循环的更新数也相同。合成脚本执行 4.64 秒，NumPy 2.5.4、PyTorch 2.3.1+cpu，单 CPU。

## 静态解释与范围

校准特征的完整配置为 35 维：常数 1、四个前缀摘要 u、六个当前可见上下文 v，以及 24 个 u⊗v 交互。旧前缀误差来自旧时点缓存的教师签发值；回归标签来自当前教师签发值的未来实际修订。两个对象的时间来源明确分开。

本实现选择等完整 H20 成熟后再同时纳入 20 个标签；这比逐期限成熟更新更保守，但仍覆盖 output-only 所需的第 20 期限。校准开始前与历史不足期返回零修正，不使用预训练教师对自己训练历史的回算误差暖启动。

本次合成使用两通道 GRU 输入和一条合成市场。可选历史拍卖协变量、LSTM、具体市场文件的发布时间含义和数据内容，仅在源码层面检查，不在本次合成覆盖内。尚未审查开发 runner 的配置选择、实际市场结果、作者基准完整复现或未来独立确认统计；这些应各有单独记录。

“通过因果与数值检查”不意味着改进有效。主张仍应由同信息线性/no-prefix、self-TD、输出校准、原 DSOF 及强参考对照的后来新签发预测结果判定。数学反例与边界说明见 DSOF_REVISION_REVIEW_ZH.md。
