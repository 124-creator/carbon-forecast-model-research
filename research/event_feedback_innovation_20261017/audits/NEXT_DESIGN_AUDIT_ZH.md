# 下一轮机制设计：旧 BCM 诊断与同一报价反馈的识别边界

2026-10-17。范围：只读上一轮公开开发结果、训练收据和固定源码；仅构造新的合成例子。未读取原市场价格、原权重或新确认资料，未进行市场拟合，未修改上一轮任何文件。本文不能改变旧确认结果，也不为旧 BCM 重新选型。

## 1. 决策建议

**结束用 shrink 或损失权重“救活 BCM”的方向。** 公开证据支持机制项相对小、早停较早，但没有证明 shrink=1 是失败的主要原因。更直接的数学问题是：在相同输出收缩下，完整/粗视图的总体最优预测仍满足塔性质；旧机制可以对未来失效的预测关系完全不敏感。

**同一报价的事件归组值得作为正确性要求与强基线；秩一协方差本身不足以成为新模型。** 可继续检验是否存在一个在明确可识别条件下，使用真实新增事件选择共享或本地参数更新的规则。必须保留不同期限的任务目标，不能把合法的预测修订误当噪声重复，也不能把奇异 GLS、标量 Kalman 或学习率缩放改名。

本轮结果见 [公开日志诊断](BCM_PUBLIC_LOG_DIAGNOSTIC.json)和 [合成收据](EVENT_INFORMATION_SYNTHETIC.json)。两份脚本均保留在同目录，便于独立复查。

## 2. 匹配增强为何与 BCM 接近

### 2.1 九组完整配对的证据

选择上一轮完整开发支持上的 hidden32、shrink=1、λ=1；三个切点乘三个种子共九组。每组都有相同配置的增强对照。所有数值仅来自公开收据。

| 检查 | 结果 |
|---|---:|
| 初始参数哈希完全相同 | 9/9 |
| 最终选中参数哈希仍相同 | 0/9 |
| 选中轮数相同 | 7/9 |
| BCM 选中轮数 | 最小 1，中位数 4，最大 5 |
| BCM 选中第 0 轮 | 0/9 |
| 总训练轮数 | 136 |
| 机制项整轮等于零 | 0/136 |
| 梯度裁剪触发 | 0/136 |
| 正矩比例 | 中位数 0.95，最小 0.5375 |
| λ×机制项/监督损失 | 中位数 3.7462×10⁻⁶，最大 0.001023 |
| λ×机制项/输出收缩损失 | 中位数 0.0002637，最大 0.04709 |

因此不是“两个分支根本没有不同参数更新”，也不是“正部截断使整个机制完全不工作”。例如 2023、seed17 第一轮，机制项为 2.47×10⁻⁷，输出收缩项为 7.86×10⁻³；该轮正矩比例为 1，广州对应短视图核平均权重约 0.826，不能归因于核数值全消失。

收据只保存总目标梯度范数，没有机制独立梯度、梯度夹角或逐参数更新分解。**小损失值不必然等于小参数梯度**；若不重新读取权重或拟合，不能把“机制梯度主导程度”说成已经得到直接测量。这里的结论应限于损失量级、激活和选轮行为。

### 2.2 shrink 与初始化是已有共同结构，不能单独解释差异

固定随机编码器特征 Z 下，初始化为

\[
\beta_s=\{(1+s)Z^\top WZ/N+0.01I\}^{-1}Z^\top WY/N.
\]

它就是完整输入的“监督 MSE＋输出平方收缩＋头部 ridge”目标的闭式头部解。增强和 BCM 共用该解，随后才同时训练完整、粗视图和编码器。在不受函数类和参数惩罚限制的总体情形下，输出收缩 s 对条件均值的影响为 1/(1+s)。固定 ridge 下各特征方向的相对衰减不完全相同，不能声称初始化严格等于把每个预测乘 1/2。

较早的选轮与很近的初值使两臂接近是合理解释，但属事后观察，不能证明因果。D1 已经有 s=0.1 的匹配对照：

| hidden | shrink | 增强分数 | BCM λ1 分数 | BCM 减增强 |
|---|---:|---:|---:|---:|
| 16 | 0.1 | 0.989816567 | 0.990297108 | +0.000480541 |
| 16 | 1 | 0.987843047 | 0.987888424 | +0.000045377 |
| 32 | 0.1 | 0.990150562 | 0.990477585 | +0.000327023 |
| 32 | 1 | 0.985439679 | 0.985379984 | −0.000059695 |

这些是一种子开发描述，不能作显著性判断，但不支持“只要减小收缩就能显示 BCM 作用”。完整三种子开发分数中，λ100 为 0.990763785，λ1 为 0.987512777；简单增大权重也没有产生更好的开发结果。

### 2.3 人口最优冗余与可推翻的反例

设粗信息集 \(\mathcal C\subseteq\mathcal F\)，两视图使用同一个收缩 s。忽略函数类限制和参数惩罚时，

\[
f_{\mathcal F}^*=\frac{\mathbb E[Y\mid\mathcal F]}{1+s},
\quad
f_{\mathcal C}^*=\frac{\mathbb E[Y\mid\mathcal C]}{1+s},
\quad
\mathbb E[f_{\mathcal F}^*-f_{\mathcal C}^*\mid\mathcal C]=0.
\]

所以增强监督目标的总体最优本来就满足 BCM 检查的矩条件。它可能有有限样本正则价值，但这不是对跨时期可迁移关系的识别。任意只依赖粗信息的 g 同时加到两种预测上，二者差不变，机制无法区分这种共同预测误差。

合成例中 A、B 为独立等概率 ±1，粗视图见 A，完整视图见 A、B。开发目标为 0.6A+0.2B，下一状态为 −0.6A+0.2B。三种 shrink=0/0.1/1 的开发总体预测全部满足零条件差，但下一状态相对 RW 的 MSE 分别为 3.60、3.281、2.05。该反例不声称市场实际按此方式变化；它证明零塔矩本身不能保证所需的迁移性质。

## 3. 同一报价使多个期限成熟：什么严格成立

在同一市场观察事件 s 前，令 \(\mathcal F_{s^-}\) 包含全部已观察历史、过去签发且不可回写的预测，以及事先确定的权重。第 j 个到期任务来自 origin \(o_j\)、期限 \(h_j\)，满足 \(o_j+h_j=s\)。将累计变化预测加回签发时当前价，得到两个模型的绝对价格预测 \(a_j,b_j\)。它们及标准化权重 \(w_j\) 均在新报价前可知。

新报价 \(p_s\) 到来后，配对平方损失差为

\[
D_j=w_j\{(p_s-a_j)^2-(p_s-b_j)^2\}
   =w_j(a_j^2-b_j^2)-2w_j(a_j-b_j)p_s
   =c_j+q_jp_s.
\]

若条件方差有限，

\[
\operatorname{Cov}(\mathbf D\mid\mathcal F_{s^-})
=\operatorname{Var}(p_s\mid\mathcal F_{s^-})\,\mathbf q\mathbf q^\top,
\]

所以条件协方差秩至多 1。原始误差或事先给定尺度的标准化误差也有这一性质。多期限、多模型配对可以扩展向量长度，但没有产生额外的随机报价。

必须保留以下限制：

- 这是条件于报价前信息的结论；跨事件汇总的无条件协方差可有更高秩，因为 q 和可预测均值随历史变化。
- 不能将“一个标量输入”推广为所有损失的协方差秩一。合成例的未配对平方损失协方差秩为 2，配对绝对损失差秩为 20；非线性函数可以产生高秩协方差。
- 若权重、模型选择或重算预测已依赖当前报价，q 不再是上述意义的可预测系数，不能直接套用该条件公式。
- 不同市场即使同日更新，也不能自动合成一个独立报价事件。应按市场和实际可用的报价次序定义事件；跨市场共同冲击需另建模。
- 事件归组并不自动消除跨时间依赖。估计创新的条件均值不等于已知真实条件均值，不能无条件宣称构造出鞅差。

## 4. 对置信和有效样本的影响

合成零效应例令每个独立报价事件产生 H 份完全相同的标准正态损失差。100 个事件仍只有 100 个独立随机输入。若误按 100H 个独立行计算均值方差，标准误缩小为真实值的 \(1/\sqrt H\)。

| 重复期限数 H | 错计独立行数 | 名义双侧 5% 检验的真实误报率 |
|---:|---:|---:|
| 1 | 100 | 5.00% |
| 2 | 200 | 16.58% |
| 5 | 500 | 38.07% |
| 20 | 2,000 | 66.12% |

解析值为 \(2\{1-\Phi(1.959964/\sqrt H)\}\)。十万次合成抽样也复现该结果；按事件计证据的误报率为 4.943%。这只是一个干净的 iid 重复例，不能把它当成实际碳价检验的误报率估计。

一般权重下，独立性近似是否虚增置信取决于符号。对等权平均、条件噪声系数 \(q_j\)，真实噪声方差与对角近似之比为

\[
\frac{(\sum_j q_j)^2}{\sum_j q_j^2}.
\]

同向重复时等于 H；异号抵消时可以为 0，此时忽略协方差反而高估噪声。应保留完整事件的标量聚合或事件向量，不能机械地把所有方差都乘 H。

相同问题也出现在伪重复测量的后验精度。单位高斯先验与单位观测噪声下，一个真实观测给出的后验方差为 1/2；把它误当 H=20 个独立观测会给出 1/21。这里的改正是正确的统计建模，不是新的学习原理。

## 5. 哪些更新等价，哪些不同

### 5.1 旧预测并不是同一个条件均值的重复测量

令 \(\mu_s=\mathbb E[p_s\mid\mathcal F_{s^-}]\)，则

\[
p_s-a_j=(p_s-\mu_s)+(\mu_s-a_j).
\]

第一项是当前新创新；第二项是不同历史信息集造成的可预测修订。即使所有旧预测在其签发时都完全合理，当前条件下的均值 \(\mu_s-a_j\) 也可不同。

例如当前条件均价为 10，来自四个旧起点的合理价格预测为 10、8、6、4。旧误差的当前条件均值为 0、2、4、6，平均为 3，而当前新创新的均值为 0。不能据旧误差均值 3 就断言当前预测器发生了参数漂移。把这些误差当成零均值的奇异重复测量，会强制不应成立的不同起点预测一致性。

### 5.2 一个随机创新不等于只能保留一个监督目标

对 \(W=\sum_jw_j\)、\(\bar a=\sum_jw_ja_j/W\)，有精确恒等式：

\[
\sum_jw_j(p_s-a_j)^2
=W(p_s-\bar a)^2+\sum_jw_j(a_j-\bar a)^2.
\]

第二项在报价前已可计算，但属于不同任务预测的对比结构。把全部目标直接替换成“平均预测对新报价的误差”，会删除该项及其参数梯度。

合成反例取两维参数 \((1,-1)\)、两任务设计行 \((1,0),(0,1)\)、目标 0：平均任务损失为 1，梯度为 \((1,-1)\)；平均预测的损失及梯度均为 0。另一例的单事件梯度噪声秩为 1，经验风险 Hessian 秩为 4。因此噪声的低秩不能用来推断哪些参数曲率或任务信息可以删去。

| 拟采用操作 | 数学判断 |
|---|---|
| H 个损失先求平均，再做一次普通 SGD | 等于损失求和后把该步学习率除以 H；本身不依赖样本独立假设 |
| 同一事件 H 次顺序更新改为一次批量更新 | 通常不完全相同，原因包含重算参数、步数、动量、裁剪和权重衰减；不能把差异全归因于统计去重 |
| 正确标量测量模型下用秩一协方差做 GLS | 严格等价一次标量创新更新；合成二次型差小于 9×10⁻¹⁶ |
| 用对角协方差把重复标量当 H 次 Kalman 更新 | 产生虚假精度；修正为一次更新属于经典正确模型 |
| 只保留平均预测的误差 | 改变了任务目标，并不等于对同一目标作正确协方差估计 |
| 按回归特征或信息子空间选择遗忘方向 | 已有定向遗忘/RLS 直接近邻，不能只凭“方向更新”主张新颖性 |
| 用可学习增益把一个创新映射为联合预测修正 | 处于已有神经 Kalman/创新状态模型范式；需额外明确机制差异及可识别假设 |

SIFt-RLS 已明确按回归矩阵行空间实施定向遗忘，且支持向量测量后再约化到标量情形；该处“信息子空间”与本文的“给定过去后梯度噪声秩一”不是同一个对象。[1] KalmanNet 已将增益计算替换为循环网络，并以创新更新状态；单纯增加一个学习增益不能构成新的原理。[2]

## 6. 共享失效与本地失效：需要什么识别条件

一个市场的一次新残差若写为

\[
r_{m,s}=\delta_s^{\rm shared}+\delta_{m,s}^{\rm local}+\nu_{m,s},
\]

该事件只识别两种偏移之和。即使同一时刻观察 M 个市场，自由的“一个共享偏移＋每市场一个本地偏移”仍有 M+1 个参数、只有秩 M 的设计：共享加 c、所有本地减 c 不改变预测。

合成例明确给出共同偏移为 1、所有本地为 0，与共同偏移为 0、所有本地为 1 两个观测完全相同的世界。约束本地偏移和为 0 能定义一种参数分配，但不是对因果来源的识别。只有一个市场实际变动 \((1,0,0)\) 时，该约束仍会把 1/3 分配给共享项。

值得检验的下一步必须先补足以下内容：

1. 明确共享与本地项不同的可观察设计、稳定锚、稀疏失效假设或状态转移约束，消除任意平移重分配。
2. 用多个独立新增事件及足够变化的可预测特征识别方向；不得用同一报价的多个期限充当重复的市场证据。
3. 允许模型在信息不足时保持“不区分共享/本地”的状态。一个无预兆冲击与刚发生的参数变化在初始事件可观测等价，不存在无假设的一次事件正确分类保证。
4. 跨市场资料必须在更新时已实际可用；不能因市场都写同一个日期就使用较晚发布的报价。只有上海继续更新而其他市场停留在 2023 的设计，不能用不存在的同期市场反馈辨认当期共同失效。

在这些条件未形成具体学习规则前，本轮只建议将事件归组纳入正确基线，不启动以“秩一反馈”为唯一新意的模型网格。

## 7. 最小有力对照与否证门槛

必要对照首先是**相同骨干、相同全部成熟任务损失、每真实报价一次更新**的普通在线学习。其次才比较事件相关性用于置信/遗忘的附加规则；否则很容易把学习率、更新次数或删除任务当成机制收益。若新规则最终退化为线性状态更新，必须同固定参数的标量 Kalman/RLS 或相应定向遗忘控制比较。

建议在市场拟合前固定以下合成否证：

- **重复不变性：**同一事件的同一任务记录复制十次，但保持该任务总权重不变，证据计数和结果必须不变。
- **合法修订：**无参数漂移的随机游走中，旧起点预测不同不应被解释为 H 个独立的同方向模型失败。
- **局部与共同不可识别：**对观测完全相同的两个世界必须承认不能区分，不能输出伪确定性。
- **方差变化而无均值变化：**高噪声不能自动被判断为可迁移关系失效；反之，真实方向变化必须在新标签足够成熟后才可能识别。
- **非等价任务：**不能通过把预测平均后再计误差，绕开原来各期限的风险。
- **共同支持公平性：**事件平均损失、参数更新频率、学习率及可用标签一致，才能把差异归因于新的证据或选择算子。

## 8. 时间边界

事件 s 的正确顺序是：保留所有过去已发行预测；读入当前新报价；只使 target=s 的任务成熟；基于这些已知标签更新；再发行 origin=s 的新预测。在线训练可以在旧输入上重算当前模型作为训练计算，但不能把这些重算值替换当初发行值用于历史评分，也不能用更新后的同一样本拟合损失作为“更新前已取得的独立改善证据”。

合成流中，修改 cut=18 之后的所有未来价格，不改变截至 cut 已发行的 95 个预测；旧预测无回写，成熟任务均满足 origin+h=current_event。此项只证明示例的因果边界，尚不是任何待实现新算法的市场验证。
