# v4 官方天津：初始化与学习贡献的只读诊断

日期：2026-10-19。**六个结构家族的最终预测都与各自初始化逐值相同；本轮它们优于随机游走的部分来自固定初始结构，没有新增的参数学习收益。** 原选择训练实际运行了 900 个正梯度步骤，验证均保留 epoch0，不能把结果写成“没有尝试训练”。这一事实只约束本次固定数据、损失、学习率及停止方案，不能推导架构在任何条件下都没有价值。

本诊断在 v4 完成后开展，与原五项冻结统计比较分开。作者实现了模型和官方天津适配器，本文不称外部盲审。没有新拟合、optimizer 更新、候选选择、p 值或置信区间。完整机器收据见 [V4_INITIALIZATION_AND_LEARNING_ZH.json](V4_INITIALIZATION_AND_LEARNING_ZH.json)，只读脚本见 [diagnose_v4_initialization.py](../audits/diagnose_v4_initialization.py)。原主候选仍为 `allocation_readout`，次候选仍为 `liquidity_full`。

## 1. 30 个 checkpoint 的复放结果

覆盖六家族 ×（两学习率选择 checkpoint＋三 seed 最终 refit），共 **30 个 checkpoint**。以 seed 17／29／43 各自初始化重建数值状态，逐一核对原 checkpoint 字节 SHA，并用原普通输入重新 forward。

| 核对项目 | 结果 |
|---|---|
| 12 个选择 checkpoint 的保存验证 loss | 最大复算差 **0** |
| 12 条原初始验证 loss | 最大复算差 **0** |
| 18 个 refit 的保存原价预测 | 最大复算差 **0** |
| 30 个保存 `state_dict` 对同 seed 初始化 | **所有 tensor 逐值相同** |
| 18 个 refit 对同 seed 初始函数 | 全部 993 个可构造起点的预测逐值相同 |
| 各家族三个 seed 的初始预测函数 | 逐值相同 |
| 源码、统计计划、官方输入与 manifest | 与原冻结记录一致 |

v1 MLP 的隐藏层权重随 seed 不同，但门末层为零，使三个 seed 的初始预测相同。比较时使用同 seed 数值状态；不能把隐藏随机权重之间的差异当作训练更新，也不能因为三个初始预测一致就声称这些随机权重本来完全一样。

liquidity_readout 的 JSON 保留了不同数组归约形状造成的原始风险差 **1.1102×10⁻¹⁶**；其数值参数和每个预测均逐值相同，这不是学习变化。表中净学习为零依赖精确函数相等证据，不是通过放宽误差阈值隐去实际更新。

两组相等也不仅是平均成绩碰巧一致：**allocation_readout 与 constant 的所有最终预测相同；liquidity_full 与 unconstrained 的所有最终预测相同。** 因而这轮无法把末端 MLP 对 RW 的 4.008546 个百分点归给学到的条件门，也无法用 full／unconstrained 的相同成绩证明符号约束有或没有普遍作用。

## 3. 验证保留 epoch0，实际训练并未被跳过

六家族各自尝试学习率 0.003 和 0.01，选择 seed 均为 17。**12 次选择任务全部实际执行 15 个 epoch、每次 75 个正梯度步骤，总计 900 步**；原收据均记录了回滚前非零参数变化。随后按原验证规则恢复最佳 checkpoint，再按所选 epoch 在成熟前缀上构造三 seed 最终模型。

所有家族均选 epoch0，两学习率保存的最优验证值于是完全相同，原 `(验证 loss, 学习率)` 规则按较小学习率 0.003 打破平局。这个 lr 值不表示经过验证发现 0.003 的更新预测更好。18 个最终 refit 构造的训练次数均为零，保存状态为各自初始状态。

12 条训练尝试中，所执行正 epoch 的最好验证值仍高于各自初始化，最小劣化差为 **0.0006676253**，远大于原 1e−7 改善阈值。因此本次保留 epoch0 不是隐藏在阈值内的微小改善或浮点平局造成的。训练日志中的 batch 平均损失普遍下降，验证却恶化；这些 batch 均值混合不同优化时刻，不能当作最后一个 checkpoint 在整个训练集合上的精确损失。本文另对保存 checkpoint 的完整拟合集合重新 forward，它们既然恢复初始化，完整集合风险也与初始化一致。

执行上限是 80 epoch，但这些选择任务按原 min15／patience12 规则在 15 个 epoch 后停止，**没有实际把每条训练尝试延长到 80**。本报告没有补跑更长预算，也没有用测试选择另一条轨迹。这里应分别记录“尝试训练”“保存最佳状态”“最终重新拟合的更新次数”，不能把三个阶段混为一谈。

本诊断只覆盖六结构的 12 次选择与 18 次最终构造，不把“结构 refit 零更新”推广为包含 GRU／LSTM／SWEWT 的全部 v4 50 个神经任务都没有更新。

## 4. 这轮支持什么，不支持什么

可以保留的是：有限暂时偏离响应在官方天津较近时期的本次任务中具有有用的**固定结构先验**，六家族的最终点风险均低于 RW。主 readout 的 H1／H5／H20 分别为 **0.972187932、0.947335672、0.960220018**；次 full 分别为 **0.967683414、0.944037716、0.961140959**。这些是同一组已经公开的最终预测的描述，不构成额外显著性检验。

没有获得的是：本次官方尾段上相对于自身初始函数的学习收益、末端 MLP 超过常数分配的非零预测增量，以及由训练新增的成交量系数作用。主模型与常数控制精确相同，因此不能把这次评价写成“新的神经门在新时期得到复制确认”。紧凑门之间的差异来自各自固定的初始函数；shock-size-only 的较低点风险也不应被事后改成新的主候选。

**epoch0 只能说明本固定训练／选择方案没有交付更好的保存模型。** 有限验证样本、训练与后续时期差异、损失、参数化、两档学习率及既定早停都共同界定了该结果。这里没有执行反事实预算、其他优化器或新结构，不能声称已经证明“任何训练都不可能奏效”或“该架构理论上永远无价值”。反过来，这些可能性也不能被当作已经观察到的收益，用来抹去本轮没有学习增量的结论。

原五项比较及两个块长的统计解释仍由[评分前冻结方案](../audits/V4_STATISTICAL_AUDIT_PLAN.json)及对应独立统计审计负责。本报告不以初始化对照新增比较家族或替换已完成的评分，也不把 v3 的正向学习记录与 v4 固定初始化的成绩合并成一个“始终学习成功”的结论。

## 5. 复算及数据边界

运行环境为 `/tmp/carbon-research-env/bin/python`，Python 3.12.14、NumPy 2.3.5、torch 2.14.1+cpu；导入原适配器时沿用 `/tmp/carbon-forecast-20261019d-deps` 中的既定 EWT 依赖，本诊断六家族输入没有新做 EWT 或拟合。只读脚本 SHA 为 `3071a5f3054772c7b3635a0141761a2ca2cad1663001f9d53db09fe7e12fd860`。

JSON 保存紧凑初始参数摘要、每 seed 数值状态 SHA、30 个原 `.pt` 字节 SHA、逐参数组变化、验证和预测复放、原训练收据摘要及输入／源码／统计计划身份。数值状态 SHA 对 tensor 名称、类型、形状及连续字节计算，与 `.pt` 序列化文件 SHA 是不同对象；它们分别回答“权重相同”和“原件身份相同”。未重复导出全部 MLP 数值矩阵，原二进制保持在运行目录。
