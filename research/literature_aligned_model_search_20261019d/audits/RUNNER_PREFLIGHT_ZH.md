## 时间轴和信息边界

设当年首个测试价格索引为 F。验证起点为 F−100，验证 origins 为 F−100 至 F−21，共 80 个。选择训练必须满足 t+20 < F−100，因此最后一个训练标签为 F−101，严格早于首个验证 origin；最后一个验证标签为 F−1，严格早于首个测试 origin。最终重训只纳入 t+20 < F 的已成熟标签，可以包含此前验证数据及间隔中的已成熟标签。

每个输入窗口为 tokens[t−63:t+1]，包含已知的当前 origin 价格变动；目标是 p[t+h]−p[t]，h 为 1、5、20 个观测记录。该实验因此对应观察到 p[t] 后的预测时点，不能声称在 p[t] 形成之前发行。测试 origin 与 t+20 都必须在同一年度，三个 horizon 共用起点，年度最后 20 个观测不作为预测起点。年度内权重固定；逐 origin 使用已经实现的历史观测，不进行当年测试损失驱动的更新。

## 尺度、损失和选择规则

RMS 使用 tokens[1:validation_start] 的可用验证前历史，目标二阶矩仅使用选择训练目标；最终扩大训练集时继续使用这些已固定尺度。RMS 前缀包含部分不属于最早训练输入行、但在验证前已经可得的观测，应准确称为“验证前历史”，不能声称严格只取训练特征矩阵的行。

设目标 RMS 为 s、训练目标二阶矩为 v_h，训练和验证损失满足：

`(forecast/s − target/s)^2 / (v_h/s^2) = native squared error / v_h`。

所以模型间共享原价格单位下、按训练目标尺度加权的 H1/H5/H20 损失。测试主指标另以各市场/年度/horizon 的 RW 测试 MSE 归一化，再等权汇总；二者有意不同，不能把训练权重直接称为测试权重。

每个模型的初始化和每个 epoch 都调用自身 `forward` 的实际预测计算验证损失。两个学习率分别使用 seed 17，按验证损失、再按较小学习率选择；随后以 seeds 17/29/43 新建模型，使用同一选定 epoch 数在所有测试前成熟标签上重训。测试损失不参与选 epoch、学习率或强基线家族。

epoch 0 是真实评分、真实保存的初始化状态。若选择 0，则最终重训记录 `epochs_executed=0`、零梯度步骤。选择阶段即便优化过，最终选中的仍可能是初始化；日志中的参数变化明确为“选择前”的变化。GRU/LSTM 初始化读出为零，epoch 0 对应 RW。不能把所有任务都叙述成发生了有效训练的成功拟合。

冻结协议已经消除了主指标歧义：主要报告先分别评分三个 seed 再平均的 `mean_seed_mse_over_rw`；先平均预测再评分的 `ensemble_mse_over_rw` 仅为三模型集成的次要结果。强基线按各市场/年度的历史验证损失，从 RW、drift、ridge_price、ridge_full、hgb_full、GRU、LSTM 中选择，不能用测试期最优家族替代。

## 公平性与剩余披露

full 与 readout 使用相同四通道、64 个历史记录、169 个参数和配对初始化，差别是神经门作用于每次历史创新分配，还是只调最后读出幅度。constant 是 7 参数嵌套控制，price-only 是 118 参数控制；它们不是容量匹配控制。GRU/LSTM 也用四通道与 64 记录；ridge_full 用 64，ridge_price 与 hgb_full 用 20。共同信息截止时点、验证规则和年度测试规则一致，但不能声称所有家族的容量、历史长度和调参维度都相同。

创新模型每次在 64 记录窗口起点将状态置零，是有限历史预测器。GRU/LSTM 输出 20 个累计预测坐标，但只有第 1、5、20 坐标进入目标，其他 17 个读出行包含在原始参数计数中。这些都不是时间泄露错误，但应在模型说明中保留。

源码完成标记会记录哈希是否变化，而不是自动抛错；独立统计审查仍须拒绝哈希不一致、预测缺失、不同行索引或非有限数值。对不确定性应先在每个 origin 平均 seed 损失，再配对重采样时间块，不能把三个 seed 当作三个独立市场。当前 PASS 不推导任何发表阈值，不要求任意 1%，也不支持经济永久/暂时冲击已经被识别的断言。
