CSV 列固定为 `date,volume,turnover,price_match,valid_volume`。空字段表示 NA，两个标记用 1/0，无法判断的 `price_match` 为空。只有作者记录在该日期唯一、有限价格与旧价格严格相同、成交量为有限且非负值，才有 `valid_volume=1`。重复日期或价格冲突时两项量额均为空；没有删除旧价格行，没有用先前量额或 0 填充。两个输出的日期顺序与各自旧 CSV 完全相同。

这里取得的是作者报表的 **Volume / Turnover 列**，不是从价格变化推断的成交量。字段单位、挂牌与协议交易的覆盖、首次可得时间仍未认证，所以不能进一步称为已经认证的真实交易所全量成交。它们适合在如实披露的开发敏感性分支中检验额外上下文，不能单凭多两个字段就宣称机制已识别。[准备脚本](prepare_auxiliary_alignment.py) 拒绝覆盖既有输出和回执，并绑定原件、旧价格及新输出的 SHA-256。

### 4.1 TGSINFO-VMD-NEQQLattice

固定作者提交：[3e8a155f034f38cb20430e601c4edb13c22ed7fc](https://github.com/StriveOrange/TGSINFO-VMD-NEQQLattice/tree/3e8a155f034f38cb20430e601c4edb13c22ed7fc)。公开树中仅见广州原始工作簿，没有湖北原始数据文件；仓库最后 push 的元数据为 2024-12-24，所以不能把发表年份 2026 当作数据包含 2026 年。

Notebook 只提取并阅读 21 个 code cells，没有执行作者代码或把作者预测成绩作为本项目成绩。整段分解发生在 notebook 的时间切分之前；代数桥接通过不能证明其信息集可用于实时预测。原始工作簿、分量 CSV 和 notebook 都留在 `/tmp/carbon-literature-data-audit-20261019d/`。来源哈希和完整范围见 [新作者审计](PUBLIC_AUTHOR_WORKBOOK_AUDIT.json)。

## 8. 新数据入口的实际进度与下一步限制

本次已经实际取得 TGSINFO 的广州工作簿、分解数组及仅供源码阅读的 notebook，以及 Zzysty 的三个价格文件和外生文件；来源身份已锁定，新原件全部在 Git 外。它们没有带来2025/2026的新价格，也没有新增独立市场。

Sustainability 2026 `10.3390/su18178967` 的[官方文章入口](https://www.mdpi.com/2071-1050/18/17/8967)在本次访问返回429；官方搜索缓存可核到1,203个交易日价格的摘要，但本盘点没有读到可下载数据的 Data Availability 或 S1 正文，所以不声称已经取得该文全样本或作者数据。根代理和文献代理也尚未定位可用附件。这个入口应保留为待取得证据，不应成为暂停实际开发实验的理由。

优先补充的仍是**可认证日期、具体工具及价格定义**的市场价，而不是再下载同一三种能源历史。真正新的确认设计还需明确未用于模型选择的来源/时期与残余暴露，冻结一次可检验的选择和评分规则。公开访问不自动提供底层行情的再分发许可；本次没有上传原始市场数据。若需复原旧 EEX、CEA 公告、ScienceDB 或 PLOS 数据，应使用各自现存下载/解析程序和固定哈希，不能把某个失效网站的历史成功回执当成今天已完成的获取。
