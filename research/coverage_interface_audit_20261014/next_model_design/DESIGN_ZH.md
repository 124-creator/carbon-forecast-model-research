# 下一完整预测模型：选择 SegRNN，限定检验“未来观察时钟边缘化”

## 决策
选择作者 SegRNN 的 segment-wise GRU + parallel multi-step forecasting（PMF）作为唯一移植底座；TimeMixer 只做静态比较，不进入下一轮训练。候选完整模型直接由过去原价序列预测未来原价增量，编码器、循环状态、解码器通过同一预测任务训练。禁止接入 MLE 签发预测、历史模型误差或任何残差校正输出。

**这不是已发现的新算法，也没有达标结果。** SegRNN 是现成基模型；下述唯一新增机制是一个有明确任务区别的研究假设。联合预测时刻与取值已有 marked temporal point process 邻居，不能把它叫首次提出，也不能用“SegRNN + 时间特征”包装论文创新。本任务完成的是有限检索、静态审计、明确选型及下一训练规范，没有市场训练。

## 本地问题依据与不能越界的推断
已阅读 README、local_coverage_model_20261014/REPORT_ZH.md、next_model_route_20261014/pilot/REPORT_ZH.md，未读取价格文件。
- 四个变化块均值直接预测连同同信息线性都弱；块均值丢失块内次序。新底座保留整个60点输入及段内位置，不再沿用四个块均值接口。这是接口纠偏，不是创新贡献。
- 已有任务 h=1/5/20 是“之后第h个观察点”，不是h个日历日。时间间隔信息与数值序列不应混为一谈；过去时间戳可用，未来实际观察日期不可当作已知特征。
- 950条合法前缀、小样本、2020—2021反复开发、强 MLE/历史修正基线等约束来自本地报告。没有重新计算日期间隔分布，**尚未证明间隔变化严重或具有增量预测力**。未来读数日期也不能自动解释为成交、发布日期或报价有效期。
- 新假设针对“观察步长对应的未来日历时长未知”，不是针对已证实的因果缺陷。若合法日期前缀审计发现间隔近乎恒定、日期含义不明，或者合成无时钟信号控制失败，停止新增机制，不开展市场挽救调参。

## 最多两个完整底座的比较
### 1. SegRNN：选定
论文 arXiv:2308.11200，2023年预印本；作者仓库当前引用为 IEEE IoT-J 2026，DOI 10.1109/JIOT.2025.3647705。因此“2026引用”不表示算法2026才首次出现。作者仓库 lss-1138/SegRNN，README自认官方实现。本次PDF提取被工具安全屏障拒绝，没有绕过。仅从检索描述确认论文分段循环与PMF机制；静态作者代码 Model 实际包含单层 GRU、段内线性/ReLU嵌入、共享循环解码及最终恢复输入末值。不能称全文精读。[1]

优势：一个小GRU、没有注意力、无需预训练权重；可以固定60输入、20输出、段长5、隐藏维16来控制容量。原版预测20个点，取第1/5/20点评分；PMF分段长度要求 seq_len 和 pred_len 可整除 seg_len。减去输入末价再恢复只是平移等变参数化，不是学习另一个模型的残差。[2]

移植只保留预测核心，以自有严格前缀加载器替代原运行器；不安装、不导入或执行这次保存的作者源码。revin=False；移植时删除顶层无条件 RevIN 导入，因此最小核心只需 torch，数组/审计使用 numpy/标准库。原 requirements 为 numpy/matplotlib/pandas/scikit-learn/torch 且无版本固定；README建议 Python3.8，这不是当前Python3.11的兼容验证。

### 2. TimeMixer：不选
ICLR2024、arXiv:2405.14616；作者官方仓库 kwuking/TimeMixer。论文的季节/趋势多尺度混合与多尺度输出融合具有明确结构，不是注意力改名；但针对当前单变量短序列，会增加下采样、分解、多尺度解码的选择。选择它并不能直接解决未知未来观察日期。

仓库当前同时承载其他任务与更新，不能把当前HEAD等同ICLR发表版本。默认依赖钉死 torch1.7.1/pandas1.1.5/scipy1.8.0 等，Python3.11风险明显，且 sktime 重复版本声明；只做文本审计，未安装验证。主模型导入 Autoformer_EncDec/Embed/StandardNorm 等自带层；不是下载一个模型文件就可运行。为限制小样本搜索和依赖面，不选它、不再扩大名单。[3]

## 唯一新增机制：观察时钟边缘化解码（研究假设，非新颖性认证）
### 明确定义
对起点s、目标h，合法训练标签包含原价增量 y_sh 和日历时长 d_sh = date(s+h)-date(s)。部署起点t只知道过去日期和价格；d_th未知，不能输入真实目标日期。

底座编码器 Eθ 保留60个末值中心化价格及段内次序。新增机制把同一个PMF解码器改为有限“时钟条件”共享解码：
- 对每h，把 d_sh/h 用内训练集分位点1/3、2/3分成3个区间，区间代表值为内训练中位数；不足最低支持20样本的相邻区间合并，最少一个区间。所有阈值与代表值都在相应训练折重新估计。
- 共享小线性头 qθ(k|Eθ,h) 预测未来时长类别；一个共享PMF网络 μθ(Eθ,h,c_hk) 用一个标量时长嵌入改变解码查询，不建立3个独立预测器。
- 训练最小化 joint-NLL：CE(k_sh,qθ) + 0.5*(y_sh/σ_h - μθ(Eθ,h,c_h,k_sh))²。σ_h只用当前合法训练标签估计、固定下限，条件方差固定1，不额外学习波动模块。加相同的预注册weight decay；不增加第二种辅助任务。
- 实际签发使用 Σ_k qθ(k|Eθ,h) μθ(Eθ,h,c_hk)*σ_h + p_t，**不使用真实未来时长类别**。无固定或预测未来日期回填。这里离散积分是一个共享条件模型对未知目标时钟的边缘化，不是训练多个基模型再组合其预测。

下一实现保留SegRNN编码/共享PMF循环。原底座有4个段查询、每查询5个输出；候选对h=1/5/20分别复制其所属段查询并注入时长代表值，每个查询依旧输出5个值，仅取对应段内位置。对三个类别重复该共享查询后加权；不是给同一5点段强塞五个不一致时长。候选的查询/FLOPs更多，必须报告，不称完整原版复现。其他输出不监督、不评分。若实现复杂度超过本协议预算，暂停，不改成普通MLP然后仍称复现SegRNN。原版与新增版采用同样历史日期信息：过去已知gap仅经一个共享标量输入投影进入段嵌入；这个公共输入不是候选专属优势，也不算第二机制。先做price-only SegRNN静态复现/接口测试，不把其成绩纳入额外搜索。

### 为什么不同、为什么还不能叫创新
不是预测强底座误差，不是固定特征广义ridge：价格编码与共享条件循环通过损失学习，时钟类别概率参与最终签发。区别现有普通观察点模型是训练联合分布并在签发积分未知未来时长；区别直接拼接日历特征是不能把未知目标时间当输入。

GRU-D与RMTPP是必须核对的时间间隔建模/时刻标记联合预测邻居；本次两个页面提取也被同一安全屏障拒绝，相关描述暂标记[unverified]，不能称已经完成直接先例审查。我们的离散时长、连续价格和观察点h只是具体限制，**不足以自动形成算法创新**。当前承诺只能写“任务结构假设”。只有同信息消融证明边缘化而非额外参数/日期输入带来稳定增益，并补齐直接同类比对后，才讨论方法贡献；不因为实验阳性就反推首创。新增模型不是元学习、注意力、残差组合，但也不能仅以“不属于这三类”取得创新资格。

## 下一训练规范（必须先执行自有合成和因果测试）
1. 数据权限：本次不读取价格。将来只有父级已核准的950记录前缀读取权限；不请求第951条、2022价格或全文件哈希。日期定义/间隔可用性审计先行。2020—2021一律标记开发段，不是未见测试；不扩展市场，不获取外生数据。
2. 输入60，目标h={1,5,20}观察点，刷新40，训练最多480起点。**两模型均完整20步成熟支持 s+20<fit_end**；本轮不改变异步标签支持、不做梯度运输，避免把标签增加当机制收益。最近120个完整成熟起点内验证；内训练目标必须严格早于首个验证起点，20步清除。不随机切分。
3. 原价末值中心化，内训练增量尺度；不得全序列标准化、插值、分解或日期回填。过去gap使用同一个训练内有界缩放，两个模型相同。未知h目标gap、类别、代表值只可作为训练标签或训练内估计量，不可经输入泄漏。
4. 固定 seg_len=5、d_model=16、一层GRU、PMF、dropout=0.1、channel_id=False、revin=False；单变量。Adam lr=0.001，batch32，最多100 epochs，内验证patience10；gradient clip1，weight_decay仅{0.0001,0.01}两档，种子{7,17,29}。两模型同档数、种子、epoch上限；记录实际参数/FLOPs/耗时，不能把同隐藏维叫同参数量。
5. 只训练两个完整基模型：公共gap输入 SegRNN 与新增时钟边缘化 SegRNN。新增版loss含CE+条件平方，底座以相同成熟支持的三h平方误差训练。联合似然与边缘均值MSE不同，必须保留这一目标差异，不能声称唯一变化只有结构。
6. 归因消融不增加另一个基模型族：a) 固定训练经验q、保持条件网络，检查是否学习时钟概率必要；b) 取消时长条件输入而保留q头与joint-loss，条件均值相同，检查单纯辅助任务/容量收益；c) 只在训练内置换时长标签且重估合法统计，负对照；d) **真实未来时长仅在合成中作为上限**，市场绝不读取未成熟目标日期作为预测输入。每个消融只用相同两档/三个种子，全部保留。
7. 自有合成先行：已知3类时钟混合与clock-dependent价格漂移正控、同gap但clock-independent漂移无机制控制、纯随机游走无信号控制；不少于两个固定种子。验证边缘预测接近生成器真条件均值、不是oracle时钟；无信号不得虚构优势。检查阶梯gap标签可恢复性与小区间合并行为。
8. 因果/实现验收：静态许可审查；作者结构张量形状自有重写测试；未来价格/日期与所有未成熟标签扰动、前缀重放、内折重新估计时钟边界、两模型相同起点、normal/python -O独立评分。保存所有配置训练日志/每seed签发预测，不保存第三方权重。
9. 开发判据：原价MSE/MAE，按年份×h等权baseline-relative MSE；种子平均损失不是先平均预测。基准RW、真实MLE与历史线性修正由并行基线审计提供，未经确认不得替换。新增版必须同时胜原SegRNN、RW和核准强基线，两个年份不反向，且消融支持时钟机制；否则停止这个实现，不加隐藏维/时钟档/其他模块救分。阈值是预注册判据，不承诺成功。
10. 预算：当前只做设计。后续合成加首个完整训练上限30分钟CPU，超过即记录未完成而非阳性；不得在未跑完时宣布达标。不因反复开发段提升而宣称独立实证。
