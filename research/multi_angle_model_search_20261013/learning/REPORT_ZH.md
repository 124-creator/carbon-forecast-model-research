# 实际结果与限制

ESS约束比强MLE略低，但开发集差距很小，不能作为创新或独立确认。2021的20步仍差于同支持MLE（1.022512 vs 1.018530）及强MLE（1.011725）；不能称全面改善。普通残差和固定交互均比同支持MLE差，说明直接增加交互自由度并没有得到稳定收益。ESS把44维交互读出的条件线性自由度压到2.034—3.726；这是收缩诊断，不是非线性机制独立证据，更不能排除普通ridge采用其他固定惩罚也获得相同表现。没有追加网格追查。

公平方法均使用同一480上限、完全成熟历史起点、相同59增量支持、训练标准化及40点刷新。最早历史发行从120点开始，此前不生成残差；学习训练起点也从120开始（协议原先未写明这一必要下限，此处明确披露）。历史残差MLE参数每40点冻结，使用当时成熟标签，状态只用当时60价格窗口；当前同支持MLE采用当前共同训练起点，残差标签则来自历史发行版本。强MLE480原算法使用更近期一步标签并保留全历史滤波状态，因此只是已知强参照，信息/状态支持不完全公平。

所有残差读出固定零截距，避免未惩罚截距逃逸自由度上限；所以这里的“普通残差ridge”是固定零截距版本，不能声称已经穷尽所有普通ridge。ESS为20滞后正相关截断启发式；没有小样本保证，未计入自适应lambda选择额外自由度。Stan来源是MCMC ESS定义，仅借用自相关形式，不是复现Stan估计器。CMU讲义给出了ridge闭式解与trace自由度公式；实际访问两项来源成功。
