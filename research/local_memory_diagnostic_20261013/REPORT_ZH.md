# 本机接管后的第一项记忆诊断

不调用Pro，不执行用户包内训练代码，不打开市场后段。读取Stage G生成器后，独立实现其长记忆交互生成公式，并以20个固定种子、每条5400步（评价后4000步）运行一次一步预测诊断。没有选择最佳种子或修改生成系数。

完整已知参数预测的平均相对MSE为0.8916506496089784；将同一因果卷积限制为过去60个增量后的预测为0.8966428479578408。截断预测与完整条件均值的平方差占信号平方均值0.04236886364126782。

这说明该公式下，60步窗口仍保留大量可预测信号；不能把Stage G失败直接归因于有限窗口缺失历史。完整记忆仍有增益，但本诊断不支持“长记忆是主要瓶颈”的断言。

截断代入预测不是给定60步历史的最优条件预测，因此这不是信息论下界。已知参数诊断也不是可部署学习器，不能拿此分数与已训练网络作公平排名。一阶段、一步结果不能推广成1/5/20步实验成功。

脚本在本机普通和优化模式实际运行，输出一致。首次运行发现逐行乘积缺少axis参数，修正后重新运行；未修改数据种子、生成过程或评价区间。

下一阶段优先检查同一信息集下的函数学习与训练问题，暂不提出新网络、不打开市场后段。Stage G原成绩及源码因果性仍待完整审计，本诊断不替代该审计。GitHub同步范围仅本次独立脚本、诊断结果和本说明；不合并Pro分支。
