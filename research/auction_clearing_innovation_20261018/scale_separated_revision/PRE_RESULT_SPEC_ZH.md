# 一次有边界的方法修订：报价位置与随机清算比率分离

## 研究地位

这是看到原始 SDMC 开发结果和尺度诊断以后提出的**一次开发修订**，不是新的未接触确认试验。先修复已由原件和独立审查确认的 2020 日历脚注遗漏；原 SDMC 全部模型在纠正输入下重跑，FDMC 使用同一纠正版本。任何原始失败、输入修复、训练失败及更改记录均保留。

本轮的可反驳问题是：在相同公开信息和可观测分解监督下，把共同报价位置和单场拍卖价差放到各自的历史尺度，能否让随机需求清算本身取得超出直接分布预测的价格精度收益。单独超过旧 SDMC 不构成创新证据。

## 唯一实际模型

用 M 表示官方公布的同场 Bid Median，用 P 表示成交价，Q=P/M。M 是可观测统计字段，不能解释成已识别的二级市场价格或数量加权订单簿中位数。未来 M、Q 和总申报量 B 只作标签；价格前向始终积分预测的 M，不输入真实未来 M。

当前参考 P0、M0、B0、S0 来自同一历史已完成拍卖。宏观尺度 v 沿用原始的过去 61 个有效价格形成的跨日波动及已知日历间隔。微观尺度 d 为过去 60 个同时有 P、M 的已完成拍卖的 |P-M| 中位数，下界为 max(0.01 EUR,0.0001*M0)，不乘预测期限平方根。全部计算只读取起点之前历史。

未来报价位置采用一个条件对数正态分布，令 r=v/M0：

    log M = log M0 + r*a - 0.5*sigma^2 + sigma*Z,
    sigma = clip(r*(0.05+softplus(raw_sigma+0.46)), 0.00001, 1.5), Z~N(0,1).

因此 E[M]=M0*exp(r*a)。微观 Q 用 3 个 Gamma 需求分量、每个 17 个从 -3 到 3 的网格，沿用已检验的随机清算质量计算及先混合成功质量再条件化的次序。内部比例尺度为 d/M0，location=4*tanh(raw_location/4)，span=0.25+3.75*sigmoid(raw_span-log(4))。有限范围在训练前固定。

各分量的网格按历史 S0、B0 的 Gamma 参考清算权重中心化，使零 location 时参考 E[Q]=P0/M0。共同位置与 Gamma 需求实现的条件独立是本次低复杂度工作假设，并非数据事实。最终 P=M*Q 是一个有限对数正态混合；其均值、CDF 和 CRPS 均解析积分。没有将 E[B] 填入非线性清算器来冒充随机积分。

共同位置、微观形状及混合头的编码器屏蔽计划供给的两个自由 context 输入；单独 B 均值头可读取它们。计划供给仍通过日历时距、目标平台等变量相关，因此这不是因果识别或完全不能推知供给的声明。

## 训练目标

保持原价格标准化 MSE + 0.2*CRPS + 0.02*B 边际 Gamma 混合 NLL。另加入：

    0.1 * [median_MSE + 0.2*median_CRPS]
  + 0.02 * [basis_MSE + 0.2*basis_CRPS].

median 的误差用同一宏观价格尺度 v 标准化；basis 的标签和原子为 (Q-P0/M0)/(d/M0)。本轮实际实现选择线性 Q 比率，而不是审查建议稿中的 log Q；所有同分解对照使用同一个定义，且没有对该选择做结果驱动搜索。M 与 Q 的辅助标签来自同一拍卖的公开字段，不是额外独立市场样本。

这是复合的边际与可观测函数评分，不是完整私人订单簿或 (B,M,P) 的精确联合似然。取消或无标签记录按明确 mask 处理，缺失值不参与相关损失。

## 公平对照及预算

固定运行 FDMC、FDMC_no_supply、FDMC_plugin、FactorDirect、FDMC_unseparated、GRU_full、MLP_full，以及 RW、LastBidMedian、Ridge、HistGB。所有预测器使用纠正后的原始输入；另向所有可训练基线提供同样的两个起点已知 context：log(d/P0) 和 log(M0/P0)。

FactorDirect 与主模型具有相同共同位置分布、比例网格、位置和跨度边界、B/M/Q 辅助标签及权重、参数量和训练预算；它的微观价格概率与参考中心都由自由概率给出，**不保留 Gamma 清算或成功概率重加权**。其编码器可读取完整的相同已知信息，是更自由的直接对照。

no_supply 在清算算子内把计划 S 替换为历史 S0，其余位置模型、输入和辅助监督不变。plugin 只把微观需求换为均值订单簿的平滑清算点，仍完整积分随机共同位置。unseparated 只把微观网格的 d/M0 换成宏观 v/M0，其余辅助标签、损失和边界不变。

神经预算为 7 模型 x 3 评估年 x (2 个学习率验证拟合 + 3 个最终种子拟合) = 105 次。沿用 hidden=32、学习率 0.001/0.003、最大 50 epoch、最少执行 8 epoch 后允许早停、patience=8、batch=128、tuning seed=17、refit seeds=17/29/43。只依据上一年已成熟验证标签选择学习率和实际最优 epoch。

经典预算沿用原配置，无新增搜索。原始记录、起点、目标、宏观尺度、真值及评价年份/期限不变。用于物理映射的 base 在本轮改为 float64 并从同一原始已知数量重建，最大既有 float32 舍入差单独报告。

## 成功标准与停止规则

主指标仍是 2021/2022/2023 x H=1/5/20 九格等权 MSE/RW MSE，先合并三个 seed 的预测再评分。原六项推进门槛照搬到 FDMC 及其同名机制对照，最强 matched 在 FactorDirect、GRU_full、MLP_full、Ridge、HistGB 中确定；另要求 FDMC 主分数严格小于 unseparated。

95% 区间沿用按年度分层、每块 20 个独立起点、2000 次的配对区块 bootstrap。固定开发样本上最佳对照的身份，不声称区间包含模型选择修正或重新训练不确定性。概率成绩改善不得替换主 MSE 成功条件。

不根据本轮评价结果再选择第三种结构、辅助权重或主指标。任一推进门槛失败即结束当前候选的确认推进，保留所有结果，形成有明确条件的发表路线。只有全部门槛通过才另行冻结确认阶段细则；本脚本不读取 2024-2025 评分数据。
