# 纯价格多市场多步预测：基线底座（不是创新候选）

## 实际运行与边界

固定 seeds = 17, 43，各自运行 shared / no_shared 两种生成条件，每种三个模型；共 12 次训练。实际训练运行 12.797 秒，90 epochs，不调整 seed 或超参数。当前实际 Python 环境没有 torch，使用 NumPy 2.4.6 手写解析反向传播和 Adam；这不是成熟深度学习框架实现，结果仅用于验证基线底座。没有安装依赖、读取市场数据、执行候选、提交或 push。

复现：在本目录运行 `python -m unittest test_baseline -v`，然后 `python benchmark.py`。未来扰动的 checkpoint 检查另见 `future_checkpoint_checks.json`（本次实际读取已训练的 12 个 checkpoint）。

## 数据和可见信息

每种条件 N=1800 个合成时间点，三个匿名合成市场，无现实日期/真实市场。潜在 persistent 状态为 AR(1) 系数 .94、创新标准差 .13；三个独立暂态状态 AR 系数 .55 / -.35 / .80、噪声标准差 .22。价格为累积潜在创新动态，加上暂态变化和小型观测创新。shared 条件三个市场加载同一个 persistent 状态，加载 .8 / -.6 / 1.1；no_shared 条件加载各自独立的 persistent 状态。两条件使用同 seed、同基础创新数组，其他结构相同。

所有模型只收到当前市场 t-31..t 共 32 个过去及当前价格，不能收到 latent、未来价格或其他市场价格。普通 MTL / PCGrad 只跨市场共享编码器参数，不跨市场拼接特征。latent 单独保存为 `generator_audit_only.npz`，train API 只接收 prices。保存 latent 为了审计，不用于学习器。

## 时间协议

同一预测起点同时预测 p[t+1], p[t+5], p[t+20]，直接多输出，不是同时间回归。固定训练内价格均值和标准差（p[0:1080]），输入标准化，输出为最后观测原价 + 网络预测原价增量。训练、验证选择及测试均为未经标准化的原价格平方误差，三市场与三 horizon 等权；没有各 horizon 分别挑选起点。

train origins 31..1059（1029）；validation 1080..1419（340）；test 1440..1779（340）。训练最后标签时间 1079 < 首个验证起点 1080，验证最后标签时间 1439 < 首个测试起点 1440，两边各 purge 20 个起点。验证/测试窗口可以使用其起点之前已经观测到的历史；不是把窗口历史也禁掉。固定离线训练，验证选择一个共同 epoch，不用测试挑选。没有在线更新，因此 label maturity 是分区标签最晚时间审计，而不是模拟在线到期队列。

## 基线与公平匹配

独立小型时序 MLP：每市场独立 32→24 tanh 编码器和 24→3 私有输出。普通 MTL：同一 32→24 编码器与三个私有输出。PCGrad：与普通 MTL 完全相同初始化、模型、chronological batches、90 epochs、Adam lr=.002、batch=128、验证选择；仅在共享编码器参数上进行负内积梯度投影，私有输出沿用原始平均梯度。每次投影的其他任务顺序由 seed+2000 固定随机化。独立模型故意不是参数量匹配：三个编码器，MTL 一个编码器；这是通常独立/共享基线的容量差异，后续不能把容量差异当作机制证据。

增加 persistence 原价基线 p[t+h]=p[t]，防止把复杂网络当成默认有效。所有训练轨迹（包括后期失败/退化 epoch）、原始预测、checkpoint、逐市场/horizon 原价 MSE/RMSE 完整保留；`verification.json` 枚举共享模型相对独立模型不胜的全部 31 个单元，不隐藏失利。

## 实际结果

下表对两个固定 seed、三个市场、三个 horizon 的 MSE 等权平均（不将其当作统计显著性）。

| 条件 | persistence | 独立 MLP | 普通 MTL | PCGrad |
|---|---:|---:|---:|---:|
| shared | 8.7211045 | 8.8907661 | 8.9778446 | 8.9328879 |
| no_shared | 10.6673260 | 10.7643513 | 10.4440466 | 10.1354710 |

shared 条件普通共享模型和 PCGrad 的平均结果均未超过独立或 persistence。no_shared 条件反而出现共享模型平均收益；不能声称共享潜在动态已被模型有效利用，也不能把 PCGrad 的提升解释成共享机制识别成功。seed=17 所有模型的验证最优都是 epoch 1，必须保留这一不利结果，可能表明水平输入/训练非平稳和短预算模型的可学习性不足。

## 供候选设计使用的具体缺陷（只提出诊断，不训练候选）

1. 当前共享编码器只接收单市场窗口，共享的是参数而不是跨市场实时观测。即使确有共同状态，模型也不能将三个市场的当前观测合并以减少状态估计噪声。是否需要过去价格的跨市场因果融合，应成为候选对照的机制问题，而不是已证实结论。
2. 原价等权 loss 下 shared 的 h20 persistence MSE=23.752529，而 h1=0.190240、h5=2.220545。共同编码器梯度很可能偏向长 horizon；现有 PCGrad 只在市场间投影，不检查/分解 horizon 间冲突。可设计市场×horizon 梯度审计，但当前没有证实 horizon 冲突。
3. level 窗口只做固定标准化，没有显式区分 persistent 增量与暂态价格回摆。不同市场加载符号相反、暂态 AR 也不同，硬共享编码器可能混合相异状态。需要与简单价格差分/局部中心化基线比较后，才讨论新机制。
4. no_shared 条件也获得收益，说明参数共享的统计正则化收益与共同动态利用混在一起。候选必须保持该负控制，并检查跨市场过去价格扰动/消融；不能只在 shared 条件报告提升。

## 已验证与尚未验证

三项单元测试实际通过：时间成熟与未来输入/标准化不变性、解析梯度的有限差分检查、负冲突投影检查。`verification.json` 保存梯度误差数值、边界和计数；训练文件保存每批市场梯度范数和冲突比例。读取 12 个训练 checkpoint 后，扰动首个测试起点之后所有价格 +10000，其当前预测完全不变，训练价格前缀也完全不变。

未来扰动检查没有重新训练两份模型；它直接检查输入、固定 scaler、训练价格前缀与已训练模型的预测不变。没有逐参数穷尽梯度验证（有限差分检查每类参数的两个端点），没有统计显著性、现实数据外推、在线更新或候选创新验证。两 seeds 不能支持可靠统计显著性结论。
