# D1 开发阶段独立审查

审查对象为 `cross_market_innovation_20261017` 中已冻结的 D1 运行；确认期文件未读取，审查没有新增模型拟合、梯度或优化器更新。**141 次正式拟合及全部已保存预测通过独立复算。这个结论只说明实现和报告数值一致，并不证明主机制有效或达到发表标准。**

## 1. 完整性与数值核验

正式运行共 93 次共享模型拟合、48 次本地模型拟合，合计 141 次；冻结任务全部完成，没有失败重试或额外正式拟合。记录耗时 245.1621 秒，低于冻结的 2,400 秒上限。全部模型使用种子 17，按 2021、2022、2023 三个年度切点独立初始化。

独立审查程序以 NumPy 实现 GRU、LSTM 和 ridge 的前向计算，没有调用 PyTorch 的预测器。首先从已批准的开发分区重建训练、验证和评分样本，再从保存的参数逐点重算全部可用视图和 H=20 个输出。随后对先前已核验文件重新核对 SHA-256，复核全部公开结果、35 个配置摘要和 15 组 RW/统计参考控制，避免不必要地重复完整前向计算。

主机制相对匹配增强对照的差为 **−0.0000596946**，约为该对照分数的 −0.0061%；相对更强的普通共享价格 GRU 则为 **+0.0021432485**。这支持继续做已限定的跨种子机制检验，但目前不足以把极小的增强对照差异解释为机制收益，也不能写成主机制优于现有强基线。

最优普通共享价格 GRU 的各市场分数为：EU_REPORTED 0.9974983、广州 1.0030832、湖北 1.0242971、上海 0.9080684。其整体低于 RW，不能表述为在四个市场都战胜 RW。主机制、超参数与后续确认比较对象都必须在确认期结果读取前选定；D1 中筛选多个配置产生的最优值不能作为未经选择偏差的效果估计。

## 3. 数据量与观测频率限制

四个开发分区共有 5,864 条价格观测，日期均早于 2024-01-01。三个评分年份的总完整 H20 起点数分别为 715、872、851，共 2,438 个。训练和评分窗口存在重叠，这些数量不等于独立样本数。

上海 2021 年只有 47 条原始观测，因此同年 H20 评分只有 **27 个高度重叠起点**。这个年度不能当作 27 次独立检验，更不能仅凭该格大幅改进建立强证据。上海开发数据中，20 个观测步的日历跨度中位数为 37 天，最大达到 314 天；其他市场的观测密度也不同。报告应使用“未来 20 个观测步”，避免将全部市场一律写成“20 个交易日”。

这些描述性结果解释了为什么需要后续时间外确认、严格配对的依赖重采样和按训练量限制的学习曲线；它们不保证扩大数据后主机制一定有效。

## 4. 冻结文档勘误与准确语义

`frozen_d1_source/data_core.py` 顶部文档字符串仍写有市场 ID 不是神经输入的旧说明。**实际冻结的 `fit_core.py` 在每个有效 token 上追加了已知市场 one-hot ID，所有相关神经对照采用同样处理；独立 NumPy 前向也按该实际规则重算并通过。**因此这是文档错误，不是已发现的输入接线错误。D1 文件保持原样，D2 可用明确标注的文档修正消除矛盾。

信息集应表述为“市场 ID 与相应归一化历史视图”。粗视图先删除价格顶点，再对保留价格重新做差分，固定核只读取粗视图的三个原始通道，分组按市场进行。统计锚只进入完整历史输入的专用残差基线，不进入粗视图一致性训练。

评分打包程序在离线执行过程中持有评价标签；因果性依赖于预测函数只读取截至起点的输入、市场 ID 和固定状态。收据中的标签访问说明应解释为预测信息边界，不能逐字扩展为标签数组在物理执行时直到逐点预测之后才首次存在。

## 5. 审查边界

初始随机编码器和 ridge 初始化只保存了哈希，没有保存初始参数文件，因此没有独立重建其全部初始数值。中间每轮参数也没有保存；审查重算的是最终选中状态的验证预测，并根据逐轮日志独立核验选轮规则，不能声称重算了每一轮的全部参数与验证预测。

已通过的实现和数值核验也不能代替新颖性判断。条件期望一致性、核条件矩和 U 统计均有直接近邻；当前方案应继续报告为这些思想在粗历史、多市场预测中的具体实施及待验证实证增量。D2 与确认期的比较必须包含匹配增强对照和开发阶段选定的更强基线，并按事先固定的统计方案解释结果。
