# 上海时间外确认的固定统计口径

本文件落实已在确认数据开启前冻结的 `CONFIRMATION_DESIGN_RULES.json`。统计模块只接收调用者传入的对齐数组，**没有文件读取、模型训练、确认集选型或区块长度选择功能**。实现为 `statistics.py`，SHA-256 为 `c0003775786ad89aead6a9007d3bf28dc7b01aa647df5be6eaece7b91d4bcd81`。

## 1. 唯一主效应

设模型 m、固定训练种子 s、预测起点 t 和期限 h 的原始累计价格变化预测为 pₘₛₜₕ，真实变化为 yₜₕ。首先在每一个起点与期限上计算种子平均平方损失：

\[
L_{m,t,h}=\frac{1}{3}\sum_{s\in\{17,29,43\}}(p_{m,s,t,h}-y_{t,h})^2.
\]

这与先平均预测再计算平方误差不同；后者会引入一个种子集成模型，本协议不使用该口径。确定性的 ridge、RW 或统计参考可以沿种子维广播，其损失不变，也不产生额外独立样本。

对年份 a∈{2024,2025} 和 h∈{1,5,20}，使用同一批完整 H20 起点，计算：

\[
R_{a,h}=\frac{1}{n_a}\sum_{t\in a}y_{t,h}^2,\qquad
\widehat\Delta_b=\frac{1}{6}\sum_{a,h}
\frac{\overline L_{\mathrm{candidate},a,h}-\overline L_{b,a,h}}{R_{a,h}}.
\]

负值有利于候选模型。六格等权，而非按两个年份各自的起点数加权；与 D1 的相对 MSE 格均值一致。候选与两个比较对象必须由开发阶段固定规则预先选定：第一项是开发阶段选定的最强基线，第二项是匹配的视图增强对照。原始 MSE 差作为辅助尺度同时报告，不能替代主效应作事后择优判断。

## 2. 配对、分年、圆形移动区块重采样

主区块长度固定为 **40 个观测起点**，重复 **10,000 次**，随机种子 **20261019**。20 和 60 个起点仅作敏感性分析，不能根据显著性改换主区块。

每次重采样在各年份内部独立均匀抽取区块起点，取连续 L 个行号，到该年末尾时在同一年内循环，拼接足够区块后截取原来的 nₐ 行。每一年都保留原起点数量；同一次抽取的行号同时用于所有模型、训练种子和期限。每次重采样重新计算六个 RW 分母，得到 Δ*。程序先形成种子平均损失面板再抽取行号，与对所有种子使用同一行号之后再平均完全等价。

伪随机生成器为 NumPy `PCG64(SeedSequence([20261019,L]))`，计算块为 256 次重采样。不同 L 有独立且确定的随机流。数据数组必须在年份内部按原始观测起点连续排序，不允许各模型各自删除不利或缺失行。

若某年份 nₐ≤L，该 L 的推断记为无法估计，不自动缩短区块。若原始 RW 分母为零，主效应本身未定义；若任一次重采样产生零 RW 分母，则该 L 的归一化推断记为无法估计，**不丢弃该次抽样、不加 ε、不用敏感性区块补救主检验**。辅助原始 MSE 差仍可报告。

## 3. 区间、单侧检验和两项多重性

采用 basic bootstrap 区间。对置信度 1−α，其端点为：

\[
[2\widehat\Delta-q_{1-\alpha/2}(\Delta^*),\quad
 2\widehat\Delta-q_{\alpha/2}(\Delta^*)].
\]

报告各比较的 95% 边际区间和 97.5% 边际区间。后者通过两项 Bonferroni 分配给出近似 95% 的同时覆盖；它不是“Holm 调整置信区间”。其覆盖性质仍依赖 bootstrap 的适用条件。

单侧原假设为 Δ≥0，备择为 Δ<0。以 Δ*−Δ̂ 构造零效应边界下的居中近似分布，使用：

\[
p_b=\frac{1+\#\{\Delta_b^*-\widehat\Delta_b\le\widehat\Delta_b\}}{10001}.
\]

这个加一规则避免有限重复次数下输出 p=0，并对全零效应的完全相同预测给出保守 p=1。它是近似 bootstrap 检验，不是精确置换检验。

只对 **block=40 的两项主比较** 作 Holm 调整。两个 p 值排序后，较小者乘 2，较大者取自身与前项调整值的最大值，再截断至 1。正面证据门槛要求两项效应均为负，且两项 Holm 调整 p 均 **严格小于 0.05**。敏感性区块的 p 值仅作描述，不新增“择一显著即可”的路径；其他模型和消融表也不加入这两项主检验的成功判据。

## 4. 推断的实质边界

重采样推断以开发选择、已签发的预测和固定训练种子集合为条件，不估计重新训练导致的参数抽样不确定性。2025 年按冻结规则用成熟的 2024 年标签刷新模型，在因果上合法，但分年固定损失 bootstrap 不重新拟合模型，因而没有传播由该刷新形成的跨年训练依赖。

圆形移动区块 bootstrap 需要适当的年内平稳性或局部平稳条件、弱依赖以及稳定的抽样分布；区块长于 H20 并不能自动证明这些条件。大量年内漂移、极少有效区块或罕见冲击可能使近似区间不稳定。两个年份不是两个足以代表全部碳市场的独立重复试验。

上海确认数据源只有 261 条原始观测，同年 H20 支持最多 221 个起点。程序报告每一年 nₐ/L 和实际抽取区块数，便于判断有限样本约束。它也要求上游审查者确认 H20 标签仍在对应年份内；仅凭损失数值不能推断真实目标日期。

result = module.confirmation_inference(
    predictions={candidate_name: candidate_pred, baseline_name: baseline_pred,
                 augment_name: augment_pred},  # 每项 [3, N, 20]

    strongest_development_baseline=baseline_name,
