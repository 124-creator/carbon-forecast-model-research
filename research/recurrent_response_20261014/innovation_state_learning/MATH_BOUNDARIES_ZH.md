# 数学边界：结构约束不等于原创性

本轮不是首次创新状态、首次GRU增益或首次移位矩阵。协议所列三个作者实现已经覆盖这些基础思路。

1. 固定累加解码本身可以只是坐标选择。

若原状态h经可逆20×20矩阵C输出y=C h，D为固定累加矩阵，令T=D^(-1)C、z=T h，则y=D z。状态h'=A h+K u可写成z'=T A T^(-1) z+T K u。因而“把decoder固定”不能单独当作新增学习能力、统计识别性或创新。DECODER_GAUGE_CHECK.json保存实际数值检查，未以解析头重命名冒充贡献。

本轮真正检验的限制是：变换后的递推必须是指定移位S减去可预测的秩一误差反馈，增益受统一加权范数约束，并由过去GRU状态生成。一般的坐标变换不会自动保留这些限制；但这也不证明既有观测器/SSM文献没有同类结构。

2. 常增益情形属于普通线性创新滤波。

常增益时，A=S-k e1'，z_t=A z_(t-1)+k u_t。它是线性状态空间/ARMA类的一个结构化表示，绝不是新的非线性算法。常增益对照若可以解释成绩，即便候选胜RW也不升级。去掉反馈则变为输入驱动的动态增益有限移位滤波，同样要保留为解释性对照。

3. 收缩证明的范围很窄。

W=diag(.9^(-j))。||W S W^-1||₂=.9，||W k||₂<.09，所以||W(S-k e1')W^-1||₂<.99。两条递推共享完全相同的输入、GRU输入编码与参数时，状态初值差在这个加权范数下收缩。这里不包含GRU本身、不包括参数刷新、不证明任何真实序列的预测误差收缩，更不能证明候选增益是Kalman最优解。

4. 不声称预测鞅一致性。

z是对会切换的统计参考预测的修正坐标，末端补0也是有限期限假设。修正的移位先验不等于证明整个价格预测满足条件期望塔性质。内部误差也是当前参数版本回放历史所得，而非不可改写的历史签发误差。
