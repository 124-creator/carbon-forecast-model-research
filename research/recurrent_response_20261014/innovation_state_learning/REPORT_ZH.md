# 可预测创新状态GRU：有界训练与停止裁决

本轮实际新写并训练了循环状态递推，不是再给M/N/O输出头补一个模块。固定结构将20个未来增量修正作为循环状态，由过去GRU编码产生受约束增益，在当前观测到来后吸收一步预测误差。机制与数学边界见PROTOCOL、MATH_BOUNDARIES_ZH。

## 核验范围

- 独立验分器不导入模型/trainer/runner，从获准原价前缀重建目标，逐一比对132个完成块与11条完整轨迹的预测一致性；149个已完成块的标签成熟和purge元数据通过检查。
- 普通与Python优化模式部分回放结果相同。另将独立验分与训练端评分函数在同一完整轨迹上的事后重算比较，共71个标量，最大差1.3322676295501878e-15。不是对不存在的完整训练报告认证。
- affine扫描已与逐时递推比较，且通过autograd gradcheck及模型参数有限差分；最大梯度差6.087101309115717e-14。这仅是算子可执行性，不是市场优势。
- 运行前记录的10个源码/协议hash均保持一致。公开文件字节/哈希另以Git index blob计，不能拿Windows换行后的worktree值混充。
- 全部普通对照也为本轮从头训练。GRU解析对照有1072个autograd参数及180个解析拟合头值；候选有1126个可训练参数，另有20维递推状态，不冒称同FLOPs或全部有效复杂度匹配。
- 候选24个fit中17个由验证选择epoch0，2个达到60epoch上限；仅否决本实现/预算，不声称已证明整类模型无效或优化全局充分。

## 对后续研究的约束

不再把“GRU学习Kalman式增益”“固定预测decoder”“移位矩阵”“稳定性上界”当作已经找到的创新。PSRNN、KalmanNet、SpaceTime作者源码已核；5个论文正文请求被安全拒绝，未绕路重取，完整查新门没有通过。

固定decoder本身对可逆decoder只是坐标选择；常增益时回到普通线性创新滤波。真正受检验的状态约束和时变增益也没有带来预测优势。本轮不追加beta、窗口、宽度、seed来救分，不补齐本已不能改变否决的LSTM。

普通GRU解析头0.900363是后续至少要保留的参照，不是新算法；它与历史0.911219的设置并非完全相同，不能把跨轮差直接归因于一个新机制。研究目标仍是模型/学习算法创新，但目前没有已成立的新主模型，更没有发表资格或未见留出认证。
