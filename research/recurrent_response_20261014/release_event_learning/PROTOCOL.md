# 冻结协议：发布事件驱动的外生信息学习筛选

## 目标与贡献边界

本轮回到完整、端到端训练的 GRU，检查煤价成本曲线是否提供可学习的增量，以及“新公告只注入一次”是否好于保持值输入。它不是已成立新算法，不是把异步 RNN、缺失掩码、双编码器或简单一阶差分首次发明的声明。即使开发区胜出，也仍需独立方法差异、充分查新与合格未见验证；不写成外生实证论文替代目标。

近邻已实际固定并静态阅读 mTAN、Raindrop、Latent ODE 的作者源码/README；另读了 GRU-D 的第三方重实现，不能冒充原作者实现或论文正文。未执行作者训练，未下载其权重。本轮没有通过论文全文新颖性审查。

## 数据与因果边界

- 广州原价只由已审核读取器请求前950行，末日2021-12-31，不请求第951行，不全文件hash。保留周末与同价行；h1/5/20为观测步。
- 对既有126份国家统计局原始HTML逐份重新核对字节与SHA，并独立解析。123个有字面发布日期的公告形成369个4500/5000/5500大卡热煤价格，另3份缺支持的发布日期头部，继续隔离。不依赖旧模型结果。
- 不重新联网认证每一旧HTML；当前官方快照及展示日期不认证历史首发版本。仅作带该限制的开发可行性筛选，不称严格实时回测。
- 可用时间是公告字面发布日期+1自然日，不用统计期间末日。缺旬不补，不构造每日煤价观测；煤价格和报告仅本地。保留已知旧公告作为历史记忆不等于填补缺失报告，跨年不制造新发布事件。
- 3煤种只合并字面标签的空白差异，不改数值、产品规格、发布日期。先有的5500单变量线性失败不自动推广到多煤种非线性GRU，也不与本轮分数直接归因比较。
- 碳价尺度、源log水平中心/尺度、源log变动尺度均只用训练输入/标签支持；源编码只处理当前已可用报告。源事件间隔、最后报告年龄、是否首次送达、无报告标记明确编码。

## 六个从头训练的方案

1. price：强普通完整历史GRU解析头，只用碳价，与上一轮普通GRU的实现数学一致。
2. clock：增加公告时钟/年龄/缺失/间隔，不给煤价，排除仅发布日期模式带来的增量。
3. raw_hold：普通GRU接收最后已知的源标准化log水平及变动；不训练额外源编码器。
4. raw_event：同raw_hold参数结构，但输入新报告的简单差分消息，排除把差分重命名为创新。
5. hold：7输入、8隐层的源GRU按公告序列更新，目标GRU在每个碳价观测接收最后的源状态。
6. event：与hold参数、初始化、训练和信息支持一致，目标GRU仅接收源状态新旧之差；无新报告时消息严格为零。

hold/event源状态均减去“同时间间隔、零数值信号”的源GRU状态，保证无值信号时无伪源消息。消息求和可回到最近源状态是算术性质，不是算法新颖性证明。源差分变换可因果逆累加；不能仅因变换后喂GRU就声称新信息或新算法。六方案不是全部同参数量或同FLOPs；匹配对照为hold/event及raw_hold/raw_event。

所有方案目标GRU宽16，特征宽8，沿用同一固定价格参考/上下文和解析9×20头；固定参考是控制的一部分，不是本轮创新。AdamW lr=.003、decay=.001、梯度clip=1、最多60epoch、验证patience12，种子17/29；不选择最佳seed。

## 时间支持与预算

沿用前轮原始459起每40观测步刷新网格，共12个刷新点；只输出2020/2021各自年内拥有完整H20目标的451起点。网格不因跨年排除20点而漂移。每个fit从头训练，最多480个候选训练支持，验证60并purge20；不随机时序划分。144次市场fit，另对hold/event、seed17各做价格未来后缀与源值未来后缀两种完整预算重训，共4次代表性因果重训。首次正式参数、尺度、训练轨迹及截止前预测须与扰动重训精确相同。

两个CPU worker；市场预算1080秒，总训练预算1200秒。不resume、不覆盖，不补跑超时块；不完整记录不通过，按已保存块计数而非仅完成轨迹计数。所有权重/逐点预测/原始报告/源值/局部bundle均local_only，不推送。

## 冻结裁决

主分数为2020/2021 × h1/5/20六格原价MSE/RW_MSE等权，再平均两个seed的损失；另报预测集成，不能互换。

源信息必要筛选：某个含煤价方案的主分数至少优于price/clock较强者1%，并在两个配对seed均胜。

事件机制必要筛选：event至少优于其余每个方案1%，两个配对seed均胜；对每个对照，两个年份均不变差且六格中没有超过5%的退化。必要门不代替显著性检验、独立新颖性与未见验证。

未过则停止这个固定事件输入实现，不调整煤种、滞后、宽度、窗口、seed救分，不把普通外生GRU或负结果改写为模型创新。
