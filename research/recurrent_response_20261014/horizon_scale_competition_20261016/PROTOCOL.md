# Horizon-dependent recurrent scale competition: bounded development experiment

Status: candidate application model, not established novelty or unseen validation. This experiment does not change prior failed verdicts. No child agents. Only the 950-record Guangzhou original-price prefix through 2021 is admitted; 2020/2021 are repeatedly exposed development periods. No 2022/2023 read.

## Problem and one candidate mechanism

Test whether forecast horizons need different recurrent time scales in a short carbon-price series. Feed causally aggregated observed changes (1, 5, 20 observations) into separated full-prefix GRUs. Each scale produces a whole 20-horizon correction. A horizon-conditioned router combines corrections. Add detached training-only relative-error competition to teach which recurrent scale is suitable for each horizon. This is an applied estimator hypothesis, not a first-ever MoE, multiscale model or auxiliary-supervision claim. MoLE (Ni et al., AISTATS 2024) and TimeMixer (Wang et al., 2024) are explicit prior art. Official TimeMixer source was inspected statically, not executed or copied. Full novelty review remains open; this is sufficient to run a bounded development experiment.

At t, input at scale w is (p[t]-p[max(0,t-w)])/(sqrt(w)*training_scale). No component is declared a latent true trend. Scale cells are separated, not a free invertible input-coordinate relabeling. Raw full-prefix GRU/LSTM controls retain their entire past. All models use the same causal MLE reference/context from the existing fair infrastructure and its correction-risk regularization. No exogenous, hidden teacher, saved model, or future revision input is introduced.

Models: raw_gru, raw_lstm, scale_mean, gate_only, shared_competition, horizon_competition. The last is candidate. scale_mean uses three experts with uniform weights; gate_only uses horizon routing without competition; shared_competition removes horizon conditioning from the router but retains competition supervision. All multi-scale models receive equal individual expert losses, so competition is not confounded with merely giving experts direct target supervision. Parameter and compute differences are disclosed, not claimed FLOP-matched.

Forecast features per expert: GRU observed-minus-zero trajectory, projection plus the common 3-dimensional causal reference context, tanh and intercept, as in the strong fair control. Each expert head is initialized by the same regularized solve as raw GRU. Initial routing is uniform; router has scale-specific state scores plus, only for horizon modes, a learned horizon/scale offset and horizon-state interaction. Corrections are combined by a convex softmax.

Training: main normalized squared error plus squared correction penalty plus 0.01 expanded-head penalty. Multi-scale models add 0.1 times equal expert risk. Competition models add 0.05 times relative-error soft-label cross entropy. Soft labels = softmax(-detached per-expert squared error / per-example-horizon mean expert error clamped at 1e-6); labels never enter forward prediction. shared_competition averages soft targets over horizons. Main validation and checkpoint criterion is original target prediction MSE only. AdamW, gradient clipping 1, up to 60 epochs, patience12, min_delta1e-6, initialization eligible. Training scale and split use existing fair_data.support: latest up to480 origins, last60 chronological validation, purge20, complete mature20 labels. No teacher pretraining or extra future data.

Declared grid per model: hidden8/16 crossed with lr0.001/0.003, weight_decay0.001. Four configurations, two historical cuts359/419, seed17, following20 issuance origins with complete targets before index459. Select mean h1/5/20 RW-normalized MSE, deterministic config-ID tie break. No expanded rescue grid. Market development: selected config only, seeds17/29, same cuts459+40*b for b0..11 and origins459..929. Primary score averages 2020/2021 x h1/5/20 six ratios, mean seed losses (not ensemble). Same-year complete-H support expected224/227,451 total. Raw RMSE/MAE/MAPE and seed ensemble scores are secondary and labeled.

Main candidate contrast: horizon_competition versus raw_gru; mechanism contrasts versus gate_only and shared_competition, with raw_lstm and scale_mean context. No every-cell win requirement; report aggregate, both seeds, annual and horizon heterogeneity. Improvement only in labels or one seed is insufficient for publication qualification. A candidate losing to its mechanism controls is not promoted. Do not infer universal failure from this implementation.
