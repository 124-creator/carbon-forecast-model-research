# 残差效用记忆GRU：完整有限原型结果

## 结论

32次正式拟合与2次代表性真实后缀扰动复训已实际完成。效用监督utility的主分数0.885317940，没有胜过本轮新训练完整GRU的0.885312432，也弱于相同结构、取消效用监督的learned记忆模型0.884469378。冻结的扩大实验条件未满足，不晋级、不改温度/权重或挑种子救分。这是本固定规则的可行性结论，不是对全部检索、分解或碳价预测创新方向的否定，更不转写成阴性论文。

## 本次真正改变了什么

保留完整逐增量GRU和共同统计参考，加入严格历史检索得到的、当前骨干尚未解释的已实现残差记忆；查询-键评分按期限产生权重，并包含零修正的不检索选项。在普通预测损失之外，用训练起点上“加入一个历史残差相对不检索的风险差”产生detach教师分布，监督查询-键评分。与上一轮多尺度专家门控不同，输入信息路径变成了历史实例记忆；本次没有把多尺度候选重新调参，也不是单独训练残差线性校准器。

RAFT、SARAF固定作者源码已在本轮真实读取并核对Git对象，未执行作者模型。[1][2]进一步真实搜索还发现PFRP与FreshCast，与未来监督检索和流式残差记忆更接近。[3][4]PROTOCOL逐项声明来源等级；后两者目前只有主来源搜索片段，不能说全文查新通过。检索、未来相似监督、残差记忆或不检索门控本身均不作首创主张。实验失败也不能用来源不充分来推翻或隐藏数值结论。

## 运行、优化与检查

主运行实际完成32次，最后保存耗时261.984秒，小于冻结1200秒。分6批、每批最多6次、最多3个CPU训练进程；没有期限延长、隐式重跑或用RW填缺。另做gru与utility各1次真实后缀扰动完整复训，两次均60轮，分别约11.35/13.44秒，小于独立180秒预算。共34次真实价格拟合；单测合成短拟合另计，不混入34。

活跃参数GRU/fixed为1252，learned/utility为2152。四者都分配2152个参数，前两者的900个记忆评分参数冻结或不使用；不宣称活跃参数、训练梯度或FLOPs全部匹配。learned与utility结构与活跃参数相同，区别是效用监督。

初始化被选中次数分别2/1/3/3（每模式8次）；各模式2次训练达到60轮上限，不能称全局优化充分。对8个拟合预测段等权平均，候选不检索权重约0.718，而普通learned约0.793，说明候选并非全部退化为零记忆，但使用更多记忆没有带来主分数改善。这不是因果机制证明。

6项测试在普通与-O模式均通过，包括记忆成熟/不重叠、detach效用教师、真实执行的合成fresh-fit后缀不变、与旧共同训练器的实际fresh GRU控制数值匹配、独立RW评分和成对清单拒绝。测试日志保存为TEST_NORMAL.log和TEST_OPTIMIZED.log。

独立验分器不导入训练器或模型，从有界原价重构标签、训练/验证支持、训练尺度和教师方差，复核32份训练轨迹的检查点选择及44项聚合数值；最大绝对差6.661338147750939e-16。普通与-O核验JSON逐字节一致。独立验分不是第三方重训。

代表性真实复训覆盖gru/utility、seed17、cut459：扰动cut之后的全部价格，重新训练后，参数摘要与原保存模型一致，cut之前保存预测最大差为0。只认证这两个代表性同实现复训，不声称所有32次完整重训或其他独立实现复现。
