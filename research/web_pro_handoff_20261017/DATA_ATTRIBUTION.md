Original depositor: Yingying Fan (2025).
Dataset: Daily Carbon Price Data from Hubei, Guangzhou, and EU Emissions Trading Systems (2018–2024).
DOI: 10.6084/m9.figshare.28682348.v1.
Repository-declared license: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Three workbooks retain original bytes; filenames standardized only. ISO/Excel date normalization and ascending ordering appear solely in derived CSVs. Original prices are not edited. Attribution/license and source limitations apply to the derived dataset as well. No embedded supplier-rights notice was found in the inspected worksheet strings; the deposit declaration is not an ownership warranty or exchange certification.

Guangzhou sheet is literally named 湖北; its 1492 quote dates/prices all match independently held official GDEA endPrice values. Keep this contradiction, do not rename the original sheet. Hubei comparison is to official Latest values, not a certification of all historical closing definitions. EU instrument/venue/currency/roll rules remain unverified.

Do not mix these snapshots with unlicensed source files, claim an authenticated continuous future, or reinterpret them as real-time vintages. Source file IDs, hashes, handling and caveats are in research/pro_data_packet_20261013/DATA_PACKET_MANIFEST.json.

This handoff exports only the first 950 complete derived-CSV records, 2018-01-03 through 2021-12-31, preserving the approved 29204 bytes. This is an excerpt of the previously published attributed dataset, not new observations; the original dataset name above describes the deposit, not the temporal scope of this handoff.
