# Frozen synthetic joint-adaptation probe
Seeds 17,29; exact pilot data(seed) and init(seed); 340 parameters, shared/private routing unchanged. Train 0:64, validation 64:128, test 128:512. 1200 macro steps, per-task validation selection every 20 steps, no test selection. Whole training limit 600 seconds. Learning rate .04, private rate .04, FD HVP epsilon 1e-4/norm. No tuning or retries after test scoring.
One candidate only: private one-step map A(p)=p-.04 P_private grad L(p). Shared meta-gradient of L(A(p)) includes mixed Hessian via symmetric gradient difference. Shared trial z=p-.04 P_shared meta-grad, followed by recomputed private A(z). Compare its actual 16 task-by-contiguous-block MSEs with A(p), not with stale p. Commit trial iff every risk <= private-only +1e-10; otherwise commit private-only. Fixed one trial, no backtracking/line search.
Controls: PCGrad same architecture/rate/1200 steps; private_only (same adaptation, zero shared); SP_budget five sequential ordinary full gradients each macro-step at rate .008 (6000 ordinary gradient calls, same as candidate five calls including private-response recomputation); shared_eval_ablation exact candidate proposal but gate tests z versus p without private adaptation. All save actual finite-step risks.
Candidate is a constrained one-step ordinary bilevel/ANIL-family variant with persistent private hidden units, not a novel model or first-in-field method. Shared parameter mask excludes task biases. Training risk feasibility is not generalization. Computational budgets match gradient calls for SP but not forward calls or FLOPs; disclose counts/time. PCGrad requires four task gradients; private-only requires one gradient. No markets, commits, or pushes.
