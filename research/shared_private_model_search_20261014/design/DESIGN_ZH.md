# 共享表示、独立动态：路线重选（2026-10-14）

## 裁决
只保留一个**待证设计**：时间块梯度一致性约束的低容量 shared-private 多任务学习（简称 Block-SP）。不是已有成功模型，不称首创；不是 domain embedding、年龄路由、阈值修补、残差校准、Koopman 或广义 ridge。改变的是估计问题：从单一广州历史拟合，改为三个异质任务联合估计共享映射，同时每市场保留独立递推动力学。

本轮只阅读指导文件、数据说明 metadata 和一个静态模型文件；主源论文获取未成功。没有读取任何价格文件、2022边界、后缀哈希，也没有训练、执行作者 loader、下载数据/权重、提交或 push。广州、湖北、作者EU的2018—2021全部已开发，不能换叫新测试。本轮合成仅写协议，未执行。

## 唯一候选：数学定义
市场 m∈{G,H,E}，本市场观察序号 i，历史窗口 x_mi 为8个截至签发已可得的标准化价格增量，所有中心/尺度仅拟合成熟训练历史。输出 y_mih=(p_m,i+h−p_m,i)/s_m，h∈{1,5,20}，以观察点而非共同交易日定义。

共享表示 z_mi=tanh(W x_mi+b)∈R²；各市场动态 v_mi=GRU_{ψ_m}(x_mi)∈R²；各步长预测 f_mh=w_mhᵀ[z_mi;v_mi]+c_mh。私有ψ_m和w_mh不跨市场共享，不在签发时读取他市场报价；跨市场帮助只来自已经可得的训练任务。共享映射没有市场ID或domain embedding。

基本目标 R(φ,ψ,w)= (1/3)Σ_m (1/3)Σ_h mean_{i∈I_mh(τ)} (f_mh−y_mih)²。I_mh(τ)要求特征可得且目标端点报价已在τ前发布。各h使用各自成熟支持，不为了h20截掉h1/h5已有标签。用各市场均权而非按总行数加权；没有用目标标准化的差异掩盖较大市场误差。

在每次共享更新内，将每个市场每h的成熟训练起点按时间排序分成4个连续块，记块风险 R_mhb及 g_mhb=∇_φ R_mhb。平均梯度 ḡ=∇_φ R。令 U=conv{g_mhb}，定义：

    d* = argmin_d ½||d−ḡ||²
         subject to min_{u∈U} uᵀd ≥ 0
    φ ← φ−ηd* ; 私有参数仅按各自市场风险更新。

这是最多36个线性约束、18维严格凸QP，零向量总可行。U不是概率置信集；只表示已观测时间块的梯度分歧。严格凸投影有唯一解，若d*=0则冻结共享步骤并继续私有步骤，不加救援门限或门控。任何非零d的一阶块风险变化≤0，但有限学习率、联合私有更新、未来分布均无无害保证。必须同时报告真实块风险变化，不用一阶论证替代预测检验。

**实质额外机制待证**：平均任务梯度可能掩盖少样本时段的相反梯度，因此共享更新要对多个成熟时间块同时满足一致下降方向，而非只对每市场平均梯度做手术。此机制不增加可训练参数。若只等价于把(m,h,b)当伪任务运行既有梯度投影，它只是既有优化法的任务细分应用，不具算法创新；必须与这个等价对照正面比较，不预先宣称不同。

容量：共享映射18参数；每市场GRU两套bias约定30参数、三个4维线性头15参数，合计153参数。该数由工具算式核算，尚未实例化框架验证。没有转移任何过去失败模型参数。

## 普通多任务、独立训练与强shared-private对照
所有对照使用相同输入、成熟支持、训练/验证时点、随机种子、预处理和梯度计算预算；另报告参数量与墙钟，不能称同参数即同计算。

1. 独立训练：各市场自己的2维tanh编码器+2维GRU+相同头（总189参数）；另保留仅私有GRU（135参数）。
2. 普通多任务：共享2维GRU+市场独立头；另运行本153参数骨干直接平均风险梯度，后者就是强SP基线。
3. 强SP（拟定）：相同骨干+训练样本上的共享/私有交叉协方差正交惩罚；仅在内部成熟验证选权重，仅为自定义正交对照，DSN思想关联未核，不称原论文复现。
4. 同骨干SP+PCGrad、SP+CAGrad；算法正文尚未取得；作者版本/参数在实施前核清并固定，不能只比较弱shared-bottom。
5. 核心消融：去块只用每(m,h)平均梯度约束；仅私有无共享；去私有动态共享到底；用打乱块替代连续块（只是算法消融，绝不随机拆训练/验证）。
6. **等价强对照**：相同36个(m,h,b)伪任务+普通共同下降投影，以及伪任务CAGrad/PCGrad。若与候选等价或同效，撤回算法新颖性，最多保留小样本适用性研究。
7. RW、历史已强的MLE/state线性、普通GRU/MLP必须留作后续市场对照。此处不读取其价格/预测，不重算旧成绩，也不救旧失败年龄路由。

## 判断条件
失败表现包括：共享方向大面积为零，效果只等于私有训练；伤害市场被总体均值掩盖；仅靠更大计算预算胜出；对伪任务投影完全等价；正控不能恢复共享优势。出现这些结果停止，不改块数救结果、不打开后续年份找正数。主比较为同骨干平均训练SP与伪任务投影；没有预设“达到某百分比就创新”。候选筛选本身探索性，之后冻结协议才可评分；所有2018—2021结果仍是开发结果。
