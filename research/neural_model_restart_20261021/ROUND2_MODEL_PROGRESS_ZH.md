# 第二轮模型实验进展

日期：2026-10-21。状态：模型实验继续，未宣告可发表成功。

## 结论与当前主攻机制

多尺度路由与外生分任务滞后注意力尚未形成可靠结构增量。滚动非零率先验与proper CRPS训练有实际收益，但矩解码器约0.17%的改善几乎可由已知的均值边际化解释，不能归功于新增方差预算。下一轮优先解决连续mark的位置与尾部表达，实施零点质量＋单调分位样条，不据本轮结果关闭ML/DL方向。

## 1. 多尺度专家：辅助损失与低学习率

实现 [multiscale_round2.py](multiscale_round2.py)，全结果 [multiscale_round2.json](multiscale_round2.json)。以3维basis代替14个独立分位间距参数，训练内验证在两学习率与有/无专家辅助损失间选择。选择seed固定11，最终从同一配置与轮数分别在seed11/22全precut重拟合。基线复用前轮已验证一致的价格、原点、目标与SHA。

这一版本双路由在五市场所选epochs为[79, 60, 40, 11, 18]，说明已经有实际训练，不能再把问题仅归为零更新。虽然相对共享路由有增量，但总体落后均匀融合与经验底座，当前不足把复杂路由作为论文主贡献。两种优化同时改变了训练/表示，跨版本变化不能单独解释为路由收益。

## 2. 概率—幅度分支：滚动先验和完整CRPS

实现及说明见 [marked_event_round2_report_zh.md](marked_event_round2_report_zh.md)，逐市场与期限见 [marked_event_round2_cells.md](marked_event_round2_cells.md)。五市场、两个种子、三种先验×NLL/CRPS六个模型，验证选epoch后全precut重拟合。

| 比较 | MQS几何改善 | 胜出单元 |
|---|---:|---:|
| 神经滚动先验CRPS / 静态先验CRPS | +0.4641% | 12/20 |
| 神经滚动先验CRPS / 规则先验CRPS | +0.0754% | 17/20 |
| CRPS训练 / 同结构NLL训练 | +2.3486% | 13/20 |
| 神经滚动先验CRPS / 经验常数 | -0.0967% | 11/20 |

完整CRPS按零atom＋正态混合解析计算，已通过梯度及独立CDF积分；不使用有限分位网格冒充完整CRPS。所有神经评分对应同一seed分布混合。原经验基准的MQS来自线性插值样本分位数，CRPS来自完整ECDF，Brier为平滑非零频率，表示差异已说明。

滚动信息明显改善部分概率漂移：全部预测原点pooled Brier相对静态约改善26.4%，但对规则先验并无神经优势，不能用Brier单元几何比掩盖近零分母。CEA一步概率更准却使价格MQS变差，促使下一节显式协调概率与幅度。

## 3. 外生组滞后注意力

准备数据及风险见 [exog_round2_report.md](exog_round2_report.md)，模型见 [exog_round2_model_report.md](exog_round2_model_report.md)。严格向过去asof，目标全部保持canonical；用asinh变化处理WTI负值和FX量纲，缺失和信息age作为输入，所有归一化仅在当前训练区间拟合。

湖北九因子有值，广州DAX全缺、末期部分信息age达260天；EU原表九列全NA，所以本实验仅按预先覆盖运行湖北/广州。上游填补与真实发布日没有独立确认，不能称完全实时外生数据。

## 4. 频率—边际矩预算耦合

实现及全部分市场/seed对照见 [marked_moment_round2_report_zh.md](marked_moment_round2_report_zh.md)。模型输出p、无条件均值mu、连续创新预算s以及中心化单位方差shape U；M=mu/p+s/sqrt(p)*U。它满足E[Y]=mu、Var[Y]=s²+(1-p)mu²/p。s²仅是连续创新方差项，不能称总风险完全与p解耦。

| 比较 | MQS几何改善 | 胜出单元 |
|---|---:|---:|
| 矩预算神经模型 / 独立幅度神经模型 | +0.1701% | 8/20 |
| 矩预算神经先验 / 矩预算规则先验 | +0.0250% | 16/20 |
| 矩预算神经先验 / 矩预算静态先验 | +0.0283% | 9/20 |
| 矩预算神经模型 / 经验常数 | +0.0735% | 12/20 |

矩神经模型对经验基准MQS仅略有优势，完整CRPS仍退步约0.573%；对经验的两个seed方向不一致。平均增量不能当作已达发表标准。均值边际化已有 [Smith等2014](https://pubmed.ncbi.nlm.nih.gov/25043491/) 先例；仅把输出拆成发生概率与mark也已有神经hurdle近邻。可检验的结构差别是预算与归一化形状、频率先验之间的耦合，仍需分清均值与预算的贡献。

[独立矩恒等式检查](verify_moment_geometry.json)的1000组随机例子中，初始化恢复最大误差8.88e-16、均值误差1.11e-16、方差误差1.78e-15。这证明代数与实现目标一致，不证明经济规律或预测优势。

新增 [仅均值边际化控制](marked_moment_round2_meanonly_report_zh.md) 后，方差预算相对mean-only的MQS额外改善仅0.00223%，9/20单元更好，两个seed方向相反；mean-only本身相对独立幅度头已有0.16787%改善。此前约0.1701%的矩解码器改善几乎可由均值参数化解释，本轮没有建立方差预算的可靠新增贡献。所有已冻结输出SHA保持不变。
