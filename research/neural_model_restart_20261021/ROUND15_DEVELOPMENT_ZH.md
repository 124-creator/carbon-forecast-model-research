## 与前轮的实质区别

前轮允许神经网络改变整条风险曲线的水平。本轮所有模型共用相同的22步总风险T，形状只能在[1]、[2–5]、[6–22]三个期限桶之间调整份额。1/5步可改变，22步均值逐行保持T/22不变。因此短期改善无法通过抬高或压低总风险获得。

目标依然是未来Parkinson区间方差代理，不称真实QV、累计收益方差或完整概率分布。

## 背景与信息边界

- KRBN来源与公司行动口径沿用第14轮；在全部特征/目标构造前删除2026行。
- 背景三桶预测采用Poisson HGB。2022、2023、2024年的背景各只用其年初前已成熟标签拟合，再预测该年。
- 神经头使用2022–2024有真正折外背景的行；2025仅作开发验证。全输入HGB对照可用2020–2024成熟行，样本更多，报告不将预算不同藏起来。
- 相同背景总量T和份额w0适用于全部消融；epoch0的无调整背景也纳入验证选择。

## 几何与候选结构

日内log坐标：r=log(C/O)、u=log(H/O)、l=log(L/O)、q=u−l。形状为eta=r/q、xi=(u+l−r)/q，满足|eta|+|xi|<=1；零range使用中性几何并由幅度上下文保留其零区间信息。

背景12特征已包含收益和range，所以不能称为完全无形状输入。新几何的增量须条件于这些已有信息。

候选构造三状态相邻期限运输：w=exp(Q)w0，其中Q列和为0、非对角元素为正。两条神经边倾斜delta改变相邻期限的风险分配。delta=0时Qw0=0，精确恢复背景；正性与总风险守恒有显式数值自检和梯度检查。

对照：同容量flat形状残差头、无几何context运输、同全输入HGB分配器、固定背景份额、均匀日风险。

这是已知可逆Markov generator的一个条件参数化，并非新概率原理。运输单位不是实际未来交易日。可检验的结构贡献仅是有限时间局部运输的归纳偏置是否优于同输入flat头。对三状态链，平稳分布可写为softmax型边势倾斜，不能将其包装为超越所有softmax的理论。

## 首轮三种子开发结果

11/22/33三种子，最多100 epoch，按2025的1/5步平均标准方向QLIKE差选择epoch。下表为相对固定背景的损失差，负值更好；不是独立测试，也不计算负对数分数的百分比增益。

| 模型 | 1步 | 5步 | 22步 |
|---|---:|---:|---:|
| 固定背景分配 | 0 | 0 | 0 |
| 均匀分配 | +0.0220271 | +0.0182871 | 0 |
| 同全输入HGB分配 | +0.0044051 | −0.0000477 | 0 |
| 几何运输头 | −0.0028198 | −0.0010685 | 0 |
| 同容量flat形状头 | −0.0032980 | −0.0008633 | 0 |
| 无几何context运输 | −0.0019905 | −0.0008051 | 0 |

几何头相对背景和context有改善信号；运输对flat在5步略好、1步更差，联合目标并未证明运输占优。不能凭此宣称“矩阵运输架构成功”。

当前neutral把eta/xi及派生项全部置零，而context保留实际收益与range。它不能单独识别wick xi，改善也可能来自显式eta基函数。因此追加预定开发对照：保持真实eta，仅置xi及相关项为零；body-only头；从严格过去样本库抽取、保持body和几何可行性的条件wick安慰剂。对照仍只使用2025及以前数据。

还确认一个更深的识别限制：固定总量但只优化1/5步损失，仍可能从6–22步桶挪用风险，补偿背景总量的幅度误差。举例：真实三桶风险为2*w0、冻结T=1；某个头把前两桶翻倍、从最后一桶扣除，可使短期预测改善，但真实风险比例始终为w0，并没有新的时间位置信息。因此，本表中的正向信号尚不能证明几何预测风险时间分配。

下一开发对照将训练目标显式分为`allocation`与旧`short_qlike`。主目标为`-sum_b (Y_b/c_t)*log(w_b)`，其中c_t是预测时已知的过去风险尺度，不可用未来总风险作分母。条件于已知特征时，其最优份额为`E[Y_b|X]/sum_b E[Y_b|X]`，共同幅度乘子会抵消。所有三个不重叠桶均参与训练和验证选择，同时另报告各桶及累计1/5/22步预测损失，防止隐藏远端损害。旧源码和结果保留，不静默改写为新目标的结果。
