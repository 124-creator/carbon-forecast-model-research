# 发表评估：这套东西能发在哪、以什么形态发

评估时点：2026-10-21，第二版（**已排除 MDPI 全家**——学校预警期刊）。依据是本仓库 round 3–7 的实验产物 + 对 *Journal of Forecasting* 2026 年碳价预测综述的全文检索。

## 0. 结论先说

**能发，但只能在非 MDPI 的中等偏上期刊发，命中率从 55–65% 降到 20–30%。**

- "新模型超越 SOTA"：**死了**。七条技术路线全负，十臂最差 −2.81%、最好 +0.27%，只有上海显著。
- "基准 + 口径审计"：**成立**，而且刚拿到硬证据——协议阶梯显示同一模型只改协议能改动 **+42.8%** MQS，换模型只能改动 **0.2%**。
- 去掉 MDPI 之后，最现实的目标是 ***Journal of Forecasting***（20–30%）；*IJF* 与 *Applied Energy* 仍是 10–15%；中文核心 30–40% 是稳妥保底。
- 一个有利的新证据：JoF 2026 年刚发了一篇 35 页碳价预测综述，**全文没有一次出现 out-of-sample / test set / split / leak**。这个空白就是我们论文的靶子，而且是发表在同一本目标期刊上的靶子。

## 1. 为什么 JoF 是最现实的第一站（新证据）

仓库里存着两篇 Wiley 原文：

1. **Bisiotis, Christopoulos & Tzougas (2026), "Forecasting Carbon Prices: A Literature Review", *Journal of Forecasting* 45(2): 496–529, DOI 10.1002/for.70054**。35 页，四张表逐篇列出数十项研究（作者/数据模型/主要结论/局限）。
2. **Sha et al. (2025), "A Two-Stage NLP-Driven Framework for Interval-Valued Carbon Price Prediction", *Journal of Forecasting***。同刊、同题材、区间预测。

含义有三层：

- **题材匹配**：JoF 连续发碳价预测，且接受"区间/概率"形态，不是只收点预测。
- **靶子明确**：对综述全文做去连字符规范化后检索——

  | 关键词 | 出现次数 |
  |---|---|
  | out-of-sample / out of sample | **0** |
  | test set / test period / training set | **0** |
  | split | **0** |
  | leak / look-ahead / data snooping | **0** |
  | in-sample | 1 |
  | CRPS / pinball | **0 / 0** |
  | statistical significance | **0** |
  | quantile | 19 |

  也就是说，这个领域最新的旗舰综述在"局限"一栏里写的是"只做一步预测""只用单一市场""忽略外部因素"，**没有一条是关于训练/测试划分与评价口径的**。我们的论文正好填这个洞：不是"某个模型更好"，而是"这个领域的比较方式本身没有控制变量"。

- **风险也要说清**：该综述的结论是"先进机器学习模型表现更优"。我们的论文在事实上与之相左。**必须写成"补充"而不是"反驳"**——"我们不质疑任何单篇结果，我们量化的是跨研究不可比的那部分方差"。写成对抗性叙事会被直接拒。

> 检索局限：关键词计数只能作为指示，不能作为定论。写进论文前必须逐节读完第 3–4 节的评价部分，确认没有用别的措辞讨论过划分问题。这一步大约 2 小时。

**推荐路径**：JoF → 被拒转 *Journal of Commodity Markets* 或 *IJFE* → 保底 *Climate Change Economics* 或中文核心。三者叙事几乎不用改。

## 3. 为什么去掉 MDPI 之后仍然值得投

三条硬理由，全部有数据支撑：

1. **空白是别人替我们指出来的**。JoF 自己的综述 35 页、0 次提到样本外划分。这不是我们自说自话。
2. **效应量足够大**。协议 +42.8% vs 模型 0.2%，是 200 倍的量级差。任何审稿人都能理解"报告精度主要在测协议"这件事的重要性。
3. **证据链是完整的**。5 市场 × 4 期限 × 10 模型 × 8 档协议 + 配对 bootstrap + 冻结 SHA256 + 一键复现。这一套的工程量本身就能支撑"基准论文"的可信度。

## 4. 面向 JoF 还需要补什么（2–3 周）

按"审稿人最先攻击"排序：

1. **扩市场：5 → 6（深圳）**。仓库里已有 Shenzhen 2020/2021 序列（`conditional_persistence_20261019b` 里有完整的年度面板）。6 个市场能挡住"样本太窄"的第一枪。若还能补北京/天津/福建试点，9 个市场会显著提高 IJF 命中率。
2. **阶梯做 20 次重复随机划分**，把 +30.2% 变成区间。这是方法论论文的必答题。
3. **用 Bisiotis 综述的四张表做对齐表**：把该综述收录研究的"数据/市场/评价指标"整理成表，标注哪些用了全样本标准化、哪些在切分前做了分解、哪些在测试集上调了参。**注意：只能标注"论文未报告"，不能推断"论文做错了"**，除非读了原文。
4. **标度约定敏感性**：滚动窗 60/120/250 + 固定常数，支撑"17.5 个百分点来自约定"这一条。
5. **公开仓库 + 一条命令复现**。
6. 英文写作 2–3 周（最大的一块，不能省）。

## 5. 如果一定要"模型创新"型论文

必须换信息，不是换架构。仓库里已经躺着两批可用数据，不需要重新采集：

## 6. 不建议做的事

- 不要把 +0.27% 写成"显著优于十个基线"。
- 不要把全样本 R² 0.99 当预测精度。
- 不要报测试集扫出来的 λ、滞后阶、种子。
- 不要把 `P_boot` 当 p 值。
- **不要写成对 Bisiotis 综述的反驳**——写成补充。
- 不要一边说"模型都一样"一边说"我们的模型更好"。
