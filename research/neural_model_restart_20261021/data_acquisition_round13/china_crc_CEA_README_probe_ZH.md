若核实成立，H/L 可能覆盖大宗折价而 C 采用挂牌口径；不能直接视作统一交易方式连续价格过程的 OHLC 或真实 QV。应保留挂牌/大宗/总量三组 volume 与 amount，各自单位不变。空白、零值和不存在交易这三种情况必须分开；无大宗时的空白不能未经结构或规则确认改成零。
