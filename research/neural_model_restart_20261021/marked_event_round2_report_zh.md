# 第二轮：历史滚动概率先验与闭式CRPS双解码实验

已实现并运行五市场、seed 11/22、三种先验×两种训练损失，共60次inner训练及随后全precut重拟合。正式运行91.84秒。本轮有小幅内部增量，但没有建立超过经验常数总体预测的优势，不构成可发表成功或新颖性证明。

滚动先验只使用原点t以前的lp[t-128:t+1]，对其中h步收益是否非零计数，Beta(1,1)平滑：p_local=(nonzero_count+1)/(129-h+2)。静态先验由当前拟合区间按h估计。static_prior固定静态概率；rolling_rule_prior固定0.8*p_local+0.2*p_static；rolling_neural_prior从相同0.8融合起点学习门控，并增加有界logit残差。三种结构的mark主干、特征、优化配置完全匹配，均接收logit(p_local)作为特征，因此比较的是概率构造增量而非独占历史信息。

幅度头保持正中心、负中心两个正态混合，分量允许重叠，混合权重不等于正收益概率。h=[1,5,10,20]是原始交易日序列观测步，目标为直接期限收益边际；h>1零收益不是期间无更新的标签。

训练对照为混合测度NLL及完整闭式CRPS。CRPS使用E|X-y|-0.5E|X-X'|，零质量作为sigma=0的退化分量，正态absolute期望使用解析公式。这不是有限分位数网格分数。已通过标准正态、纯atom、autograd梯度及独立CDF数值积分核对。训练目标以原点历史波动标准化，预测反变换一次。MQS仍是15个分位数上的两倍平均pinball，与完整CRPS分别保存。

保留第一轮的全部4307个市场—原点—期限键、切分、128步窗口和step=2。训练t+h<val_start，验证t>=val_start且t+h<cut；末25%precut验证，最大48轮，统一验证MQS选轮，然后重新估计归一化/初始化统计，在所有可用precut标签固定轮数重拟合。CEA/广州/上海cut为2024-01-01，湖北/EU为2023-01-01。测试是历史复用的探索区间，未用来调本轮参数。

两个seed采用等权预测分布混合，再CDF二分计算分位数，完整CRPS包含跨seed分量项，Brier使用同一混合分布的非零概率。对神经混合模型，这三项评分对应同一预测分布。第一轮使用seed分位数平均，两轮不能把全部差异归因于新架构；本轮内部消融是主要证据。

经验基准需要单独区分：其完整CRPS来自所有全precut可用训练标准化样本的ECDF，不是15个分位点的离散分布。公式为mean_i|z_i-y| - sum_i(2i-n-1)z_(i)/n²，最后乘原点scale一次。其MQS为了沿用第一轮基准，使用np.quantile默认线性插值样本分位数，并非严格ECDF左逆；Brier使用Beta(1,1)平滑非零频率，而非原始ECDF非零质量。因此经验基准的MQS、完整CRPS、Brier分别对应不同的经验表示，不应声称同一经验分布。这里没有将15分位点构成的离散分布冒充完整ECDF。
